# Portable review package plan

The current reviewer is intentionally a workspace checkpoint. To package it
without workspace or Git dependence, split it into two pure entry points:

```python
rebuild(word_path) -> arrangement_doc
verify(arrangement_doc, caller_path, invoice_path) -> review_doc
```

`rebuild` should authenticate the compressed native WORD bytes, replay all
events over exact `Fraction` rows, build the original strict destination
histories, and return the 47-cut filter, fourteen `L_E` bases, all 468
source-derived main-free MOVE rows, pair intersections, and eleven-group
rank receipt. It must not read the A/B residual basis files.

`verify` should enumerate all 16,383 site subsets from `arrangement_doc`,
check the arbitrary one-relation finite direction partition, price the 1,425
candidate classes and arbitrary-codimension cache-only bound, then bind the
17-call caller and signed invoice. To preserve this independent engine, the
468-row A/B `ROWS.json` comparison should be an optional validation input;
it is not needed to derive the rows or theorem.

The minimal self-contained data bundle is the exact #7481 WORD, the exact
17-call caller JSON, the exact signed current invoice, and a local copy of
the small standard-library directed price routines. All bytes are hash
checked. Functions return documents without writing outputs. Keep explicit
exceptions in normal and optimized Python, and include one mutation control
for each pinned input and an incorrect site-space/control case.
