coefficients remain unchanged. Each record retains its exact source event,

## Budget and exclusions

The fixed source catalogue can be built once with charged exact 9-dimensional
integer/Gaussian arithmetic, or retained as authenticated finite metadata.
Runtime emits one record per whole-field operation; serialization accounts
for integer bit lengths, owner indices, coefficients and matrices. It never
enumerates coefficient packets or an expanded recursive compiler tree.

This is a mathematical metadata producer, not a literal tape dispatcher or
the completed selected compiler. Each emitted operation still owes actual
payload acquisition, packing, address traversal, primitive execution, work
retirement, same-owner return and history accounting. Product, completion,
split and lockstep composition are later joins. No supplier invoice, selected
certificate, complete kappa or foundational assumption is claimed discharged.
