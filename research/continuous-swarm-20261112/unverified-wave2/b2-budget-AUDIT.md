## Optimistic budget and exact granularity

For M complete records, each of r complex coefficients at Theta(p) bits,
V=Theta(Mrp). Source 05-layers.tex has d=Theta(p^epsilon), 0<epsilon<1, and
r=2^Theta(p/d), exceeding every fixed polynomial in p. With polynomial setup
U(p), query cost q(p), and J(p) queries, the extra work is U+Jq. If J<=C M
for fixed template C, then (U+C M q)/(M r p) tends to zero, including setup
because M>=1. Physical whole-volume scans remain in the ordinary bill.

If J~M r (one query per coefficient), the ratio instead becomes q(p)/p.
Polynomial query work alone no longer proves the same node tariff. For
example, a deliberately p^2-step descriptor routine per coefficient costs
Theta(V p), exceeding V Lambda(p) e^tau for e<=d, fixed polylogarithm Lambda
and epsilon*tau<1. The same routine per record is negligible. This refutes
the generic amortization inference, not an actual bound claimed by A1/A2.
A1 contains no coefficient loop. Fixed-tape metadata scans still need their
actual query multiplicity; merely calling each query polynomial is insufficient.
