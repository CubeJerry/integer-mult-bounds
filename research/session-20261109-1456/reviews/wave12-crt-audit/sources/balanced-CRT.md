# A separate CRT route through batched reversible switches

Written construction, 2026-10-19. This replaces the fast packing interface
with balanced CRT, reversible switches and total sparse repair. The ordinary
interchange used below is supplied by BIT.md. Its complete application to
multiplication is PROOF.md; finite checks alone do not establish that theorem.

## Why the existing packing bound is insufficient

PR4024 (`e99297be6749518a1b5b85cd129ecaf204d26c63`) implements a single
full-support coordinate reorder followed by one streamed triangular shift
per source axis. Its O(V d) term fits its stated epsilon=.997 family, but
cannot be silently absorbed at epsilon arbitrarily close to one when the
desired saving is about .001731. The fine-prime transfer explicitly retains
prime packing as an interface assumption. A bit-coordinate permutation alone
does not implement the nonlinear modular shifts.

The construction here has the bound

    O(V p^(1-a) ell^2 polylog(p)),

where an already completed ordinary interchange costs O(V h^(1-a)), the
total binary address length is L=Theta(p), each record has R=Theta(p) bits,
there are d=Theta(p^epsilon)
source axes, and their binary widths are ell or ell-1 with
ell=Theta(p^(1-epsilon)). Its saving is therefore

    a - 2(1-epsilon),

up to arbitrary fixed slack for logarithms. With the completed BIT
stage a2=.001733394791695384296, this has room above the complex target for
epsilon sufficiently close to one. The implementation and amortization
arguments below establish the corresponding interfaces.

## 1. Balanced CRT factorization

Take a power-of-two number d of pairwise coprime source moduli s_i, each
strictly below its dyadic target t_i. Choosing d within a constant factor of
p^epsilon does not change any exponent. For a consecutive group G define

    S_G = product_(i in G) s_i,
    P_(G,i) = product_(j in G, j<i) s_j,
    k_G = sum_(i in G) a_i P_(G,i),
    Phi_G(a)_i = k_G / P_(G,i) mod s_i,

where division means multiplication by the modular inverse. A singleton map
is identity. Suppose G splits into equal groups A followed by B, and each
child has already been transformed. Coordinates in A need no change. For
each i in B apply independently

    y_i <- y_i + k_A (S_A P_(B,i))^-1 mod s_i.

Reconstruct k_A from the current child coordinates in A by ordinary exact
CRT arithmetic. This is numerical control computation, not a permutation of
the payload. The formula follows from k_G=k_A+S_A k_B. Thus bottom-up tree
levels produce Phi_G, and each level changes only right-child axes using
unchanged left-child controls. An inverse processes levels in reverse and
subtracts the same offsets.

Logical indices may be stored in reverse physical order, with axis0 the
innermost coordinate, as ordinary mixed-radix coefficient order requires.
All groups still occupy contiguous physical intervals. The arbitrary-source
switch implementation below reads its control function on the complete y
field; it does not require logical A to precede B on tape. Thus no full
physical axis reversal is part of this construction.

On the padded rectangle, fix target values >=s_i and disable a node's shifts
when any left-child value is invalid. Each update is a permutation, fixes
invalid target values, and preserves the set of globally valid addresses.
Consequently arbitrary dirty invalid records are permuted bijectively and
zero padding stays zero. The valid restriction is the required CRT map.

This factorization needs O(log d) parallel levels. No step obtains a fast
payload permutation merely from an efficiently computable address key.

## 2. Each modular rotation has a bounded switch program

At fixed left-child controls, a target axis carries the permutation

    x -> (x+c) mod s for x<s;  x -> x otherwise,

on its existing 2^h coordinates, h in {ell-1,ell}. A Beneš network gives
2h-1 layers. At each layer a switch flips one address bit, and its control
depends only on the other h-1 bits and c. The standard constructive proof
colors the even cycles of the bipartite graph joining input pairs to output
pairs, then recursively routes the two colors. It uses no data coordinates.
Shorter axis programs receive identity operations, not extra coordinates.

All axes at one tree level can use a common O(ell)-layer schedule. At a
given layer each active axis has one target bit. Its Boolean switch control
depends on its own other bits and the left child of its tree node. It is
independent of every active target bit. Thus the switches commute.

Numerical controls may be generated by an intentionally inefficient but
explicit finite algorithm: list the 2^h images, build pair adjacency, color
cycles by repeated scans, and recurse. At a single current address, recompute
the relevant tables and read the switch. Using sequential integer tapes,
an ample bound for all controls and the forward/inverse macro address maps is

E(p,ell) <= C 2^(4 ell) (p+2)^16.

One explicit sequential simulation justifies this generous bound. The
algorithm in `benes` stores permutations, inverses, colors, a work stack,
and switch tables at all recursion nodes. Their combined length is
O(2^ell p^3) bits: each level contains O(2^ell) entries and there are at
most O(p) levels, with O(p)-bit entries. Replace every indexed access by
a complete sequential scan of these encoded arrays, returning to their
markers. Bound all elementary arithmetic by schoolbook O(p^2). Fewer than
O(2^(2ell) p^6) such operations suffice even if adjacency, coloring and
table queries are repeatedly recomputed by nested full scans. Their product
is O(2^(3ell) p^11). Repeating for at most O(p) axis controls and for the
fixed number of forward/inverse gadget operations remains below the stated
2^(4ell)(p+2)^16 bound after increasing its fixed constant. Exact CRT
reconstruction and modular inverses use only a polynomial in p. Encode
all recursion state in the same sequential work region; no new tape is
allocated at a recursive call. Erasure and head returns have the same bound.

The exact constant is fixed. This is exponential in ell, so it MUST be paid;
the old polynomial-in-p preparation allowance cannot simply be reused.
The large-guard argument below pays it without a per-record E surcharge.

## 3. Reservoirs independent of the switch functions

Put

    G=64(ell+ceil(log2(p+2))),  B=2^G,  K=64G,
    r_max=floor(L/(100G)),  H=r_max G.

Eventually ell>=ceil(log2(p+2)), ell>=2 and d>=51200. Then G<=128ell,
L>=d(ell-1), and r_max>=d/51200. Thus r_max=Theta(d), H>=G and there are
at most a fixed number of batches per level. The constants may be very
poor. Handle the finite initial range by the elementary procedure; the
algorithm checks these integer conditions rather than assuming them.

Batch at most r_max target axes. At a non-root tree level every node lies
wholly in one of the two global halves. Process batches from one global
half at a time and choose the control reservoir in the other half. At the
root, split the right-child targets into its two quarters; use the inactive
quarter as the reservoir. Subdivide these batches at r_max. There are O(1)
batches per level; their number depends only on fixed constants.

Each batch has a contiguous unused address interval of length at least
L/8 eventually. Neither its active axes nor any of their control functions
uses this interval. Since 3H<=3L/100, borrow three H-bit fields there.
Move them into two front positions and one back position using a fixed
number of paid equal-H interchanges. Recompute all logical positions after
these moves. The switch functions still omit the three borrowed fields.
Undo these placements at the end of the batch. Their dirty values must be
restored for every address, not just valid CRT addresses.

For literal disjoint swaps, choose the three source H-blocks within that
unused interval and away from the first 2H and final H destination blocks.
The interval has length >=L/8>=12.5H. Removing the destination end regions
and allowing two H-blocks of alignment waste still leaves room for three
source blocks. Three disjoint source/destination exchanges suffice.

## 4. Compact switch gadget with a larger guard

The algebra is the retained compact arbitrary-source gadget, with Boolean
source functions f_i(y) in place of source bits. This substitution is valid
because all f_i omit the target set and the borrowed controls. Let j_i be
the target positions in the current y field, and let u_i,t_i be the low
r active base-B digits of two H-bit controls. Put z_i=u_i mod 2. Define F by

    y += sum_i 2 z_i t_i 2^j_i;
    t += sum_i y[j_i] B^i;
    y += sum_i z_i (1-2t_i) 2^j_i;
    t -= sum_i (y[j_i] XOR z_i) B^i.

Use the back H-bit field for the retained paid shuttles of the t updates.
Execute F, load u += sum_i f_i(y) B^i, execute F, and unload u by the same
function. For good addresses the completed F changes only target bits, so
every f_i has the same value at load and unload. The ideal result is
target_i XOR=f_i(y), with all borrowed and non-target coordinates restored.

Every t update and u load/unload is an ordered rotation after shuttling
that entire H-bit field with the back H-bit field. Its source y then
precedes its target. Undo the shuttle immediately afterward. The dirty
back field is restored at the endpoint for every address, including bad
ones. There are four t updates and two u updates across the complete
macro, hence twelve paid H-bit exchanges. The y additions are already
ordered because u and t precede y. This realizes all displayed additions
with the ordinary primitive and complete-fiber scans; their notation
does not assume an unpaid earlier-target controlled rotation.

Here is the cancellation for each active digit, including dirty controls.
Write b for its original target bit. The first addition leaves b unchanged.
The t update gives t+b; with t<=B-2 this causes no base-B carry. The two
y additions then have total z(1-2b)2^j. They flip precisely that target
when z=1 and restore its higher guard bits. The final t subtraction is
(b XOR z) XOR z=b, restoring the original t. Guard separation and the
2B margins keep every intermediate carry inside its own guard interval,
so this proof applies simultaneously to all targets. Loading f_i in u
has no base-B carry because its original digit is <=B-2. Its parity
changes from z_i to z_i XOR f_i. The two completed F operations thus
flip the target by f_i. Each f_i ignores every active target, so its load
and unload values agree and u is restored. Unused high digits remain
unchanged. This proves agreement with the ideal switch for every good
address, not just for constant source functions or initialized controls.

Color targets by current position modulo K, so guard intervals are disjoint.
This uses O(K)=O(ell+log p) colors. The last K positions are treated by the
elementary one-bit controlled permutation, with an unused H-bit reservoir
as complete payload to pay preparation. No last-K exception is dropped.

For this elementary exception, exchange the target bit with the last bit
of y using one width-one ordinary interchange. Transform its Boolean
control function by that known exchange. All its dependencies now precede
the target, and the back H-bit reservoir remains a complete suffix omitted
by the function. Rotate the two target slices conditionally and exchange
the bits back. Preparation is paid by this 2^H suffix, including when the
control depends on every other non-reservoir bit. At most K such exceptions
cost O(VK); they introduce no E-per-record term.

The usual good predicate requires active u_i,t_i != B-1 and a margin 2B
from both ends of each K-bit guard. Its bad density is at most

    r [2/B + 8B/2^K] <= C p 2^-G.

Every actual rotation is bijective. The ideal switch layer preserves the
good predicate and agrees there with the actual macro. Therefore both
maps preserve the bad set. On the bad holes, apply the correction key
T(S^-1(x)), sort those holes by this full key on fixed tapes, and merge them
back. This is the retained sparse repair, now with its control evaluation
cost explicitly increased to E(p,ell). It does not sort the full input.

Since

    2^-G E(p,ell) <= C 2^(-60 ell) (p+2)^(-48),

bad-key evaluation, O(p)-bit keys, radix passes, counters and clearing all
fit O(V). Dense control preparation occurs once per complete target fiber
of at least 2^H addresses (or a larger y fiber), and H>=G eventually.
Thus E/2^H has the same bound and dense preparation also fits O(V).
These are two separate amortizations; incomplete bad fibers cannot use
the dense-fiber argument.

Dense **guard detection** needs a separate bound. The old PR2250 tariff
contains M A^3 and assumes superpolynomial record length; CRT records have
only R=Theta(p) bits. Do not import that tariff unchanged. Enumerate each
current address with an L-bit binary counter. Store an ordered, linear-size
descriptor marking the active base-B digits and the disjoint K-bit target
guards. In one sequential pass over the counter and descriptor, test each
active u/t digit for all ones and compare each guard against its two fixed
binary thresholds. The tested intervals are disjoint within each field, so
their total bit length is O(L), not rL. Threshold strings are generated once
per color; their total length is O(L). Compare from most significant to least
significant bit using a three-state less/equal/greater flag. Return the heads
and update the counter in O(L) steps per record. Thus this dense test costs
O(M L)=O(V); it uses no ring multiplication, full switch-table evaluation,
or inverse-macro evaluation on good records. Only exceptional records invoke
the E(p,ell) computation. Reinsertion reads the one-bit hole stream and
compares an O(L)-bit key only at a hole, again within the paid bound.

One color uses O(1) ordinary H-bit interchanges plus linear scans and paid
repair. It costs O(V H^(1-a)+V). With K colors and H<=L=O(p), one switch
layer costs O(V p^(1-a) (ell+log p)), including placement and restoration.
The scratch for numerical control generation is <=E, absorbed by complete
fiber volume; fixed-tape radix sorting and the ordinary callee use fixed
inventories. No number of tapes depends on d, ell, or input length.

## 5. Composition and verification boundary

O(log d) tree levels, O(ell) switch layers per level, and O(1) batches give

    O(V p^(1-a) ell^2 polylog p).

Insert and remove dyadic padding by the ordinary O(V) nested enumeration.
The inverse has the same cost. All forward/inverse word and control
generation is uniform: Section 2 specifies the sequential simulation,
Section 3 handles integer rounding and reservoir placement, and Section 4
proves arbitrary-function cancellation, full keyed repair and the linear
guard scan. Numerical parameter validity is checked before entry. A literal
transition table is not supplied; the construction uses a fixed inventory
of sequential tapes and encoded loops, without a random-access oracle.
PROOF.md applies it to the actual fine-prime and precision family. The
separate complex and Gaussian constructions are in COMPLEX.md and GAUSSIAN.md.

`check_batched_crt.py` passed 2,015 complete modular-rotation networks
(110,980 input columns), 4,132 complete padded CRT addresses (1,173 valid),
and 87,040 compact addresses, including 62,560 exceptional repairs. It
checks source functions that depend on guard bits and unused high digits.
`check_compact_crt.py` additionally composes raw words and keyed repairs
through ten forward/inverse layers on all 4,096 padded addresses. These
finite results test the endpoint and repair; the uniform costs follow from
the preceding counting arguments, not from timing the fixtures.
