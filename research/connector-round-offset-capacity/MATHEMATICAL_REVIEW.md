## Correction and inherited interface

For D groups of b sources with `D(2^b−1)≤c`, reserving a distinct round for each nonempty group subset is possible. In any round every source is called once. Thus a reserved subset S at round r yields the actual prefix `r·1+1_S`, regardless of the preceding permutations. Every boundary `rk` also supplies `r·1`. For a global mask, its nonempty group intersections S_i are disjoint, so their productive prefixes sum to `1_M+(Σr_i)·1`. The ordinary positive read at `r₀k`, `r₀=(−Σr_i) mod c`, cancels this offset.

This correction does not require an unused round, a negative map, a random event, or a new oracle. The correction may precede or follow productive reads. All requested reads can be sorted chronologically because they do not modify the connector. Repetition is permitted. A full-set prefix at the final boundary remains legal: its vector is zero modulo c, identical to the initial boundary. The correction still works in that case. If a block component mask is empty, no reads are required.

At most D+1 reads are used for a nonempty component. The assumption `D+1≤c` permits padding to c reads at zero. Exactly c reads cancel arbitrary initial dirty contents; exactly c calls of each source restore the connector. The source coefficient is the desired binary mask. Source immutability and initial-output preservation hold, and the matrix order is always A_M B_j. Neither commuting maps nor primality is assumed. Algebraically, the productive prefixes solve the problem modulo the diagonal subgroup generated by the all-ones vector; the boundary read lifts to the exact target. That subgroup has order c for every integer c≥2.

For concatenated blocks, each previous block contributes c copies of its source coordinates at later boundaries and hence contributes zero modulo c. Use only the local reads in nonempty components, then pad the total once to c. There are at most `floor(c/(D+1))(D+1)≤c` pre-padding reads. Therefore

    N(c)≥Db floor(c/(D+1)).

## Quantifiers and quantitative lower bound

For fixed depth d=D+1, choose `b=floor(log₂(1+c/D))`. This satisfies the reservation bound and gives `k=Db=(d−1)log₂c+O_d(1)` for every sufficiently large integer c. There is no divisibility restriction or subsequence. The coefficient matches the inherited depth-d upper leading term. Each fixed D gives global coefficient D/(D+1); fixing D after an error tolerance and then sending c to infinity gives liminf≥1 without a uniform-in-D assumption.

The stronger explicit growing-D calculation in PROOF.md is also correct. For c≥16, put L=log₂c, D=floor L, and the b above. Since D≥4, `1+c/D≤c`, so b≤L. Also `b≥L−log₂D−1`, D≤L<D+1, and D+1≤c. Thus

    Db floor(c/(D+1))≥cb−cb/(D+1)−Db
                    ≥cL−c log₂L−2c−L²
                    ≥cL−c log₂L−3c.

The final inequality uses L²≤2^L=c for L≥4. Equality holds at L=4, and `d/dL log(L²/2^L)=2/L−log 2<0` thereafter. All rounding effects have therefore been charged.

## Independent check of the universal upper bound

For any floor word on n sources, all c reads for a mask can be regarded as a multiset of cn boundary positions after identifying the final vector `c·1` with the initial zero. A multiset determines one residue vector; distinct binary masks are distinct modulo c because c≥2. Therefore

    2^n−1≤binom(cn+c−1,c)≤(e(n+1))^c,
    n≤1+c log₂(e(n+1)).

This counts multisets, not ordered schedules. Equal vectors at different boundaries can only make the upper bound looser. The argument holds for every valid floor word, with no block restriction. Setting x=(n+1)/c yields exactly `x≤log₂c+log₂x+log₂e+2/c`. For x≥4, `log₂x≤x/2`; for x<4 there is already a constant bound. This establishes `n=O(c log c)`. Substitution gives `n≤c log₂c+c log₂log₂c+O(c)`, in particular the upper estimate claimed in the proof. Together with the explicit lower bound it proves the full limit, not only a liminf.

A fully explicit independent coarse upper estimate is also available: with L=log₂c and y=n/c, the same count gives `y≤L+3+log₂(y+1)`. For y≥6, `log₂(y+1)≤y/2`; hence y≤2L+6, also true when y<6. Substituting this and `2L+7≤9L` gives

    N(c)≤c log₂c+c log₂log₂c+7c,  c≥2.

For an optional all-c lower estimate, choosing D=floor(log₂c) still works for c≥2. Then `b≤D+1` and `Db≤D(D+1)≤2^(D+1)≤2c`, so the same floor calculation gives `N(c)≥c log₂c−c log₂log₂c−4c`. The package's sharper `−3c` bound on c≥16 is valid and sufficient; this optional variant is not needed for acceptance.
