# Encoded row-stock dispatch for current compiler occurrences

This package supplies a source-bound physical refinement of the row/occurrence
interface in #6878. Fixed local transition tables split a complete encoded
field into any fixed final number of roles, produce row and stock quotients,
update ordinary child geometry, and reassemble every public output in its
original parent row order. A finite source binder emits charged coordinate
routes at actual compiler occurrence and elementary-axis boundaries.

The selected #6030 result stays conditional, with
`kappa=781451/250000000=0.003125804`. All five assumptions remain. The written
theorem quantifies over every admissible runtime size for a fixed finite
template. Tests provide finite evidence for that scoped implication, not a
numerical multiplier or full assumption admission.

## What changes

The retained literal parking caller handles two roles with a supplied row
guide. Earlier physical padding already provides a linear binary decoder,
and an older complete recursive controller exists. This package uses those
facts to resolve a narrower current-source boundary:

* General fixed divisor `g`, exact quotient headers, inverse complete-row
  order and full product-of-live-divisors stock. Neither maximum factors nor
  nominal field counts replace the actual reservation invariant.
* Physical header production for `e=N*f+r`, child `e'=f`, its complete remainder
  span and actual `f<=t` phase cutoff. Preserved root geometry is separate from
  the decreasing ordinary active width.
* Distinct matched compiler fields and ordinary row children. Existing matched
  owners are never repartitioned. Final rank-one children alone consume the
  final uniform width factor.
* Complete coordinate permutations, complements and inverse returns bound to
  emitted physical owner IDs. Nonzero elementary axes receive explicit prefix
  routes. Every transposition costs three selected XOR records each way.
* Canonical numeric-zero row padding in the actual three-bit symbol encoding.
  Component delimiters survive; raw zero bytes do not substitute for numeric
  zero rows.

Within-row starts remain fixed after arbitrary row division. `entry_start`,
`active_start` and `back_start` are within-row coordinates, with root `q0*K`
subtracted once. `q0` is not recomputed from a non-power-of-two quotient. Full
front/back fields, every spectator plane and every encoded record stay present.

## Concrete evidence

The core suite covers 160 split/merge cases over divisors 1, 2, 3, 5, multiple outer
prefixes, row widths, nonbinary quotients and translated origins. Canonical
pattern padding covers 360 binary-pattern cases and rejects stock larger than root rows and
malformed raw-zero replacements. Geometry checks cover 221 extent calculations,
48 child updates with long integers, 12 root updates and 213 cutoff decisions.

Actual source-generated uniform programs of ranks 3–8 are routed and checked
at multiplicities 1, 2, 3. At rank 8, 235 source events become 859 events, including
624 charged selected XOR records. Its 28 paid sites and owners are unchanged;
four private-field borrow occurrences remain visible. A separate coordinate
oracle applies XORs to GF(2) masks and checks controls, selected columns,
complete complements and inverse returns. The raw compiler-control fixture
is not advertised as a Gaussian operator identity.

Physical-alphabet tests use component-delimited Gaussian records with
divisors 2, 3, 5, 7 and child row count 3. They copy up to 16,128 physical bits,
perform a known rowwise transformation, and return it to the correct parent
rows. A wrong-composition control casts already matched fields `00`,`11` to
one packet and obtains `01`,`01`: all nominal sizes survive while owners mix.
The typed entry rejects that cast. Actual omitted-axis-route, missing-inverse,
wrong-owner and missing-child-geometry mutants are detected.

The frozen owned lifecycle is also joined to the live row service. A width-six
source-generated program makes 72 ordinary children and 512 leaves through
two stock divisions per run. A separate rank-two fixture executes the encoded
ordinary width change `6 -> 3` and its actual cutoff through a physical stack.
Both match a separate value interpreter and run twice without increasing
retained capacity. Native/coordinate services in these integration fixtures
are explicitly identities, with a finite value-rotation leaf. They establish
ABI composition, while the separate route oracle checks coordinate meaning;
they do not admit Gaussian endpoints or selected compact-domain parameters.

The lifecycle supplier is frozen from the publicly accessible

prepare/split/merge charge is `2^16*(N+g+1)*(V+E+1)`.

scan or hidden depth pass occurs. Root canonical-pattern padding costs at most
`4096*(V_root+1)`, plus the zero-row producer and numerical callee. Every added
coordinate service, private operation, bridge, suspension, remainder, leaf,
native primitive and root producer is charged in the complete invoice.

Backing uses historical maxima for each fixed work port and the actual
continuation inventory. Erasure does not shrink old capacity. Under retained
current-volume and compact contracts, the favorable selected implication
