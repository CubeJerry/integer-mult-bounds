# Selected native generic MOVE preflight

See [`PREFLIGHT.md`](PREFLIGHT.md) for the bounded source audit, rank and
monomial census, predecessor overlap, and proceed/stop gate. [`CENSUS.json`](CENSUS.json)
is regenerated by [`build_census.py`](build_census.py) from the pinned source
object. [`SOURCES.json`](SOURCES.json) records canonical source pins and the
rank-1/rank-2 predecessor bindings.

This is a preflight for a possible literal source-specific join. It does not
implement a generic tape dispatcher, discharge `native_all_columns`, or claim
a full caller tariff.
