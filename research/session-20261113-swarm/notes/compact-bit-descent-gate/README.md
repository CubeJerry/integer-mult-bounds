## Named caller and current binding

Take the earlier-source compact CNOT in notes/compact-control-movement.tex.
Name one shuttle exchanging its complete temporary fields t and b. Their
binary width is

`u=(f-1)G`, `G=4 ceil(log2 p)+6`.

For f=1 the source uses the elementary highest-bit operation and no
zero-width interchange. For f>=2, u>=1. Its shape is

`[P] x [2^u] x [J] x [2^u] x [B]`, `V=P J B 2^(2u)`.

P,J,B include every intervening/outer spectator and raw payload bit. Both
exchanged fields are arbitrary complete ranges. The compact construction
uses at most four such interchanges for an earlier source, twelve for a
later source, and respectively four/ten controlled rotations. A rotation
is the retained split/merge plus finite arithmetic; it introduces no
recursive interchange except the explicitly named shuttles.

  completed all-size, arbitrary nonbinary spectator-cardinality, internal

  final high-part ordinary exchanges.

## Dimensions, precision, volume and stock at each edge

role count B_j, and all compiled matrices/owners. Let

`W0_j=B_j |GL_(N_B)(F_(q_j))|`,
`H_j(w)=q_j^(N_B^2(w-1))`, `W_j(w)=W0_j H_j(w)`.

Here w is an **address atom's radix-q precision**. It is not the complex
coefficient component width. BIT intermediate operations may act on
arbitrary encoding bits; completed permutations return those bits exactly.
The complex common grid/width remains unchanged as payload. All generated
local-ring arithmetic and weights are exact, with ancestry descriptors;

## One decreasing measure

Order tuples of natural numbers lexicographically. Assign

```
mu(compact caller) = (3,0,0),
mu(Oj(e))         = (j,2,0),       j=1,2,
mu(Fj(n,w,A))     = (j,1,n),       j=1,2,
mu(O0)           = (0,0,0).       terminal completed premise
```

The named compact call decreases the first coordinate. Ordinary-to-weighted
body calls decrease the second, regardless of e,n,w or numeric padding.
Same-stage weighted children preserve the first two coordinates and satisfy
`1<=n'<=floor(n/N_B)<n`, since N_B>=2 and n>=N_B. Atom, transport, high-part
and bounded-fallback calls decrease j; their argument width need not be
smaller. Finite native words and bounded loops make only finitely many
calls per node. Ordered-affine arithmetic is an independently terminating
finite integer algorithm under the retained primitive contract. Thus no
infinite chain is possible in this dependency graph.

This is a mutual/stratified induction, relative to O0. It is not induction
on coefficient precision, total tape volume, f or fG. In particular f=2
gives u=G, which grows unboundedly with p; even the intermediate atom count
can eventually exceed the original f for fixed N_B. That defeats a naive
width-only proof, not the lexicographic proof. The independent old backend
can also use a different prime; the <4 pair padding and its own <q_old^2
radix conversion are finite factors at only two named bootstrap levels.

## Stock descent and actual call volume

The current application reserve is

`D=2+ceil(log_(N_B)(max(1,ceil(e/w))))`,
`S_j(e,w)=W_j(w)^D S_old`.

For an internal atom count n, put L(n)=ceil(log_(N_B)(max(1,n))). If
`1<=n'<=floor(n/N_B)` and n>=N_B, then `L(n')<=L(n)-1`: from
n<=N_B^L obtain n'<=N_B^(L-1). The root n<=ceil(e/w) therefore has
enough powers of W_j(w) for every generated child. The extra two powers
are conservative; the argument does not treat them as two fixed recursion
levels. All ancestor high fields stay complete and fixed at child return.

The distinction `V_parent/W0_j`, rather than `V_parent/W_j(w)`, matters:
the whole high matrix is retained in one batch. Its cardinality is not
cancelled by deleting data. It cancels in the normalized moment because
each fixed low-type operation acts on its whole high packet, while its
N_B^2(w-1) digits are still charged in fresh stock. This is explicit in
three-stage-cover-bit and the selected recursive-closure proof. Fixed
helper copies and suspended parents are additional owned physical storage,
not productive inputs or free erased history.

For fixed templates and primes, log_q S_j=O_fixed(w log e), so k/e tends
to zero at rho=1/250<1. Freeze a cutoff beyond which k<e/2 and every
other retained requirement holds, before defining the next stage. Smaller
widths use the predecessor. Its inner borrowing does not require a fresh
external stock multiplication: it restores its current argument chunks
and fixes the entire outer ROW before returning. These are completed API
premises, not consequences of the descent inequality.

`V[e^(1-rho)+e^((1-rho)(1-covered)+rho(1-previous))+e^rho log e]`,
