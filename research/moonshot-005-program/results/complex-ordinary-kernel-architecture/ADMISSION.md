## Current constructive interface

Let `a=A^(tensor V)`, `D=16^V`, `T_s=SWAP_cd`, and
`T=(I+T_s^(tensor V))/2`. Literal identities give

```
A^(-1) T_s A = SWAP_ad,
A^(-2) T_s A^2 = SWAP_ab.
```

For the actual first-column choice
`C[:,0]=(P T, J(I-P)T, I-T)^T`, an explicit ordinary output unit H gives

```
H K   = (a^2 R1plus,0,0)^T,
H K a = (a^3 R2plus,0,0)^T,
R1minus=(I-SWAP_ad^(tensor V))/2,
R2minus=(I-SWAP_ab^(tensor V))/2.
```

Thus `K X=0 iff X=R1minus X` and `K a X=0 iff X=R2minus X` for every
operator column X. These are genuine ordinary kernel interfaces at every
positive width. Their ranks are exactly `(D-8^V)/2`; the source rank is
`(D+8^V)/2`, not D/2. The aligned quartic column is
`-(a^4+B2)/2`, with B2 a literal Gaussian-rank2 unitary. Each Gaussian class
component has full rank D even though their sum has smaller rank.

The active-swap obstruction uses forward conjugates that are ordinary.
