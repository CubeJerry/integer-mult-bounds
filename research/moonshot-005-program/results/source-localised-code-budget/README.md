A rational source-bound certificate proves that every one-stage linear code
with one original donor cochart and one original receiver cochart per packet,
and with every packet transport leg newly paid,
costs at least98.992356 additional moment/native at exponent199/200. This is
strictly above the entire conditional H4 allowance, before any reverse duty.
The sharp weighted clique-cover special case costs97+2^(199/200).

hybrid paid/funded transit, multi-station packet and changed-common-response

packet transit. This is a scoped
negative result and supplies no new κ.

Run from any directory, using the permanent programme checkout as source:

```sh
python3 -B verify.py --repo /path/to/integer-mult-bounds --output RESULT.json
python3 -O -B verify.py --repo /path/to/integer-mult-bounds --output RESULT-OPTIMIZED.json
```

The verifier uses only Python's standard library and writes only the requested
output. It authenticates immutable sources and reviewed routing payloads,
reconstructs original route cocharts, proves the74 dual sets acyclic, verifies
