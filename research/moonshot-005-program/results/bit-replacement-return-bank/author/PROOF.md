# The minimum return bank is the rank of the complete fitting

**Conditional physical bridge, exact native algebraic controls, and a sharper
near-minimum seed inequality. No new κ.** The construction below applies to an
already realized balanced proper transfer B. It does not supply that missing
transfer. It replaces the fixed canonical return bank and therefore has a
different contract from the retained-canonical quotient repair theorem.

## 1. Fixed proper programme, freely chosen return bank

Let F be a finite field of characteristic two, b a positive field-bank width,
and n=111b. Fix an actual balanced two-wave programme whose restored X owners
are at Hub before the original Y owners leave ground. Its unchanged late word
has the all-input endpoint map

    z -> Gz+Bx,

where G is invertible. B contains all proper X contributions, including genuine
late line taps and retained early snapshots. Proper containment gives B_ij=0
at every nonforeign pair, in particular B_ii=0. All original inputs are
independent and arbitrary. Remove the old canonical formation, descent and
ground preload, while retaining the proper stages, source caches, restoration
and public routes. Define

    A=I_n+B,          q=rank_F A.                       (1)

**Theorem 1.** Exactly q F-symbols of one-way X-dependent information from Hub
to ground are necessary and sufficient to complete y_i+x_i using this fixed
proper programme. Necessity allows deterministic nonlinear messages and
nonlinear ground preloads. Sufficiency is a fixed linear whole-record word,
with all new owners, movement and ordinary operations paid below.

**Necessity.** If the ground receives a transcript d(x), correctness forces

    G preload(y,d(x)) + Bx = y+x.

At y=0 the transcript must determine Ax, which takes exactly |F|^q values.
A transcript of h F-symbols has at most |F|^h values, so h>=q. Ground must
not have additional uncounted X-dependent information; the proper word and G
remain fixed. These are the same separation conditions as the retained-bank
repair theorem, with no preexisting canonical information supplied for free.

**Sufficiency.** Factor A=L R with R a q-by-n full-row-rank matrix and L an
n-by-q matrix. After restoring every original X at Hub, form Rx in q new owned
field records and MOVE them from Hub to ground. Preload the genuine Y owners
with

    z=G^{-1}(y+L(Rx)).                                 (2)

Retire the new records after their last read using charged dirty CLEARs.
The original late word now produces Gz+Bx=y+(A+B)x=y+x on every original X
and arbitrary Y. No original holder is replaced by a synthetic public bank.
The only new transport is the explicitly charged return bank.

Over GF(2^w), this bank has qw actual binary records. Tensoring the fixed
finite binary word with every positive body identity preserves the result.
The lower bound also scales: an arbitrary binary transcript of body width V
must carry at least qwV bits on this fixed-code interface. No field extension
or unused coordinate normalization makes the return cost disappear.

## 2. Native fitting rank, gauge freedom, and the relation to retained repair

A has identity diagonal blocks and zeros at every native noncontact. It is
therefore a fitting on the authenticated 111-role graph. The retained native
rank theorem gives

    q>=9b.                                             (3)

Write h=q-9b. The saturated-star rigidity theorem proves that h=0 lies in
the canonical **vertex-gauge orbit**. It does not force the literal retained
canonical row space in the original labels. The equality orbit is already
captured by the endpoint-gauge/cycle criterion and is not a new algebraic
escape. The meaningful enlarged target here is an actual proper word with
small positive h, or an actual equality-case word.

If H is the retained canonical row basis, its fixed-bank repair count is

    r=rank([H;A])-9b.

By (3),

    0<=h<=r,               r-h=9b-dim(row H intersect row A).    (4)

Thus h and r agree exactly when row H is contained in row A. Retaining H
can cost more for a fixed proper B when the useful return space is tilted
away from H. Equation (4) is exact, including noncommuting array blocks.
It does not prove that the gap survives every allowed change of source or
receiver basis. Such changes alter the physical proper transfer and must
be compiled and assessed as their own candidates.

Once the return bank changes, the old proof forcing every B_ij=I or even
every foreign B_ij invertible no longer applies. Higher-rank fittings can
have singular foreign blocks. Their arbitrary-input source correctness
must be checked through (1)-(2), not through the retained canonical
normalization theorem's obsolete premise.

## 3. Full ordinary and movement charges

Put M=111bw and C=qw in actual binary records. A direct implementation of
the replacement protocol has the following charges, additional to the
unchanged proper stages and their restoration/caches:

| Return-bank operation | Count or upper bound |
| --- | ---: |
| INIT at Hub | C |
| ADD to form the dense binary matrix Rx | MC |
| MOVE from Hub to ground, gap eight | C |
| In-place binary implementation of G^{-1} on original Y | M^2+3M ADD |
| ADD from return records to genuine Y, using G^{-1}L | MC |
| Charged dirty CLEAR at ground | C |
| Additional simultaneous return owners | C |

The two dense matrix products have arbitrary binary coefficients, so the
old 111C canonical formation bound cannot be reused for them. Each matrix
entry one is one co-located ADD. Gaussian elimination and three-ADD swaps
implement the invertible ground matrix without spare records. All code and
coefficients are fixed finite data, expanded into binary whole-record maps;
no field multiplication oracle or free matrix operation is assumed.

For comparison with the retained seventy-coordinate accounting, let
C0=9bw. Its complete ADD upper bound was17M^2+50M+111C0. Since deleting its
old return protocol cannot increase the proper-stage work, a deliberately
conservative complete replacement upper bound is

    ADD <=18M^2+53M+111C0+2MC.                          (5)

This overcounts the old ground work rather than relying on an unaudited
cancellation of ordinary terms. The actual source/caches are unchanged,
so INIT and charged dirty CLEAR are each bounded by5M+C, and the retained
public-plus-auxiliary peak bound becomes7M+C. These remain finite word
implementation bounds. Program generation, storage, precision, the general
compiler/erasure foundations and the full recursive caller are not thereby
admitted.

The exact normalized movement becomes

    Q_h = (4451/8)[1] + (7213/16)[2] +24[4]+(9+h/b)[8].  (6)

Here [a]=a^(199/200). Every field lane and binary extension copy stays
charged. The same rational interval comparison as the retained-ground
repair package gives, at b=5760,

    h < 202.329744960032041975945569... .                (7)

Thus the strict limiting movement screen is h<=202. The corresponding

## 4. A genuine noncanonical near-minimum target on the native mask

The following construction shows that near-minimum fitting targets are
nonempty and need not have the literal canonical return space. It is an
algebraic control, **not** a balanced physical-network realization.

Take b=1, K=I+O, and any orthogonal native pair a,b. For a field element
alpha!=0 define

    Delta=alpha O[:,a] e_a^T + alpha e_a e_b^T,
    B=O+Delta,
    A=I+B.

The two modified columns remain supported only on allowed foreign entries.
The diagonal is unchanged. If alpha!=1, every foreign entry of B is
nonzero: affected entries are1+alpha and all others are1. The construction
also exists over F2 with alpha=1, where it deliberately has some zero
foreign entries, which the replacement interface permits.

Let D=I+alpha e_a e_a^T. Direct algebra gives

    A=K D + alpha e_a(e_a+e_b)^T.                      (8)

The authenticated canonical code has no nonzero vector supported on
{a,b}: a common native neighbor exists, and restriction outside its
foreign set is injective. The same fact excludes e_a from col K.
Deleting column a from K leaves rank nine, as follows from the identical
support argument on its symmetric column code. Hence KD has rank nine
for every alpha, including alpha=1. Also e_a is outside its column space,
and (e_a+e_b)^T is outside its row space. For alpha!=1 the latter follows
by multiplying by D^{-1} and using the two-coordinate support fact; for
alpha=1 every row of KD is zero in column a, while e_a+e_b is not.

The rank-one update in (8) therefore has rank exactly10. Moreover
row(H)+row(Delta)=row(H)+span(e_a,e_b), of dimension11: the two columns
O[:,a] and e_a are independent and their sum K[:,a] is canonical.
Thus

    rank A=10,       h=1,       r=2.                   (9)

Putting this scalar construction on h selected internal lanes and the
canonical construction on all other lanes gives

    rank A=9b+h,         retained quotient rank=2h.    (10)

Avoiding the first seventy lanes preserves those common corrected rows.
For alpha!=1 every foreign block is a diagonal invertible matrix. These
are deliberately correlated, nonflat endpoint targets with a quantitative
rank budget, not generic independent foreign matrices.

There is a useful limitation: when alpha!=1, a donor-column rescaling
turns this particular example into a rank-one proper perturbation of O.
It therefore does not prove a gap after optimizing every allowed endpoint
gauge. It proves (4) can be strict for a fixed proper code, and gives an
explicit native target for testing a physical factorization. Over the
scalar binary field no nontrivial scalar gauge is available; the alpha=1
control still has the exact ranks in (9), with its singular-block scope
explicit.

## 5. A sharp improvement of the native seed's LR rank-excess bound

Use the retained35-role star seed: eight point roles and27 edge roles,
the edges of K8 except one. Two points have degree six; the other six have
degree seven. For a fitting of total native rank9V+h, the seed's rank is
at most9V+h and at least9V. In its normalized point-frame factorization,
retain the inherited quantities g_e(a), G_a and S_e. The credited LR
inequality gives for every incident pair(a,e={a,b})

    G_a <= h +2(g_e(a)+g_e(b)),

and `rank(I+S_e)<=g_e(a)+g_e(b)`. Using the global h only weakens the
inequality if the seed has smaller rank excess.

Let a be the average g at a degree-six endpoint of a cross edge, b the
average g at the degree-seven endpoint of those12 cross edges, and c the
average g over the30 endpoints of the15 high-to-high edges. Averaging the
same LR inequality over those three directed incidence types gives

    4a-2b <= h,
    5c-2a <= h,
    2b+c  <= h.                                       (11)

No symmetry of the actual matrix is assumed: these are averages of its
actual nonnegative ranks. Multiplying the three inequalities by
54/11,42/11,120/11 respectively and adding gives

    sum_(a,e) g_e(a)=12a+12b+30c <=(216/11)h.

Consequently the native seed satisfies the stronger bound

    sum_e rank(I+S_e) <= floor(216h/11).                (12)

This improves the retained27h bound without changing its scope. The
constant216/11 is optimal for the LR inequalities alone: the nonnegative
real values

    a=9h/22,   b=7h/22,   c=4h/11

saturate all three inequalities and the objective. This is an exact
linear-inequality sharpness control, not a claim of a matrix realization.

At V=5760 and h<=202, the sum in (12) is at most3966. In a fixed choice
of the edge coordinate labels, the common kernel of the27 operators
I+S_e therefore has dimension at least1794. That common kernel need not
be invariant under the other factors. No canonical direct summand,
global near-gauge theorem, or inexpensive transport is inferred from it.

## 6. Verification and next construction

The separate exact checker reconstructs the native graph and verifies
the two-column construction over F2 and GF(4), all noncontact/diagonal
conditions, every foreign invertibility assertion, q=10 and r=2. It
checks a complete small fixed-code return-bank identity with arbitrary
original X and Y, and rejects an omitted return symbol and a missing
G^{-1}. It also checks (11)-(12) by rational dual arithmetic and records
the LR-relaxation equality control.

The next construction is a physical balanced proper code with
`rank(I+B)<=9b+202` at b=5760, or the corresponding strict scaled ratio.
It may use singular foreign blocks if the replacement bank compensates
them. A useful first target is to realize one correlated nonflat native
fitting on a genuine overlapping source/receiver fragment, then preserve
its rank bound through the same-original-donor gluing and later routes.
The explicit target in Section4 is not a claimed solution of that task.
