# An explicit noncanonical fifteen-class fitting for the q8 source problem

**Exact algebraic target and scoped necessary source conditions. No physical source is constructed.** This is a candidate historical code for the programme's existing eight-packet task, not an additional research branch or a claimed supplier. It follows the binary-four obstruction by supplying an actual fitting far from the canonical code that passes the coarse arrival support screen.

## The actual partition

Normalize the pinned111 source root lines to squared norm4 and first nonzero coordinate positive. They are the8 coordinate roots2e_i and103 sign vectors on14 weight-four supports. The14 supports are closed under complement and hence form7 complementary pairs (S,S^c).

For a four-support S, partition its8 positive-line sign representatives by parity of the number of negative entries. Each parity set has4 vectors. Two distinct representatives of equal parity differ in exactly two of their last three signs, hence have dot product4-2*2=0. Pair each parity set with the same-parity set on the complementary support S^c. Disjoint supports are orthogonal. This gives two orthogonal bases of8 roots per complementary pair, plus the coordinate basis:15 disjoint bases of the full120-root completion.

Restricting these classes to the actual111 roots gives15 nonempty mutually orthogonal classes of sizes

    8,7,7,8,7,8,8,8,7,8,8,5,8,8,6.

The checker records every actual source index and verifies all pairwise rational dot products. It uses only the pinned native bytes and does not choose a fitted floating tolerance. Nine classes are still full8-dimensional bases; four have7 roots, one has5 and one has6.

## A complete fitting, not a complete source

Let H be the15-by111 class-indicator matrix, and D the111-by15 membership matrix. Set A=D H; equivalently A_ij=1 exactly when i and j lie in the same class. This is a fitting over every value field: A_ii=1, and any off-diagonal nonzero is a genuine orthogonal foreign contact. Every class is nonempty and supports are disjoint, so rank(H)=rank(DH)=15 over every field. The exact111-row fitting is thus established by the partition and elementary block-J rank argument.

Each foreign row has at most7 entries. The coarse proxy ell_i=1[support>36]+1[support>52] is zero at every row. This demonstrates that the programme's algebraic arrival constraints leave concrete noncanonical targets available; it does not show those local corrections are physically generated.

A finer geometric warning is already visible. For each row in a full8-root class, its7 foreign roots are independent and span the whole terminal facet. No ONE proper subspace can carry all seven, so the refined arrival argument requires at least one additional source/packet arrival beyond that row's own Y predecessor. There are72 such rows. Two proper subspaces suffice to cover each seven-root set by a6+1 split, purely as geometry. The other39 rows have foreign rank at most6. Thus the exact per-row support-cover floor for this target is72 additional arrivals, still below the optimistic111+8 budget. Neither geometric coverage nor the coarse zero proxy supplies actual cache contents, compatible paths or chronology.

## Exact relation to the canonical binary code

Over F2 let C be the canonical nine-code of the actual source, with K_ii=1 and K_ij=1 at orthogonal foreign contacts. Exact binary elimination gives

    dim row(A)=15,  dim C=9,  dim(row(A)+C)=19,

A separate exhaustive enumeration of all512 codewords of C finds exactly32 that are constant on each class; these are precisely C intersect row(A). Five explicit independent intersection words are saved. This gives a second exact certificate for the intersection5 and quotient10. The admitted historical-mode count gives rank(G_x)<=8+sum_C nu_C, so at least7 actual proper-cell kernel dimensions are necessary in the original no-Y-feedback model. The new Y-nuisance normalization, if independently admitted, supplies the same conclusion with cocharted Y feedback. These are actual historical coordinates with image/chronology constraints; they are not free newly available observations.

The desired physical envelope remains q8 with the specified unit-refined profile, whose complete movement accounting was already established conditionally. No additional price improvement is claimed. A realization must form, retain, decode and restore these fifteen code directions through those eight actual trajectories and the original ascending fields, within every endpoint/ownership/ordinary/precision cost.
