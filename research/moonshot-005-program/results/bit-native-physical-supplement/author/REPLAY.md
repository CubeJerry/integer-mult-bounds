# Native physical continuation

From the checkout root use Python 3, NumPy and a C compiler.

    python -B research/moonshot-005-program/results/bit-native-physical-supplement/author/check.py --repo . --work /tmp/native-supplement --out /tmp/native-supplement-receipt

The main physical witness is the two-star word in `bit-global-two-star-target`. The `stars` selector independently reconstructs the true source taps, verifies the whole star and leaf matrices and checks its exact primitive receipt against the author's compiler. The `bilateral` selector verifies the common predecessor, every actual proper Schur complement, all costs and a large disjoint native minor. The `profile` selector verifies the separate 3,720-field synchronized profile. The `frozen` selector checks the complete native original-target quotient obstruction at all 6,470 pairs. Pass one or more names with `--select`.

`--prior-work` can point to the generated working directory of `bit-native-physical-replay/author/check.py`. The independent native matrix and gauge hashes are checked before their use. The full native rim rank has a separate `--full-rim` option together with `--select bilateral`. Temporary working space holds the regenerated large coefficient arrays. Only source programs, explicit parameter data and compact receipts are required in the checkout.

The final two-star and synchronized profile words use different endpoint operators. A third result freezes the pure endpoint operators as a hypothesis for the negative theorem. Their costs and kernel dimensions are separate.
