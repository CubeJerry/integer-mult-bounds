# Independent review of deferred terminal caches

**PASS: the rescheduling lemma and the literal one-receiver four-copy
control are sound within their stated source class.** The independent
interpreter checks all 888 original input columns, every chart, the exact
current value at every cache capture, the deferred Y chronology, the real
canonical formation and delivery, all original-X restoration, and every
owner retirement. It imports no code from the author's builder.

The useful positive result is that a compatible X-only source circuit can
finish and restore its public X records before the Y phase begins. The
construction retains its original receiver contributions in stationary
caches, including contributions available only at terminal facets. The
package constructs this mechanism for receiver 3 in four physical copies.
It does not construct a compatible source for all 111 receivers.

## 1. Why the abstract rescheduling is valid

The source restriction is essential: every change of X must depend only on
the X-side computation, and the explicit source word must restore the raw
original X records at Hub. Delete the original Y operations and execute the
X subsequence in its original order. At each removed X-to-Y read, initialize
a stationary owner at the actual common chart and copy the current X value
into it. Because the X computation does not read Y, the current source value
is exactly what the original read would have seen.

After the X computation and its restoration finish, execute the original
Y subsequence in its original order. Replace each deleted cross read by a
read of its stored owner. The Y record then visits exactly its original
charts, and it sees exactly the original sequence of values. This proves
both legality and the full arbitrary-Y map, without requiring a rank or
surjectivity claim about hypothetical held coordinates.

For the uncompressed construction there is one extra INIT, one extra capture
ADD and one dirty CLEAR per original cross read. The original cross ADD is
retained as a cache-to-Y read. Public movement is unchanged, and each owner
is stationary. These ordinary costs cannot be erased merely because cache
movement is zero.

In the native setting all Ys initially occupy ground. If the original
Y-only linear map is the identity and its source contribution is B X,
preloading K X at ground changes the output to Y+K X+B X. When K+B=I this
is the desired correction. Raw restored X records at Hub can form a real
basis of K. Every such formation, descent, preload read, INIT and CLEAR is
additional cost. The actual control includes these operations explicitly.

The lemma does not apply to a proposed source that needs Y values to form
its X packets. It also does not install caches retroactively after a public
X has already passed the chart where its needed contribution was available.
The earlier chronology changes.

## 5. Scope for subsequent work

The lemma removes a chronological obstruction for a future compatible global
X-only network. It does not prove that individually feasible receiver circuits
can share the same X routes, aggregation and inverse operations. A complete
global construction must still produce every simultaneous receiver channel,
retain the needed actual terminal values, restore the public sources, and
invoice all caches and local operations.

This construction also has a different earlier history from the frozen
scalar/F4/F8 current cuts. Those cuts do not contain these terminal captures.
The current-cut formation gate therefore does not prohibit this changed
source, and the new rescheduling lemma does not defeat that gate by treating
missing caches as if they already existed.

No complete supplier, full native caller, new kappa, or foundational discharge
is established. The author's source-specific scope and partial completion
claims are correctly stated.
