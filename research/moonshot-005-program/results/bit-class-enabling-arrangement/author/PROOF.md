## 1. Equality constraints over every field

Let U be the native fifteen-class indicator code and Local(F_i) the scalar
coordinate space supported on original root lines inside receiver facet F_i.
For each class c define

    P_c = intersection_(i in c) [U+Local(F_i)].

For v outside U, W=U+span(v) has nonzero local intersection at EVERY receiver
in c exactly when v belongs to P_c. This is the meaning of 'enables a whole
class': an algebraic local-direction condition, not availability/completion.

Let N_i be its own column together with all real-nonorthogonal foreign
columns. Then v belongs to U+Local(F_i) iff its values are constant on each
N_i intersect a, for every source class a. Subtract the appropriate constant
on each class to obtain the local remainder. Every N_i intersects every
class, which also proves U intersect Local(F_i)=0.

For P_c impose these equalities for all i in c. Within each source class
join two indices when a constraint equates them. P_c is precisely the space
of functions constant on the resulting connected components. Every
component has one free value over ANY field. The finite partitions certify
an arbitrary-field theorem, not a coefficient search.

## 2. The exact arrangement

Write V_a=F^a/span(1_a). The ambient quotient by U is the direct sum of these
fifteen spaces. In the own class c the constraints leave all V_c; in each
other class a there are exactly TWO connected components. Their indicator
modulo constants spans a line D_(a,c). Thus

    P_c/U = V_c direct-sum sum_(a!=c) D_(a,c),
    dim(P_c/U)=|c|+13.

Dimensions are18 through21. For distinct c,d there is exactly one further
class e such that D_(e,c)=D_(e,d), giving

    (P_c intersect P_d)/U
      = D_(c,d) direct-sum D_(d,c) direct-sum D_(e,c).

This three-dimensional space is supported on class blocks {c,d,e} and lies
in P_e/U. Intersecting with any fourth P_f gives zero modulo U. All105 pairs
and455 triples are checked:35 triples have quotient dimension3,420 have0.

Hence P_c/U are NOT pairwise disjoint. A vector outside U belongs to zero,
one, or three of the P_c, never more. Membership in two forces membership
in the third class on their line, and forbids every class off that line.

## 4. Higher-dimensional extensions require receiverwise coverage

For h>1, all receivers of a class may be enabled by DIFFERENT directions
of E. There need not be one vector in E outside U belonging to P_c.
Counting P_c memberships of the2^h-1 binary directions is not a bound on
whole classes enabled by U+E.

The native counterexample E=span(x0,x1) has rank17 after adding U. Each of
x0,x1,x0+x1 belongs only to P_coordinate. Yet U+E enables NINE whole
classes, with minimum indices

    0,8,9,14,15,38,39,46,47,

and88 individual receivers. At different receivers a different coordinate
unit is local. The correct interface records each individual space

    E_i={e in E: e belongs to U+Local(F_i)}.

A class is enabled exactly when all its E_i are nonzero. This coverage
counterexample does NOT establish a feasible q8 or q10 source.

## 5. Operator-valued support-of-extension gate

Suppose a historical block space W contains U tensor F^V and is
class-constant outside a set S of classes: on each class a outside S, every
scalar row of W has the same V-coordinate coefficient at all its ports.
Extra directions within S may be arbitrary operators, with no dimension,
tensor or commutativity assumption.

Every source class meets the forbidden set of every receiver. Consequently
any W-row local to a receiver facet vanishes on every class outside S. This
also holds below a receiver facet. Let D be the union of ALL receiver-facet
downsets and Q=sum_(C in D)(W intersect Local(C)). Then Q vanishes outside S.

Use the general quotient first-entry principle on W/Q (proved in the
operator-shortening package). For a receiver in class a, its own input
coordinate differs from u_a by a facet-local row, so the required quotient
projection is u_a modulo Q. The15-|S| outside-class indicators remain
independent modulo Q. Each packet contributes at most V first-entry
coordinates, proving

    q >= 15-|S|.

For E=span(x0,x1), S is only the coordinate class, so q>=14 despite nine
whole classes being algebraically enabled. This independently confirms the
root's proposed quotient gate and generalizes it to arbitrary operator
extensions supported on any specified classes. A q8 code retaining U must
depart from class-constant behaviour in at least seven classes; q<=10
requires at least five. These are support conditions, not sufficient
constructions or dimension-only lower bounds.
