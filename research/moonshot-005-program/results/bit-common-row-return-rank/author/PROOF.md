## 1. What k correct rows imply for a replacement bank

Let O be the pinned111-role native orthogonality matrix, and put
K=I_111+O. Its characteristic-two rank is9. Let B be the complete proper map
of any fixed balanced causal code on b field coordinates per real role.
It vanishes on nonforeign blocks. Assume the same leading-k projection P
satisfies PB_ij=P on all6,470 foreign blocks. Write u=b-k.

Order all correct coordinates first, followed by all remaining coordinates.
Then the map needed from Hub to ground for exact completion is A=I+B, with

    A = [[K tensor I_k,      0],
         [C,          I_111u+B_bad]].                 (1)

No condition on C is imposed. The upper-right zero block follows from the
full-column common-row identity, not merely from a selected diagonal minor.
It follows that

    rank(A) <= 9k+111u = 9b+102u.                     (2)

If the bottom-right block is invertible, equality holds: use its columns to
eliminate C, leaving K tensor I_k in the upper block. All ranks here are over
the same characteristic-two field and multiply by w after binary expansion
over GF(2^w).

The replacement-bank protocol forms a row basis of A at restored Hub, pays one
rank-eight descent per basis field symbol, and preloads the same genuine Y
owners at ground through the inverse of the fixed pure-Y map. Therefore its
additional movement relative to the paid9b-bank baseline is

    ((rank(A)-9b)/b) * 8^(199/200).                  (3)

Its full ordinary and owned-record invoices belong to the separate
replacement-bank theorem. The finite rank bound(2) is not an implementation
of a near-complete proper code.

At b=5,760, the strict limiting movement ceiling is

    rank(A)-9b < 202.329744960032041975945569… .      (4)

Consequently **5,759 common native rows would already be enough for this
movement screen**: u=1 gives an excess of at most102, with first even retained
paired-caller multiplicity m=92 and limiting room at least
0.13790555546685523085585072711897148… . Full coefficient construction and all
ordinary, recursive, precision, ownership and complex-supplier obligations
would still remain.

Two missing rows give only the bound204, which does not certify the screen.
This does not exclude a two-row-defect code with actual excess at most202.
At scaled b=5,760s the same statements use the strict ratio
(rank(A)-9b)/b < (B_infinity-Q_0)/8^(199/200);202 is not a universal integer cap.

## 2. The upper envelope is attained inside the actual seventy-row family

**Theorem.** The same reviewed physical balanced code family used for the
seventy-coordinate result contains a code with all source and foreign blocks
invertible, the same seventy correct rows, and

    rank(I+B)=9*70+111*5690=632220.                  (5)

Thus its replacement bank needs580,380 more field records than the original

### The source affine space is the essential domain

Fix a downstream specialization satisfying the reviewed mixed-flow minors and
both pure-wave invertibility determinants. For each actual donor j, the source
matrices vary over the affine space

    A_j={F_j : T_j F_j=R_j}.

The right side R_j repeats the first-seventy projection. In particular **every
column of R_j after the first70 is zero**. The affine equations act separately
on source input columns. Thus A_j has a point whose last5,690 columns of F_j
are all zero: retain any solution on the first70 columns and set the rest to0.

Choose those points simultaneously for all111 donors. This is only a polynomial
witness. Its early source maps are singular and it is not itself an admitted
physical code. At this witness, however, no bad input coordinate enters any
proper path. Consequently B_bad=0 and

    det(I_631590+B_bad)=1.                           (6)

The determinant in(6) is therefore a nonzero polynomial on the joint affine
space A_1 times ... times A_111. Each proper block is affine-linear in its
donor's source matrix after the downstream specialization has been fixed, so
this determinant has degree at most631,590.

The existing seventy-row theorem proves that each det(E_j), for the early
source block, and each det(B_ij) is a nonzero polynomial on the relevant A_j.
These factors and(6) all live on the same joint affine product. Their product
is nonzero and has total degree at most

    (111+6470)*5760 +111*5690
      =38538150 <2^30.                              (7)

Parameterizing each A_j over the same field and applying the finite-grid
nonzero-polynomial lemma supplies one assignment where all factors are
nonzero. The actual early maps are then invertible, all original X labels can
be restored at Hub, and the already invertible pure-Y map retains arbitrary
original-Y correctness. The proper word, all source visits, all owners and all
movement charges remain the retained ones.

At this actual assignment the bottom-right block in(1) is invertible, so the
rank equality(5) follows. No numerical global coefficient table is asserted.
The existence proof remains a finite exact coefficient-selection construction
in the same sense as its predecessor.

### Optional simultaneous maximal foreign defects

The retained-ground repair theorem additionally proves that every polynomial
det(D_ij-I_5690) is nonzero on the same source affine space, where D_ij is the
lower-right block of B_ij. Those factors have a separate mixed-minor witness
with B_ij=diag(I_70,lambda I_5690), lambda different from0 and1.

They can be included in the joint product above. The resulting total degree is

    38538150 +6470*5690 =75352450 <2^30.             (8)

Thus there is one actual balanced code that simultaneously has maximal

This is an existence result for badly synchronized members of the real source
family. It is not a universal impossibility theorem for that family or for
different interior coefficients. It demonstrates that determinant nonvanishing
alone need not move the construction toward an affordable exact bank.

## 3. Exact finite controls

The checker reconstructs the native O from the authenticated integer root
table and verifies rank(K)=9. It builds small-bank matrices overGF(4) using an
explicit two-bit multiplication representation. On good coordinates each
foreign block is identity; on bad coordinates it is multiplication by omega,
where omega^2+omega+1=0. The checker verifies that I+omega O is invertible on
all111 native roles. Arbitrary deterministic lower-left shear blocks are also
included, so the controls do not silently assume C=0.

Every foreign block is checked invertible, every correct row is checked on all
input columns, and the exact binary rank is checked equal to
2*(9k+111(b-k)). Replacing omega by1 is a negative control: the bad block then
has canonical rank9 rather than111. These fixtures validate the algebraic
envelope and its strictness. They are not claimed to be physical balanced
network assignments.

The actual physical existence claim is proved by the common-affine-space
polynomial argument in section2. Its finite inputs are the already reviewed
mixed minors and the exact degree accounting, not the smallGF(4) fixtures.

## 4. What remains

The rank envelope gives a concrete sufficient endpoint target, but the current
construction fixes70 of5,760 rows, far from5,759. A deliberately correlated
source with rank(I+B) at most9b+202 could be preferable to increasing the count
of common rows; it is not required to attain the envelope in(2). Native source
formation, all H/D/K/F compatibility, body-width compilation, the complete
ordinary and recursive invoice, both strict suppliers and the five foundations
