# Retained records must preserve the raw outputs too

This package proves a sharp algebraic record count for chronological helper
loans with specified common and raw output duties. It extends the programme's
joint restoration interface from common-only recovery to the complete declared
raw target. **No new kappa. No source word or paid transport is supplied.**

For actual differences `T delta=Qq-Hu`, common outputs `Y=Wu+Z delta`, supplied
records `Nu,Rq`, and target `Wu,Dq`, the proof identifies every already known
difference combination in a matrix C. Subject to the explicit raw-feasibility
gate, the exact additional record count is
`rank([C;Z;AG])-rank(C)`, where `D=AQ+BR` and `G=T-Lambda Z`.
For full raw recovery this simplifies to `k-rank(C)`, attained by an optimal
subset of actual difference coordinates. The rank of Z alone can undercount
the records required to preserve all raw inputs. For partial raw targets,
mixed records can outperform retained coordinates.

See [PROOF.md](PROOF.md) and [independent review](review/REVIEW.md) for all
hypotheses, the dependent-common-record extension, sharpness and limits.
The algebra holds over every field. Complex/BIT source matrices, scalar
operations, physical routes and compiler contracts still require admission.
