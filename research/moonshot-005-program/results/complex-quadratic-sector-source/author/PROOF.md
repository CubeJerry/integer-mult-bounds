# An actual quadratic-sector source raises the minimum head rank to two

**Status: proved explicit partial source, awaiting independent review. No new κ.**

Three actual common-body native halves, an ordinary conditional bank
permutation and one short ordinary circuit give an invertible source with
only rank-two and rank-three Clifford components. The cubic component is
nonzero and has one full input-column's physical rank. This is a concrete
use of the half-integral ordinary algebra singled out by the modular
parabolic theorem. It is not three independent Gaussian endpoint jobs.
Its rank-two component is invertible, so a single final native on two of the
three retained roles cannot turn it into three pure rank-three jobs.

## 1. Exact source and quadratic transport

Use the admitted order-fifteen source on head bits a,b,c. To avoid confusing
the axis name with its operator, denote the source head by A:

    A = C_b D_b CZ_ac P,
    P: a->c, b->a, c->b.

Let H=CZ_ac and J=CZ_ab. These are actual ordinary diagonal involutions and

    H A = A J.                                         (1)

Indeed P J P^-1=H, and C_b, D_b and CZ_ac all commute with H. This is an exact
one-column operator identity, retaining its actual scalar phases. For every
integer tensor width V>=1 put a=A^(tensor V), h=H^(tensor V), k=J^(tensor V).
Then h a=a k and h^2=k^2=I literally. Both h and k are ordinary quadratic
phase passes on the full arrays. No additive one-column identity is being
tensored.

The required actual head ranks are

    r(A^2)=2,       r(A^3)=3,
    r(A J A)=2,     r(A^2 J A)=3.                       (2)

The first two are from the admitted C15 source. The latter two follow by the
exact symplectic source calculation authenticated by the checker; A J A=H A²
already proves its rank is two. A³ and A²JA are distinct projective group
elements. Their ranks multiply by V, preserving every tensor phase.

## 2. Two fully explicit ordinary interstages

Define p=(I+h)/2, q=(I-h)/2 and v=(I-k)/2. On three arbitrary independent
roles set

    C_h = [[p,0,q],[0,I,0],[q,0,p]],
    Q_k = [[I,0,I-k],[0,I,0],[I,0,I]].                   (3)

C_h is unitary, C_h²=I. It has the following literal whole-record
implementation on its active roles x,z, with no scratch field:

    x <- x+z;
    z <- -2 z;
    z <- z+x;
    z <- h z;
    z <- z-x;
    z <- -(1/2) z;
    x <- x-z.

The first three operations form the sum/difference matrix
S=[[I,I],[I,-I]]. The last three form S^-1. Thus the circuit is
S^-1 diag(I,h) S = C_h. It charges four field ADDs/subtractions, two
whole-field SCALEs and one actual quadratic phase pass. The 1/2 is an
explicit field-level scalar, never tensor-powered. These ordinary primitive
operations are already in the retained model; no free masked access,
new register, owner, copy or erasure is assumed. All their precision and
compiler services remain charged.

In computational coordinates h has diagonal entries +/-1, so C_h also
has the interpretation of exchanging the two roles exactly where the
quadratic parity sum_j u_(a,j)u_(c,j) is odd. Its physical table contains
zero and one even though its collective group-algebra expansion uses 1/2.
This explains the boundary of the modular integral-coefficient theorem.
The primary source invoice uses the explicit seven-step primitive circuit,
not a presumed free conditional permutation.

Q_k is an ordinary unit with active two-role determinant k. Its actual
in-place implementation on active values x,z is

    x <- x+z;
    z <- k z;
    x <- x-z;
    z <- z+x.

It uses three field ADDs/subtractions and one fixed quadratic phase pass.
It produces x'=x+(I-k)z and z'=x+z. The third role is untouched. Reversing
these four instructions gives its exact inverse. No new Gaussian call,
owner or erasure occurs.

Each h or k phase is generated by the already retained fixed-alphabet
odometer method: the parity changes only at the updated coordinate digits,
whose total number of changes is geometrically bounded by a constant times
the array volume. Phase generation is uniform linear combinatorial work with
O(V) control storage. The actual phase pass, layout/tape traversal and compiler
service remain charged. This does not prove the compiler foundation.

## 3. The assembled word and an all-width formula

Use the actual three-role source notation

    K = [[I,0,a-I],[a,0,-a],[I,I,-I]] = L(a) T,
    L(a)=[[a,I,0],[0,a,0],[0,0,I]].

The source lower native is obtained by globally exchanging the first two
role labels, exactly as in the pinned three-role base. Put

    W = K C_h K Q_k K.                                (4)

This word uses three real native halves. All three inputs x,y,z remain
arbitrary and independent. Let

    w=x+y-z+a z,     b=a k a=h a².

Direct substitution through the five factors, using only (1), gives

    z_out = b z,
    y_out = a² k w,
    x_out = b z + a²(x-z) + a² v w.                    (5)

This is a universal noncommutative algebra calculation with the stated
relations. In particular it is valid for every tensor width, not only the
small widths used in numerical checks. All field-level signs and factors
1/2 remain outside tensor powers.

Separate (5) into the following two matrices:

    W2 = [[a²(I+v), a²v, b-a²(I+v)],
          [a²k,     a²k, -a²k],
          [0,       0,    b]],

    W3 = [[0,0,a² v a],
          [0,0,a² k a],
          [0,0,0]].                                   (6)

Then W=W2+W3. Each coefficient of W2 is a finite combination of actual rank-
two Clifford maps: a² multiplied by ordinary coefficients, or b=h a².
Each nonzero coefficient of W3 is a combination of A³ and A²JA, both rank
three. At every sufficiently large faithful tensor width the direct Gaussian
rank decomposition therefore gives

    pi_0(W)=pi_1(W)=0,   pi_2(W)=W2,   pi_3(W)=W3.

The nonzero lower cubic coefficient a²ka is invertible, so W3 has physical
rank exactly D=8^V, for every positive V. It is a real cubic source channel,
not merely a favourable numerical rank count. The full W is invertible
because every factor in (4) is an actual invertible operation.

## 4. Exact limitation: the quadratic component remains invertible

The bottom-right block b of W2 is invertible. Its upper-left two-by-two
block is

    diag(a²,a²) [[I+v,v],[k,k]].

The second factor has inverse

    [[I,-v k],[-I,(I+v)k]],

as follows by solving its two equations using k²=I. Hence W2 is invertible
for every V. This is stronger than absence of an ordinary left kernel.

Consequently no invertible ordinary row encoding can isolate a nonzero
pure rank-three row of W: such a row would annihilate W2. In particular,
one additional native supported on two roles, with arbitrary ordinary
interstages and outer encodings, cannot complete three pure rank-three jobs
as a *suffix* of this source. The unused native row must already be pure
rank three after the ordinary pre-encoding, which is impossible. The same
argument applies in the reverse direction to an untouched column and a
prefix, using invertibility of W2.

This is a restriction on this fixed intermediate. It does not exclude all
four-native callers, other quadratic-sector words, mixed source orientations,
additional paid queries, changed bodies, or a changed intermediate endpoint.
The mixed source should not be mistaken for a solved (3,2,2) caller.

For a useful normal form, subtract the third output from the first and put
D2=diag(a²,a²,b). Then

    (I-E_02) W = D2 R (I+E_12 a),
    R=[[I+v,v,-I-v],[k,k,-k],[0,0,I]].                  (7)

R is an explicitly invertible ordinary unit. Thus the source contains a
rank-one shear together with three rank-two head factors, but R is between
those factors and the shear. Conjugating it through D2 is not automatically
ordinary. Equation (7) is a possible interface for later composition, not
an invoice credit for four independent services.
