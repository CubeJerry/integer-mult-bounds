## 1. The universal noncommutative extraction lemma

Let a,b,D1,D2 be invertible endomorphisms on any vector space. All products below are ordered; no commutation is assumed. Write U(a)=[[I,a],[0,I]], L(-b)=[[I,0],[-b,I]], and Delta(D)=diag(D,D). Apply chronologically

    F1=Delta(D1)U(a), diag(c,I), F2=Delta(D2)L(-b), U(d).

The unique c making the second output independent of the original second input after F2 is

    c=b^-1 D1 a^-1 D1^-1.

Indeed that input's coefficient is D2(D1-b c D1 a), so invertibility gives exactly this solution. With it, the two outputs after F2 are

    x2=D2 c D1 x + D2 b^-1 D1 y,
    y2=-D2 D1 a^-1 x.

The unique final upper shear that removes x from x2 has

    d=D2 b^-1 D2^-1.

Consequently a signed swap gives the exact independent endpoint

    (D2 D1 a^-1 x, D2 b^-1 D1 y).

This identity holds on arbitrary independent baselines. A finite noncommuting rational-matrix check and wrong-order controls accompany the algebraic proof. Uniqueness is only within the displayed template: one diagonal interstage correction and one final upper shear. It is not a uniqueness theorem for all callers.
