Let L=[L6 L9 L48 L73], K=L W be an anchored forced space, and let M_j collect actual parent off-target outputs on the active old L blocks. Four retained identities force candidate coefficients C_r=S_old(j,r) S_new(j,r)^(-1) W_r. Isolation requires M_j C=0. Since each block change is invertible, every stacked subset of C blocks has the same rank as the corresponding W blocks. Consequently, if N_j spans ker M_j, every block subset A must satisfy rank W_A <= rank (N_j)_A. The checker evaluates every nonempty subset, saves M_j and N_j, and checks all ranks with exact GF(64) arithmetic. Passing these inequalities is not sufficient for a common D, source realization, common target readout, or whole fibre.
