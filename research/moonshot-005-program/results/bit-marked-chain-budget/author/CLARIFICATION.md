# Scalar-extension clarification after independent review

The reviewed PROOF.md bytes remain fixed. In section3, first pad the occurring conic parameters inside a field K' extending the original field. Then choose the pair-annihilator coefficients in a common rational-function extension transcendental over K'. For a K'-vector a, a generic annihilator kills a exactly when a belongs to its fixed pair plane. All choices coexist in that one extension. A row defined over the original field acquires no new exceptional type on extension: a finite type is the ratio of its first two kernel coordinates, already in the original field; the remaining type is infinity.

This makes explicit the interpretation accepted in Worker A's independent review. It does not change the fitting, original value field, paid operations or theorem.
