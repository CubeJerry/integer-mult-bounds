# The optional common-plane source cannot realize the irreducible target

This is a narrow application of the admitted S023 odd native witness,
with its proper-map hypotheses re-established for the S027 target. It
does not contradict either the target's algebraic existence or the new
source-only Hall theorem. **No new kappa.**

## Exact statement

Retain the actual nested native source routes and the source-plane cuts:
an ordinary donor-plane emission has p field symbols, a foreign receiver
sees sixteen planes per tight donor, and it sees fifteen H-to-D ports of
total capacity p at each such plane. The original bank has b=16p>0.
Singleton-exposed donors are excluded from the tight witness below.
These conditions hold in both the original balanced and scaled bank480
atlases used by the programme.

Suppose the proper word, with its independent original Y input set to zero,
has the exact prescribed linear X transfer B*. B* is the S027 irreducible
target: it differs from the native foreign identity blocks only in receiver
row80 and donor column10. All X inputs remain independent. The completion
return bank is separate from this proper word; no extra informative
nonproper path is granted inside it.

Suppose also that every ordinary H uses the same quotient kernel K_H for
all its native donors in their common original-input coordinates. The
quotient labels may differ by bijections, and interior processing may be
arbitrary deterministic. This includes the optional common F_H specialization
of the new two-evaluation source theorem, with its selected linear quotients.

**Theorem.** No such proper implementation of B* exists.

## One unchanged receiver row is enough

Use receiver i=2 and the following retained odd set of27 tight donors:

    S={3,6,7,23,24,27,28,52,53,56,57,66,68,69,71,73,
       75,78,80,97,99,100,102,103,105,108,110}.

It is exactly the receiver2 witness in
`bit-native-plane-asymmetry/author/output/WITNESSES.json.gz`.
Every donor in S is foreign to receiver2 and sees sixteen ordinary source
planes there. Every visible plane meets S in zero or two donors, giving
216 paired planes. The fresh checker verifies all these properties from
the pinned integer root table and rejects deletion of any one donor.

Receiver2 is not the modified row80, and S does not contain the modified
column10. Thus B*_(2,j)=I_b for every j in S, at every target width b=60w.
Fix every other source input to zero. The required proper output at receiver2
is exactly sum_(j in S) X_j. This is an actual restriction of the proper
target, without using a canonical-zero slice or assuming that a changed
return bank is neutralized for free.

Each selected donor's sixteen quotient emissions must jointly recover X_j
and have total dimension b. Their joint map is therefore invertible. The
quotients in the two-evaluation specialization are linear; more generally
the admitted quotient/coset interface gives the same subspace statement
after its bijective output relabellings.

Fix a paired plane H with selected donors j,k. Hold all their other
fifteen visible quotient coordinates fixed. The varying input fibres
have dimension p. Only the p-symbol H cut can carry the change to receiver2.
Since the target increments add, the two fibre direction spaces must be
the same p-dimensional space L_H: their sum has dimension at most p and
contains each of them. This is the ordinary sumset saturation proof,
valid even for nonlinear interior processing.

Let E_(j,H) be donor j's inverse-coordinate projection onto L_H. Its kernel
is K_H and it is identity on L_H. The two donors have the same image and
kernel, so E_(j,H)=E_(k,H). At every selected donor,

    sum_(H visible through j) E_(j,H)=I_b.

Sum these identities over the odd set S. Every incident plane appears
twice with equal maps, hence cancels in characteristic two. The left
side is zero while the right side is I_b, a contradiction.

## Why the scope is consequential and limited

This supplies the missing premise check for applying the old odd witness
to this particular changed-bank target. The witness uses only proper
identity blocks that the two-star perturbation leaves unchanged. Its proof
does not subtract the historical scalar deficit from a repair allowance.
The size, rank and decoding form of the separately paid return are not
needed once the proper B* map is required.

Donor-specific source kernels remain live. The source Hall theorem already
permits that larger class with determinant degree37. Arbitrary donor gauges,
a different proper target that changes the witness blocks, altered source
cuts, or extra informative routes require a fresh analysis. An actual
completed code using a different proper B is not excluded by this result.
