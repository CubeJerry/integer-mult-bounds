# Source regeneration of the 417,028-field native construction

The compact package retains exact fresh-source digests, GF(64) generation scripts and seeds, the author’s original source stream and synthesis logs, the completed exact physical rank and cost receipt, and the independent 16,515,072-coefficient native quotient/fold receipt. Rebuild the assets locally, then run the portable physical verifier.

    python generate.py --repo REPO --out FRESH_ASSETS
    python verify.py --repo REPO --assets FRESH_ASSETS --out FRESH_RECEIPT

The generator performs a complete streamed large-sector native complement reduction, reconstructs the older four gauges, and synthesizes the six real new actuator matrices. It checks every generated array against the original released SHA-256 digest before writing it. Use --cache WORK to retain its intermediate Schur and sensor packets between executions. The earlier four-gauge and marked six-observer packages are prerequisites. The original author run used a source-first computation of the observer arrays and a separate native eight-role quotient for K. Optional --heavy on verify.py rechecks all large native observations independently of the cached assets. The finite numerical and physical result appears in ADMISSION.md.
