# Radial diagonal commutator ranks lie in the same cut cone

**Exact optional corollary; independent review pending.** Let P_g act by permuting the135 Lagrangians. Let D be any diagonal operator, over any field, commuting with the full ordinary parabolic H. Its values are constant on the four H orbits. For each distinct diagonal value a, let S_a be the corresponding H-invariant level set.

The matrix D−P_gDP_g^{-1} is diagonal. Its rank is exactly the number of positions whose two diagonal values differ. Every such position belongs to exactly two symmetric differences S_a symmetric-difference gS_a. Therefore

    rank(D−P_gDP_g^{-1})
      = sum_a (1/2)|S_a symmetric-difference gS_a|
      = sum_a h_{S_a}(g).

This lies in the same nonnegative radial cut cone, regardless of the number or numerical spacing of the diagonal values. The same conclusion holds for nonnegative sums of these commutator-rank functions. Consequently R2<=R1; if D is nonconstant then R1>0, so such a potential cannot detect rank2 at twice the rank1 cost. Commutator rank is subadditive under multiplication by invertible group operators, so these are legitimate candidate length functions; their calibration fails.

The15 equality patterns among the four orbit values can be checked exactly, but the level-set identity is the proof over every value field. This extends the sign-cut failure to arbitrary radial diagonal rank operators in this fixed permutation basis. It does not extend to non-diagonal operators in the H commutant, a different representation, marked-factor mechanisms or arbitrary full-ordinary callers.
