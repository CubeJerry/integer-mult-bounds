## Theorem: nonlinear encoders cannot improve these static finite-field costs

Fix a finite field F_q of characteristic two and positive integer V. The input is x in (F_q^V)^111. Let S be either precisely declared common side-information rowspace, U_j the four fixed bank rowspaces, and K the canonical C9 rowspace. Each bank sends one message

    m_j = f_j(U_j x, Sx)

with at most q^(ell_j) possible values; the function may be arbitrary and nonlinear. A decoder gets Sx and all four messages, and must recover Kx exactly for every x. No new local/raw-point announcements are granted after those messages. The encoder is generously allowed Sx even if it did not physically have it.

Then ell_j >= d_j V, where d_j is the displayed conditional target dimension. Consequently total message length is at least13V or9V field symbols, respectively. The certified linear messages attain these bounds. Thus the exact optimum is unchanged by arbitrary nonlinear bank encoders in this fixed-side-information, direct-canonical interface.

### Proof

Fix j and let T_j = S + sum_(h != j) U_h. The certificate supplies d_j canonical rows k_1,...,k_d and binary input perturbations lambda_1,...,lambda_d with

    T_j lambda_t = 0,
    k_s lambda_t = delta_(s,t).

These identities are checked independently and remain valid in F_q. For arbitrary t_1,...,t_d in F_q^V, choose

    x = sum_t lambda_t tensor t_t.

Every such input has Sx=0 and U_h x=0 for h != j. Hence all other bank messages are constant, including when their encoders depend on Sx. The selected canonical outputs are exactly(t_1,...,t_d). There are q^(d_j V) distinct required output tuples. Exact decoding therefore requires at least that many distinct values of m_j. Its allowed alphabet has at most q^(ell_j) values, so ell_j >= d_j V. Summing the four inequalities gives the stated bounds. The explicit linear witnesses supply the matching upper bounds for all111 canonical rows. This proves the theorem for every finite characteristic-two field and positive V. No finite input experiment is being extrapolated.

## Boundaries that matter

The rank80 model does not receive the83 raw point announcements. The rank88 model receives exactly those points before compression; it does not get later feedback created by the new messages. The theorem targets recovery of the canonical space at a common decoder. A noncanonical receiver-specific fitting code need not satisfy that target. New shared measurements, coupled acquisition across banks, different placements, or paid interactive source processing can change the interface. No movement, erasure, storage, source-restoration or supplier price is inferred from13/9 message dimensions.

The nonlinear extension is stated only for finite fields and bounded message alphabets. Arbitrary maps on infinite sets cannot be bounded by this counting argument. The author's linear rank theorem continues to apply over every characteristic-two field in its stated linear block model.

The dual cut is also a negative control against the tempting claim that a three-dimensional target quotient requires only three global messages: the bank-separated encoder restrictions force nine here. It is not a universal lower bound on all possible continuations.
