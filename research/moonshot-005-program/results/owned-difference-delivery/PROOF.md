full-value linear form

    L_i = value_r - sum_s c_s value_s.

Exact reverse propagation through the original prefix gives

    L_i = R_i h,

with R_i a nonzero rational row on entering helpers only. There is no main-input
coefficient or initially undeclared owned input. `CERTIFICATE.json` records R_i;
the verifier recomputes it independently of the homogeneous forward rows.
The same R_i h occurs in both virtual copies. Subtracting the equations gives
`Delta_r = sum_s c_s Delta_s` for arbitrary shared dirty h and arbitrary
independent main inputs. Tensoring the exact scalar identities with I_V proves
the same statement for every permitted V. The original chart provider remains
an inherited premise, not an assumption discharged here.

Suppose a physical lift currently satisfies the following invariant:

1. Its common or reference first-copy values follow the source correctly.
2. For EVERY live virtual role s, the current difference Delta_s has a certified

   current chart. The expressions use actual current versions and admitted
   scalar services. Their storage, source access, and prior transport are paid.
3. Physical ownership, snapshot safety, and the original common owned MOVE are
   valid. Retiring any observation separately preserves the invariant and pays

Only the displayed observer differences are needed for a given local
substitution. A weaker demand-only code may supply them selectively; the full
all-live invariant is a convenient sufficient condition, not a requirement of
the ten identities or a claimed feasible source-wide H4 architecture.

This is the all-live-row cochart decoder invariant used by the programme's
changed-main prefix construction. It is an assumption about an actual code,
not a free grant of 1080 helper-difference arrays.

Consider one listed owned MOVE r:a->b. Every observer s in the table is already
in chart b, and its value is unchanged by this MOVE of the distinct owner r.
By the invariant, each Delta_s is a linear combination of current physical
observations in b. Substitute these expressions into the displayed identity.
It follows that Delta_r is already in the same physical cochart span in b.
Execute the ONE original common/reference owned MOVE. Update the decoder for
r to this destination expression. All other virtual difference decoders retain
their current charts and values. Hence the invariant survives without a second,
differential transport for r.

The proof is causal: it uses only observations already present at the
destination before the MOVE. Neither the moving source owner nor a future
observer appears. The common MOVE changes no existing destination observation.
A materialized snapshot, when needed by the next consumer or before an aliasing
write, is formed from the flattened physical observation expression before
those observations change.

If that flattened expression has K nonzero terms, a fresh zero snapshot needs
K ordinary ADDs plus its INIT and eventual CLEAR. Existing storage can be used
only with the corresponding ownership proof. A direct implementation with all
32 named differences individually present uses at most32 such ADDs across the
ten snapshots; if the named differences are themselves decoded, the relevant

Keeping source observations stationary adds no Gaussian MOVE, but it consumes
