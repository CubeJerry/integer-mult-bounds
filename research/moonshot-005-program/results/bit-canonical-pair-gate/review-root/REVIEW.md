# Independent review of the canonical pair-intersection gate

**Proved within the stated native fitting interface: if the canonical quotient
has dimension d<2V, then chi>=165. No new κ.** This is independent of the
scalar reservoir, field size, block commutativity or a chosen pencil type.
The reviewer wrote a separate source checker and verified the universal
argument below. Source certification uses prime103 for nonzero minors.

Let C be the native rank9 canonical code, J_i its closed allowed support,
and A a fitting with V-by-V blocks, own blocks I_V and forbidden blocks zero.
For a positive-saving receiver i (chi_i<2), some canonical foreign block is
deleted: retaining every canonical contact would retain chi_i=2. If a nonzero
row a of k^V had aA_i in C tensor k^V, locality and the own block would force
aA_i=K_i tensor a. At a deleted block this is impossible. Thus the quotient
image E_i of row(A_i) has dimension V. Since all E_i lie in a common space
E of dimension d<2V, every two positive-saving rows have a nonzero common
quotient vector.

The source checker verifies, for all6105 pairs, that restriction of C to
J_i^c intersect J_j^c has rank7. Its kernel is precisely span(K_i,K_j),
because both words vanish there and are independent. Binary ranks extend
to every characteristic-two field, and the statement tensors with k^V.

Take two nonorthogonal positive-saving roots i,j and a nonzero common
quotient vector represented by aA_i and bA_j. Their sum is canonical and
supported in J_i union J_j, so it has the form K_i tensor c+K_j tensor e.
At input i, nonorthogonality gives A_ji=K_ji=0, forcing c=a. At input j
it forces e=b. Hence

    a(A_i-K_i tensor I_V)=b(A_j-K_j tensor I_V),

and this common literal vector is supported in J_i intersect J_j. Both a
and b are nonzero by the injectivity just proved. For every foreign input
l in J_i minus J_j, therefore aA_il=a, so A_il cannot vanish. This is the
crucial whole-block support conclusion; it does not assume a nonzero block
is invertible or use a commuting scalarization.

All5740 ordered nonorthogonal exclusive supports span their rank7 real
facet. Therefore a zero-charge row is orthogonal to every other positive-
saving row. The checker also authenticates55 pairwise vertex-disjoint
nonorthogonal pairs such that at one endpoint the exclusive support has
27 roots and homogeneous quadratic evaluation rank27 in its seven facet
coordinates. That endpoint has chi=2 if the pair both save, as follows.

Normalize roots to norm squared4. On the facet of r_i, the exclusive roots
annihilate Q(v)=(r_j dot v)^2-||v||². The projection of r_j to that facet
has norm squared3, so Q has eigenvalues2,-1,...,-1 and rank7. The rank27
evaluation certificate makes Q the unique vanishing quadratic up to scale.
Two proper subspace covers would give the product of two nonzero linear
forms, whose symmetric matrix has rank at most2, a contradiction. This
argument is over the real chart geometry, distinct from the characteristic-
two value field. The exact checker verifies every matching witness, and
rejects a duplicated matching edge as a disjointness control.

Let p be the number of positive-saving rows and z the number of zero-charge
rows. The matching implies p<=111-55=56, and total saving is S=p+z. If
z<=1, S<=57. If z>=2, choose two zero-charge rows: their roots are orthogonal
and every positive-saving root lies in their closed common support. The
actual source has at most32 such roots, while zero-charge roots themselves
are pairwise orthogonal, so z<=8. Thus S<=32+8=40 in this case. In all cases
chi=222-S>=165.

The retained eight/nine-full-route caps138/131 are below165, so a fitting
in those actual route interfaces must have d>=2V. Adding the canonical
9V to obtain an11V history bound is legitimate only if the historical
space actually contains that canonical code. The result is not a lower
bound on arbitrary history rank or a physical packet count. Changed
chronologies, quotient dimension at least2V, or other source interfaces
remain possible. The new two-packet pentagon module, if independently
admitted, does not contradict this gate merely by using two lifetimes:
its evolving coefficient history has larger dimension.
