I checked the universal argument directly. Four distinct cubic points are
independent, including infinity; field extension safely pads fewer types.
For each pair, a generic vector in the two-dimensional annihilator vanishes
on a base-field vector exactly when that vector lies in the pair plane.
These are six fixed global quotient codes, not six choices made afresh at
each receiver. An identity preimage cannot lie in an incident pair plane:
one cubic vector is killed by Phi, and the other has image rank at most1.
At a regular row the identity preimage lies in at most one pair plane,
because pair-plane intersections are zero or cubic lines of Hankel rank1.

Thus the six scalar capacities give `3S+2S_non <=84`. If S>=28, all
inequalities saturate: S=28, S_non=0, every scalar code has saving14 and
every used support-domination inequality is equality. The six type-pair
equations force weights `(7,7,7,7)`. Scalar equality14 permits only
double-saving rows, and rowwise equality therefore makes each type weight
even. The contradiction is valid even if some padded types were unused.

The theorem is `chi>=195` for at most four exceptional types in the
independent four-direction chain. The stronger `chi>=201` result remains
applicable in the earlier at-most-three-type scope. Five types are genuinely
outside this proof; this is not an exclusion of all F4 chains.
