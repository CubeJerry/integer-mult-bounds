## Why an invertible target requires a saturated route flow

Attach a super-source with one unit-capacity arc per original input port, and a super-sink with one unit-capacity arc per original output port. Give each retained paid occurrence one unit of capacity; give the `k` parallel new exports their actual aggregate capacity `k`.

For any chart set `A`, write `i(A)` and `o(A)` for its numbers of original input and output ports. Invertibility of the complete target implies

\[
\operatorname{rank} E_{A^c\leftarrow A}\ge i(A)-o(A).
\]

Indeed, a kernel of the outside-output restriction on the `i(A)` input directions can have dimension at most the `o(A)` inside output coordinates. Every whole-field message leaving `A` has rank capacity at most one field. Therefore every super-source/super-sink cut has capacity at least 1,289. The integral maximum-flow theorem supplies an integer route flow `f` of value 1,289, saturating every original input and output port. This is only a necessary condition and does not assert that a routable target has a linear code.

At width `V`, the same argument multiplies all ranks and capacities by `V` and then divides by `V`. Free histories, zero-initialized owned fields, local changes of basis, operator-valued messages and retiming cannot increase a cut's information capacity.
