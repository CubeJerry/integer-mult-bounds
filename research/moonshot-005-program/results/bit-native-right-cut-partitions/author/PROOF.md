# Four fixed right words fail the prescribed target irrespective of the upstream code

The 3+12 spread and single-45 K words, each followed by either the transposed Reed–Solomon or minimum-cache F word, all fail a necessary right-cut condition for the prescribed two-sided target. The certificate uses two native receivers, 3 and 35. It permits arbitrary computations at source, H and D and arbitrary bijective input and output gauges, including nonlinear gauges that mix copies or components. The eight-field proper boundary per body and absence of an extra input-dependent channel are its hypotheses.

## The equality forced by a common eight-symbol message

Fix receiver i and donor j on an identity edge of the target. Make only this original donor differ from a fixed baseline. At native bank 3,840 the 60 D charts containing j and perpendicular to i each have eight outgoing fields per body, repeated in eight copies. The stacked right map R_ij of the fixed K/F word is invertible on these 480 coordinates per body. This is the actual proper matrix on owners that enter the K nodes of i. It contains all delayed Hermite corrections, all genuine terminal Y inputs, and the selected F completion. Common constants due to fixed baseline inputs only translate the readouts.

For a nominated d, set Q_ijd equal to the eight d rows of R_ij inverse. At the full bank each row is replicated in eight copies in the physical input and output order. If f_i is an arbitrary bijection used for the receiver's gauge, then Q_ijd f_i(x), up to a fixed translation, is the required d readout when the logical input at donor j is x. It ranges over the entire alphabet of 64 field symbols at the native bank. At d there are only 64 incoming field symbols from the four genuine j-H flags. Call this shared message s_jd(x); it may be any function of x. It is independent of which downstream receiver is being considered. An arbitrary input gauge at j can be absorbed into s_jd.

For any chosen receiver i this readout factors through s_jd. Since both the message alphabet and the surjective readout have exactly the same size, s_jd attains every message and its decoder onto the readout alphabet is a bijection. Thus the partition of the logical x values according to Q_ijd f_i(x) is the same for all chosen receivers. This argument fixes every other donor and original baseline. It neither transposes a nonlinear computation nor assumes linear upstream coding.

Now take several labelled pairs (j,d) valid for both receivers on identity edges. They are separate single-donor tests in the same logical coordinate alphabet for x. The corresponding partitions coincide label by label and hence have the same common refinement. For a fixed i the number of blocks in that refinement is the field size raised to the rank of the row stack of the corresponding Q_ijd, at full native multiplicity. The common bijection f_i of x preserves this number for every label simultaneously. Therefore the two receiver stack ranks must be equal.
