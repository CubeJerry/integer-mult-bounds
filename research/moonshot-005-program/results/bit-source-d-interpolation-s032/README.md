# A finite source/D interpolation reduction

**Exploratory reduction and bounded failed candidate search. No new whole receiver, physical supplier, or κ.**

This separate follow-up lets the D1509 sections seen by receivers 6, 9, 48 and 73 change while source quotients compensate. It retains their prescribed identity readouts and prescribed native H263/H642 fibre images. Previously admitted packages are unchanged.

The source family changes the six protected quotient rows on the 96 protected source coordinates at each donor's four D1509 parents: 44 independently variable local maps. All other coefficients and H words are fixed. These quotient variables need not arise from a common invertible right change of a source bank.

## Exact local criterion

Fix donor j and D parent h. Let F be its 6-by-96 protected quotient map. Let C span the parameters observed at that quotient by retained native H interfaces. Let L be the 96-by-32 common frame for the four retained D receivers.

At receiver r, the actual six proper outputs of this quotient equal B(j,h,r) F for an invertible 6-by-6 matrix B. Let E(j,h,r) insert the appropriate D1509 ingress coordinates among those outputs, with off-D entries zero. These maps are reconstructed from actual labelled proper rows and the literal source map; each factorization is checked exactly.

For a proposed D word T', its actual retained section is S(j,r)=T'[O(r),I(j)]. A singular section cannot provide the prescribed identity readout on eight independent parameters. Otherwise the required quotient image is uniquely

    F_new L(r) = B(j,h,r)^(-1) E(j,h,r) S(j,r)^(-1).

The prescribed H images require F_new C=F_old C. Define

    X = [C,L],
    Y(T') = [F_old C, B(j,h,r)^(-1) E(j,h,r) S(j,r)^(-1)] over four r.

A linear quotient map satisfying these equations exists if and only if

    Y(T') ker(X) = 0.

Necessity follows from F_new X=Y(T'). For sufficiency, this kernel condition makes the requested map on the column span of X well-defined; extend it to all 96 input coordinates. The quotients have independent coefficients, so the 44 tests together characterize this prescribed interpolation family before source ranks, nonsaturation and physical scheduling are required.

This criterion allows changed ingress when the retained D sections change. It does not establish that the extended source maps retain whole inverse fibres: the complete rank conditions remain separate obligations.

## Bounded attempt

The saved search tests 128 deterministic elementary output shears of the old physical D word, each with coefficient 1. An early output uses only an early row; a late output may use either phase. Thus the 19/16 phase split and phase invertibility remain valid. The changed output is seen by a retained receiver.

Of the 128 candidates, 19 have a singular retained section. The other 109 fail a source/H interpolation equation. Every first failure in the fixed checking order is donor 0, quotient H116. No candidate passed all local equations, and no full source word or compiler invoice was attempted.

These are failures of this finite list. They do not exclude other coefficient choices, simultaneous changes, other quotient coordinates, H-word changes, or a changed fifth space. The result is not a general coupled obstruction.

The original D word and the admitted six-free-row repair are positive controls. Omitting H observations also leaves independent columns L, making every nonsingular section choice locally interpolable. Thus the failed equations identify retained H observations as the obstruction in these candidates.

## Reproduction and evidence

From the repository root, copy search.py into an empty temporary directory and run that copy with Python 3 and -B, keeping the repository root as current directory. The script writes beside itself. Arithmetic is exact GF64 with modulus x^6+x+1. The saved run completed all 128 candidates before its 240-second guard.

INTERPOLATION.json.gz saves all 44 systems, actual D owner indices, generators, relation kernels and ingress-to-quotient maps. RESULT.json records each candidate and its first failure. SOURCE-PINS.json and MANIFEST.json bind inputs and outputs. This is an exploratory package; admission and any independent review remain separate.
