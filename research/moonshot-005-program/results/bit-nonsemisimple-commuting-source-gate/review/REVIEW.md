# Independent review of the nonsemisimple commuting-source gate

Root accepts the stated obstruction on the asymmetric atlas and its integral
replications, subject to the explicit original-coordinate commuting-family,
proper-target and no-bypass hypotheses. This extends the earlier semisimple
gate; it does not establish the same result for the older balanced phase split.

The algebraic proof has been checked independently. The inverse of an
invertible finite block matrix with entries in a unital coefficient algebra
is a polynomial in that matrix, so its blocks remain in the algebra. The
tight common H-image is a graph with invertible commuting ratios. After a
finite splitting extension, copying a nonlinear code componentwise is a valid
alphabet reduction; no polynomial extension of nonlinear operations is used.
Common functions still factor through the intersections of the linear graph
spaces. On each primary component, a difference with nonzero residue
character is invertible, so a port with two different colours loses that
entire component. Pairwise intersection of all port audiences forces one
residue colour. The radical ideal is nilpotent, hence its module image is
proper. The resulting graph-span dimension is strictly below the 3p
independent actual early inputs. The fully early H cut, with no informative
route around it, supplies the contradiction.

A separate checker reconstructs H263 directly from the authenticated root
and route data. It confirms three donors, 33 joint-tight receivers, 90 actual
early owners, no late owners, 45 covered ports and all 990 nonempty pairwise
audience intersections. It does not import the author checker or rely on the
old colouring certificate for these conclusions. Removing a route or making
one audience disjoint breaks the corresponding checked premise.

New algebra controls use the nonsplit primary algebra F4[epsilon]/epsilon^2
on its four-dimensional binary module. For each of three fixed nonzero
residue characters, the graph span is 8<12. A three-dimensional Jordan
primary block gives span 7<9. Unrestricted noncommuting GL2 gives span six,
equal to the full input dimension, and escapes the asserted argument.
These controls support the all-width primary-module proof; they are not an
exhaustion of commuting matrix families.

One useful design consequence is that quotients X->X u_H in a common matrix
column representation have scalar coefficient blocks and belong to the
excluded family, even if the column vectors depend on the donor. The general
two-evaluation source package allows mixed row functionals and is not thereby
excluded. Noncommutativity is a necessary escape within this source class,
not a sufficient global construction.
