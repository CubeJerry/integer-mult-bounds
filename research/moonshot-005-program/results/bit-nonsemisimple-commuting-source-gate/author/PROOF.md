Use the actual asymmetric bank480 source and H-port quotas, all original

**Theorem.** No exact proper implementation of either stated target exists
in this jointly commuting source class on these fixed routes.

The new two-evaluation source theorem permits arbitrary donor-dependent

## 3. The H target is a graph over the coefficient algebra

Let R be the unital commutative subalgebra of End_F(M) generated by all
source coefficient matrices. An invertible sixteen-by-sixteen block
source matrix with entries in R has its inverse in Mat16(R): its inverse
is a polynomial over F in the whole finite matrix by Cayley–Hamilton.

At a tight receiver i and plane H, write u_j:M->M^16 for donor j's
inverse-coordinate H column. Its sixteen entries belong to R and it has
an R-linear left inverse. Exact shared H saturation forces the images of
u_0,u_61,u_62 to be the same p-dimensional space. This follows from the
same input-fibre sum argument used by the admitted source theorem; all
relevant proper target blocks are identities here.

Choose u_0 as reference and let v_0 be an R-linear left inverse. Then
u_j=u_0 a_j with a_j=v_0 u_j in R. Indeed both maps agree on every input
because their images lie in im u_0. Each a_j is invertible, since both
maps are injections onto the same image, and its inverse also belongs to R.
In the independent H inputs Z=(Z_0,Z_61,Z_62), the required H target can
therefore be identified with

    T_i Z = Z_0 + a_(i,61) Z_61 + a_(i,62) Z_62.

Its row space W_i is a p-dimensional graph with all three projections
invertible. The transpose actions on M* form one commuting algebra too.

Because each receiver sees exactly p H-port symbols and requires its
p-dimensional target, its entire visible port tuple is a bijective
function of T_i Z. Therefore an individual shared port factors through
the intersection of all W_i for its audience, even when its actual
encoder is nonlinear. The proof is translation invariance under the sum
of the corresponding linear kernels. Different source quotients can be
fixed independently at every tight view, so no extra local input is hidden
in this argument.

## 4. Common generalized eigencharacters, without semisimplicity

Pass to a finite extension K/F splitting the characteristic polynomials
of the finite commuting family. If a code over F existed, independent
copies indexed by an F-basis of K would give a code over K with the same
numbers of K symbols at every cut. Run nonlinear operations componentwise;
no polynomial extension of them is assumed. This is an information
reduction, not a claim that field extension or a physical basis change is free.

Decompose M* into common generalized eigenspaces

    M* = direct_sum_l M_l.

This can be obtained by repeatedly refining generalized eigenspaces of
the finitely many commuting generators; every refinement is invariant
under all of them. On M_l, each element a of R has one scalar character
lambda_l(a), and its remaining part belongs to a common algebra J_l of
strictly triangular matrices. Commuting nilpotents triangularize together,
so J_l is nilpotent. In particular J_l M_l is a proper subspace of M_l:
otherwise J_l^n M_l=M_l for every n, contradicting nilpotence.

The target W_i splits accordingly into graph modules W_i^l. Give receiver
i the residue colour

    (1, lambda_l(a_(i,61)), lambda_l(a_(i,62)))

at component l. If two colours differ, some difference of coefficients
has nonzero scalar character on M_l and is therefore invertible there.
The corresponding two graph spaces have zero intersection on M_l.
Consequently a port can depend on component l only when all receivers in
its audience have the same residue colour.

Every receiver must see at least one such monochromatic port; otherwise
all its messages would be independent of an entire nonzero target
component. Two distinct colours would thus supply two disjoint port
audiences. Section2 rules this out. All receivers in I have the same
residue colour, separately for every l.

## 5. The entire fully early H output has insufficient information

Fix one component l, write d_l=dim_K M_l and n_l=dim_K(J_l M_l)<d_l,
and use the common residue colour from Section4. Every W_i^l lies inside
the sum of one fixed diagonal graph and nilpotent corrections in the
other two coordinates. Hence

    dim_K span_(i in I) W_i^l <= d_l+2 n_l <3 d_l.

Summing over l gives

    dim_K span_(i in I) W_i <3p.                    (1)

Every actual H port is covered, and all its functions factor through
some W_i. Thus the entire45-port tuple is a function of the linear
space in(1). It has strictly fewer than |K|^(3p) possible values.

But all3p actual early inputs at H are independent. They are part of the
global invertible early encoding of the original X banks. The only routes
by which these variables can reach Hub cross the actual H-to-D ports;
outside early inputs can be held fixed, and stationary H snapshots do not
leave H before restoration. Restoring every original X therefore forces
the H output tuple to distinguish all |K|^(3p) inputs. This contradicts(1).

This proves the theorem for arbitrary common commuting coefficient
families, including nonsemisimple and nonsplit families. Noncommutativity
alone still does not prove a source works; the single-donor pencil gate
and all shared H/D/K constraints remain independent.
