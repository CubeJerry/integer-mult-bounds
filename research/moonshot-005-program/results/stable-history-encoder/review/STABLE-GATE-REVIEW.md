# Independent review of the stable-history gate

**ACCEPT after restriction of the hypothesis to neutral controls.**

Let `C = ker A`, let `K` span `C`, and assume
`dF0=0 => dBK=0`. If two history decoders have the same baseline row, their
responses agree on `C`; hence they define a well-defined linear map

    G : row(F0) -> dual(C),   G(dF0)(c) = dBc.

For a baseline row `r` locally encodable and terminal recoverable, the
recoverable-encoder unit-gain requirement is exactly that `G(r)` be nonzero,
up to normalization of an admissible control coefficient. Restricting to
`D = row(E) intersect row(W_T) intersect row(F0)` gives the map in the draft.
If `S` is generated by baseline rows of certified stable decoders, then
`D intersect S` is in its kernel. Rank-nullity yields

    rank(G restricted to D) <= dim D - dim(D intersect S).

In particular `D subset S` rules out this fixed encoder interface. The
conclusion requires an actual stable decoder, not baseline equality to an
arbitrary unobserved endpoint. All coefficient-admission and complete cost
conditions remain separate from this algebraic test.

The reviewed source has the stronger all-control annihilation premise.
The neutral-control statement is nevertheless the correct minimal universal
hypothesis and avoids conflating a general dual `dB=mu A` with `dB=0`.
The original concern about a discrepancy with the existing source theorem
was resolved: all nine source duals have `mu=0`.

This is an independent mathematical derivation. The companion source review
instantiates it only for donor77, receiver189 and chart71/pre29098, where
`D=span(u77)` and `u77=final189-initial189` has a stable literal history lift.
No source feasibility or new kappa is asserted.
