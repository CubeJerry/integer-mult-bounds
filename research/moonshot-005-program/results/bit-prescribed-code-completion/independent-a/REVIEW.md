## Gap caught and repaired

The initial draft permitted unlimited free newly decoded-point feedback in the mixed case. That permission invalidated the deduction of five paid ground arrivals from a static fitting-code dimension bound: receiver-local observations can decode new point values and free feedback can increase global rank without crossing a paid boundary. For example, common a and a+b+c permit a receiver with local c to decode b; free b feedback then reveals c, although c is not initially determined by that common code and local a. Thus static common-code lower bounds cannot automatically be applied to that interactive process.

The corrected proof explicitly grants only the old T17 points free and excludes further free feedback. I accept that repair. The broader interactive mixed case remains unresolved; this review must not be used to restore the removed claim.

Changed preloads, recoded paid carriers, newly acquired low-chart nonpoint information, and receiver-specific nonlocal delivery remain outside the theorem. In particular the physically built active-S6 plus two-canonical-row source is a legitimate change of interface and does not contradict this gate.
