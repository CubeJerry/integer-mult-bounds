## Exact activation thresholds

For i outside Z, and a seed row s in S with own coefficient s_i=1, let

    M_i(s)={j outside Z union{i}: s_j=1 and <r_i,r_j> !=0}.

These are precisely the other raw coordinates that must be granted before s can be a valid fitting row for i. Therefore the minimum number of fresh points needed to make i fitting-compatible before any other nonseed activation is

    d_i=min{|M_i(s)|:s in S, s_i=1},

with d_i=infinity when every S row has zero own coefficient. This is an exact equality: a minimizing row attains it by granting its displayed mismatch set; conversely every fitting row requires those noncontact coefficients to be canceled by raw grants.

The checker enumerates all256 S rows exactly, gives every one of the94 individual minima and an attaining point set where finite, and obtains

    min d_i over h0 outside Z =5,
    min finite d_i over h1 outside Z =7.

Because the code splits by h class, grants in the other class cannot reduce either threshold. Projecting any candidate fitting row to the receiver's own h class removes irrelevant opposite-class coordinates and leaves its own and same-class noncontact requirements unchanged.

## Why the complete bootstrap needs at least fourteen grants

Consider the first h0 receiver outside Z that is decoded without having itself been freshly granted. Before that event, every known h0 coordinate outside Z must be a fresh grant. The threshold theorem therefore requires at least five h0 grants. If there is no such event because all41 outside h0 receivers were granted directly, there are certainly at least five grants anyway.

Similarly the first nongranted h1 activation requires at least seven fresh h1 coordinates other than19,20. If every remaining finite-threshold h1 receiver is granted directly, the bound still holds. The two zero-column coordinates19,20 must additionally be granted in every complete scheme. Consequently every complete bootstrap in the stated model uses at least

    5 +7 +2 =14

fresh whole-record raw-coordinate grants. This argument permits adaptive choices and unlimited free feedback rounds. It does not extrapolate a failed finite search.

Each new individually acquired raw whole-record point reaching ground requires at least one positive owned descent under the retained native record contract; the earliest native-line copy already costs[1]=1. Thus the extra movement is at least14 for this model. The full-history fifteen-output source has less than8 movement room, so this mechanism cannot close its111-output target even under the stated optimistic free-side-information and free-feedback grants.

## Fields, widths and scope

All source constraints are binary linear equations with right-hand side0 or1. If a given grant set permits an exact fitting over any characteristic-two extension field, consistency of that binary system also gives a binary solution. Therefore enumerating the256 binary seed rows certifies the grant-set thresholds over every characteristic-two field. Tensoring whole-record grants with the identity preserves the argument for every positive record width.

For a grant set below threshold, the missing fitting condition yields an annihilating coefficient functional just as in the seventeen-point closure theorem. Two independent-input assignments agree on every granted observation but differ in the desired input, excluding arbitrary exact processing of those observations. This does not establish a bound for mixed nonpoint captures or a changed source code. Those remain the relevant possible escapes.
