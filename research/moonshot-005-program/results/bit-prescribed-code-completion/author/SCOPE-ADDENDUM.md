# Clarification of the canonical gauge statements

The intersection inequalities in section5 of the frozen PROOF.md are valid:
the baseline intersects a full invertibly vertex-gauged canonical code in
at most4V dimensions for S8, or3V for active S6. They therefore price retention
of the **entire** gauged canonical code: at least5V or6V additional dimensions.

Those inequalities alone do not show that every complete fitting inside the
sum of baseline and gauged canonical code must contain the entire canonical
code. The explicit forced-line calculation in section4 establishes that
stronger statement only for the ungauged envelope actually checked there.
Wording about the full canonical gauged completion class must preserve this
distinction.

FRAME-SATURATION.md now independently supplies a universal5V lower bound for
unchanged S8, so no four-direction completion remains in any envelope. For
active S6, a five-direction fitting using only a proper part of a nontrivially
gauged envelope has not been excluded by the intersection argument. Its5..6
gap remains open.

This addendum preserves the earlier frozen document and identifies exactly
which implication is not supplied by its valid rank estimate.
