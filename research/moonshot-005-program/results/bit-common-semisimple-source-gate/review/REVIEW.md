## The three reductions are valid

**A common finite splitting field suffices.** There are finitely many
coefficient blocks at each fixed r. Every one is diagonalizable over an
algebraic closure, so all its eigenvalues lie in some finite extension of
the finite base field. Their compositum is finite. Pairwise commutation
makes each eigenspace invariant under every remaining matrix. Restriction
of a semisimple operator to an invariant subspace is semisimple: its
minimal polynomial divides the original square-free minimal polynomial.
Induction on the common eigenspace decomposition therefore produces one
matrix S diagonalizing the entire family. It is the same S for every
donor, source block, and plane; this is the essential hypothesis.

**Product-code lifting is legitimate for nonlinear operations.** If a
complete deterministic F-code existed, e=[K:F] independent copies use
exactly e times every input and port alphabet dimension over F. Identifying
each e-tuple with one K symbol restores the original counts in K symbols.
The linear source coefficients in F act K-linearly under this grouping.
Every arbitrary nonlinear operation is run on each independent copy and
then regrouped. This operation need not equal the function obtained by
replacing base-field arithmetic by K arithmetic in a displayed formula.
Correctness, injectivity, all original inputs, restorations, and port
capacities are preserved by the direct-product construction itself.

No free physical field-extension compiler is inferred. A hypothetical
physical code implies a code in the information model, and the latter is
already impossible. Costs or temporary resources of a separately compiled
extension cannot reverse that implication.

**The common coordinate change preserves the native contraction.** Apply
S to each of the sixteen p-coordinate source blocks and to every receiver
block. The actual native and canonical matrices act on the role index with
binary coefficients, so this one common transformation commutes with both.
In particular it preserves the canonical-zero input slice. Relabel each
quotient by S inverse; its coefficient matrices become diagonal. Subsequent
functions compose with these bijections, preserving their alphabet sizes.
Thus the lifted source is exactly a varying aligned scalar-stripe source
over K, to which the admitted cut applies. The information proof grants
arbitrary processing at the cut, so an extra causal implementation of S
across the physical waves is not being assumed.

The resulting plane alphabet has at most 538644r dimensions over K, while
the canonical-zero slice to be distinguished has 587520r. Their difference
is 48876r>0. The alphabet contradiction holds independently of the degree
of K and all downstream nonlinearity.

## Scope and controls

Finite-extension multiplication matrices are included: finite fields are
separable, and all multipliers in one common representation commute and
are semisimple. Direct sums of such common representations are included as
well. Individually diagonalizable donor families with incompatible bases
are not automatically one commuting family. A nonzero nilpotent Jordan
part is not semisimple. Noncommuting arrays, nilpotent coefficient algebras,
different donor bases, or a changed route/source contract remain outside
this theorem; none is asserted to give a construction.

The independent checker implements F4 directly from
`w^2+w+1`, without an algebra package or author-code import. It verifies
the multiplication representation `M=[[0,1],[1,1]]`, an explicit common
extension eigenbasis, and all 180 matrices of GL(2,F4). The field algebra
has no common eigenbasis over F2 and exactly 18 over F4. It checks direct
sums, all 4,096 two-block quotient conjugations, and all 4,096 inputs of a
small binary role map under the common basis.

A componentwise binary Toffoli lift is tested on all 64 inputs over F4;
it is bijective and is explicitly different from substituting F4
multiplication into the binary formula. Separate semisimple donor bases,
a noncommuting semisimple pair, and a nonzero nilpotent Jordan block all
fail the common-diagonalization test. The separate-donor example also
shows that equal sums in different transformed input coordinates can
represent different original native sums. These controls support the
precise scope; the universal corollary rests on the written reduction and
the pinned native information cut.
