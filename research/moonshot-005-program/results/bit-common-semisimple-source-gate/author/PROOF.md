# A common semisimple coefficient algebra cannot supply the balanced source

Retain the balanced quotient model of the admitted varying-stripe port
cut. Each source has16 blocks of p=360r coordinates over a finite field F
of characteristic two. Write every ordinary quotient in linear labels as

    Z_(j,H) = sum_s C_(j,H,s) X_(j,s),

with p-by-p coefficient matrices. Arbitrary bijective bundle relabellings,
unrestricted singleton encoders and nonlinear downstream processing remain
permitted within their real capacities.

**Theorem.** No complete native code exists if the one family of all C
matrices, across every donor, plane and source block, commutes pairwise
and every member is semisimple. Here semisimple means diagonalizable over
an algebraic closure. Different donor-specific common bases and nontrivial
nilpotent parts are not excluded.

## Extension without assuming polynomial nonlinear operations

A finite commuting semisimple family has a common eigenbasis over a finite
extension K/F. Split its characteristic polynomials in one finite field.
Every commuting matrix preserves the eigenspaces of the first; its
semisimple restriction is still diagonalizable. Repeat on those spaces
through the finite family. Let S be the resulting common basis matrix.

If a deterministic code over F existed, take e=[K:F] independent copies
and identify each e-tuple of F symbols with one K symbol through a fixed
F-basis. Each port has the same number of K symbols as it previously had
F symbols. Run arbitrary nonlinear operations componentwise in that basis;
no polynomial extension is asserted. The source matrices have coefficients
in F and therefore act K-linearly by the same C matrices. Addition and the
binary canonical map extend componentwise, preserving all original inputs
and native targets. This is a capacity reduction, not a claim that field
extension or its physical implementation is free.

## Common conjugation reduces to aligned scalar stripes

Set X_(j,s)=S Xtilde_(j,s) for every source and source block, and relabel
every quotient Z_(j,H)=S Ztilde_(j,H). Then

    Ztilde_(j,H)=sum_s (S^-1 C_(j,H,s) S) Xtilde_(j,s).

All coefficients are diagonal, so this is precisely the aligned varying-
scalar-stripe source class over K. A common transformation at all receiver
blocks preserves every native sum and commutes with the binary canonical
map. Bundle relabelling is permitted; subsequent functions compose with S.
All cut alphabets and source information remain unchanged. The negative
information bound already grants arbitrary processing of data at a cut,
so no free causal compiler of S across the two physical waves is needed.

## Consequences and exact scope

Multiplication matrices from a single finite extension field form a
commutative semisimple algebra: finite fields are separable, so each
minimal polynomial has distinct roots in a finite splitting field.
Therefore replacing scalar coefficients by multiplication matrices in
one common finite extension cannot evade the native cut, even when those
matrices visibly mix the chosen base-field coordinates. Direct sums of
such multiplication representations are excluded for the same reason.

The conclusion concerns one common representation on the p-dimensional
bundle for all coefficient blocks. Separate donor conjugations can break
this common-algebra hypothesis and remain open. A successful block-array
source must escape common semisimple commutativity, or leave the other
specified source/route conditions. Noncommuting coefficients and
nonsemisimple commuting algebras are distinct unexcluded possibilities;
neither is asserted to yield a code.

Finite controls should include commuting matrices diagonalizable only
over an extension, noncommuting matrices, and a nonzero nilpotent Jordan
block. They illustrate scope; the universal statement follows from the
written lifting/conjugation argument and the independently verified native
information cut. No MOVE lower bound, compiler, supplier, κ improvement,
or foundational discharge follows.
