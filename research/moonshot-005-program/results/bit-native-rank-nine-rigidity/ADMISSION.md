# Formal rigidity of the canonical 9b return

For every characteristic-two field and body size b, the canonical native fitting is formally rigid, up to independent native basis changes, at rank 9b. The foreign-coefficient tangent has dimension 110b². Two independent finite calculations use 1,998 factor variables and 6,470 edge variables respectively. A nongauge scalar square-zero direction costs at least the rank of its coefficient matrix, and a single native edge attains equality.
