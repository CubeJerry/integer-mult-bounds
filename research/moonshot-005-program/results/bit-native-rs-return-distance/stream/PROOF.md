After ordering by actual component and copy, the fixed programme splits into eight copies of a 96-field component and a 384-field component. A marked D receives H outputs only from the 9-port component and goes only to that K component. Each delayed H derivative, D update and K cache stays within the same copy. The whole native exception at a singleton uses the recorded derivative scales in the relevant component. For the right-hand word, `check.py` verifies every late pair is internal to its declared component. The solver iterates original donors. For one donor j it acts on the complete coordinate basis, places its evaluations or scaled derivatives on the actual H slots, propagates the physical H and D operators, evaluates each active K on the resulting owners and contracts each actual receiving facet against its declared functionals. It appends the self-identities to form the original columns of I+B. It never forms the full native square matrix. The optional external-block control compares separately generated proper blocks cell by cell, including a singleton control. The exact rank computation itself uses no external block values.

For elimination it embeds the field in the reciprocal polynomial presentation GF(2)[t]/(t^6+t^5+1) by mapping z to the inverse of t. The program checks this map on all 4,096 field products. Each nonzero pivot column is normalized in the reciprocal basis, then retained from its first nonzero row to the end. New columns eliminate against those stored columns. Permutation signs are trivial in characteristic two, so the product of the pivot values, converted back to the original polynomial basis, is the full determinant when the rank equals the dimension. The accelerated multiplication uses the six-by-six binary matrix of each multiplier and authenticates all SIMD byte outputs against bitwise polynomial multiplication in both field bases. A scalar implementation is selected when the host lacks the relevant instruction.
