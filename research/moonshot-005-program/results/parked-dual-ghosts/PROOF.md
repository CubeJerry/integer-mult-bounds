## 1. The parking lemma and its precise interface

Let a linear source prefix have independent genuine dual inputs

endpoints are `b+R d`, that its other live endpoint rows have no dependence

For every selected slot, make the following literal rewrite.

1. Move the genuine original `b_j` directly from its initial line to the hub.
2. Initialize a new, genuinely owned zero field `g_j` at `C_j`.
3. Replace the old active slot by `g_j` in every remaining operation of the
   prefix, preserving all source reads, coefficients and chart locations.
   Its original ascent tail is now owned transport and is paid accordingly.
4. At the common boundary, retain the actual value of `g_j` at the hub.
   Add it into the parked genuine `b_j` to recover the parent's public output.
   It may also be used as an authenticated source before its eventual CLEAR.

The rewritten active computation is exactly the original linear computation
with the selected initial coordinates set to zero. Therefore its other
endpoint rows are unchanged, while `g_j=(R d)_j`. The genuine original is
still `b_j`, so adding the ghost gives the original public `b_j+(R d)_j`.
This is a complete algebraic proof for every field volume under the retained
linear/chart semantics. It applies simultaneously to any selected set.

The assumptions are necessary interface conditions. A logical alias for a
missing coupled dual is not a genuine original that can be parked. An input
already read earlier cannot be removed from that earlier computation by this
rewrite. If another live endpoint depends on the parked original, the stated
endpoint-preservation conclusion requires an additional repair. The exact
source replays below verify all of these premises rather than assuming them.

The new field is initialized only after its location has been specified. It
never contains a free copy of the parked original. It occupies the old active
slot at every later cochart operation, including the genuine `d` injections.
Every MOVE is nested and has the correct owned flag. The original raw value
