## Why the complete hub history is handled exactly

There are 1,022 public MOVE arrivals at hub127, no hub departure, and 1,022
final common hub fields. Every other native hub operation is a public ADD or
a nonzero public SCALE. Hence the vector of 1,022 arrival values and the
vector of 1,022 final hub values are related by an invertible local linear
map. No source control admitted by this proposition acts at the hub, since
the hub contains every port a.

It follows that restoring the common hub outputs also restores all hub
arrival responses. Using final hub fields therefore retains the complete
hub observation span. It does not discard any prehub observation, and it
introduces no transport of common data between charts.

The source has a certified invertible public endpoint map T. In its final
output coordinates, the common hub fields are 1,022 coordinate directions
and the remaining common outputs are 458 directions. The verifier seeds the
source with the offhub columns of T inverse and replays the actual native.
It checks every final offhub unit column and that every hub arrival has zero
component on those 458 coordinates.

For each receiver, initial cochart observations project onto a set of known
offhub coordinate directions. Eliminate those directions from the actual
prehub arrival rows. Exact rational elimination produces a complete kernel:
3,397 rows, total residual rank1,538, and 1,859 relations. Every relation is
then completed with an explicitly listed final-hub linear combination. The
source-adjoint pass authenticates the resulting identity on every original
common input.

Additional relations involving only initial observations and hub values
have zero private response when the initial observations are captured before
controls and the common hub endpoints are restored. Thus the 1,859 stored
relations suffice for the pure-gain test under the stated endpoint condition.

## Direct upper-cone certificate

For a relation ell, initialize its adjoint with the stored final-hub
coefficients. Add each historical arrival coefficient immediately after its
specified source MOVE and propagate backward through the literal ADD,
SCALE, COPY, INIT and CLEAR rules. At every source interval where a field's
adjoint or chart changes, inspect its nonzero entries. This enumerates all
distinct current-role source sensitivities; an intervening instruction that
changes neither has the same sensitivity.

For every relation owned by port a, every inspected nonzero sensitivity is
at a chart containing a. The initial-observation terms cancel the remaining
initial adjoint exactly. This proves both the baseline identity and the
claimed localization. The direct identity does not need a COPY-zero guard;
requiring the actual guard cannot enlarge the control class.

Since a has odd weight, a is not in H=a-perp. Every chart in a monotone raw
Y2 itinerary ending in H is a subspace of H and therefore does not contain a.
No allowed donor control can change any of the complete receiver-history
null relations. With the common endpoints restored, any pure private linear
functional of the granted history must lie in the complete original null
space, so its qY2 coefficient is zero.

## Chronology and physical interpretation

The grant includes all source-time arrivals at the receiver's original route
charts, even if the raw receiver was not there at that time. This is an
optimistic history interface. A concrete one-relation decoder can retain a
stationary owned accumulator at each observation chart, collect its initial
and arrival terms at the source times, and let rawX2 make one late ascent to
consume those accumulators. At hub127 it can read the stored relation's final
hub terms. Such an implementation needs charged INIT, ADD and CLEAR work and
retained ownership, but it need not add a MOVE. The impossibility result grants
that ability rather than assuming that every historical read must occur during
an immediate raw traversal.

Likewise, a donor can leave stationary copies of qY2 while taking its original
raw route once. The all-cut control test grants those caches. It does not
charge them as new transport, and it does not assume that a q value remains
physically available at an abandoned chart without storage. Even with this
strong history/cache grant, the clean own-reverse gain is zero in the fixed
baseline interface.

No lower bound of96 paid rank1 calls is asserted. The result identifies an
interface that cannot perform the96 duties; a different common-dependent
record scheme or jointly encoded transport can escape it. Observation-aware
raw-route fusion changes the available whole-system moment margin, and the
older all-newly-paid packet bound near99 is not by itself binding against a
fused blank margin near118.3. Neither margin nor this scoped obstruction is
a complete construction of the104 forward,96 hosted reverse and8 coupled
reverse duties.
