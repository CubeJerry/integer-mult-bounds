## Chronology and source preservation

For each nonempty subset initialize a stationary owner at its actual chart. Every listed X original already visits that chart. Capture it immediately after its first arrival, while it still contains raw X_j, before source recoding. All captures finish before principal queries. Neither its value nor any original X route changes.

P3, P4 and P5 already visit respectively C1, C4 and C3 on their descending paths. Query the new row during that existing visit. Together with the private substitution r_i, the actual first retained value at M1 becomes a_i+r_i+s_i. It is a replacement of a_i, not a free extra copy. The existing reset uses that same first retention, so all later payloads and terminal values of these three principals remain unchanged.

The required real-chart nesting is M1 subset C1 subset F4, M1 subset C4 subset F74, and M1 subset C3 subset F78, with dimensions5,6,7. Insert the corresponding pair chart on the old receiver's last M1-to-facet move, and read the new stationary s_i field there. The private r_i correction, if present, is then read at the final facet. Hence both added perturbations cancel and every old endpoint is preserved. These visits ascend through a genuine nested chart flag; no incomparable chart jump is used.

P6 already descends through Extra6. Query t6 there and continue its existing route. Its final ground value becomes old_P6+t6, including its unchanged existing E corrections. No old receiver reads P6, so no old endpoint changes. **The old ground P6 value is not also granted.** The actual ground rows are exactly `seed_rows_hex`, and the old code metadata is explicitly marked as predecessor metadata. All other terminal principal values remain unchanged.

Exact binary elimination verifies that the base eight-dimensional terminal row space has zero intersection with the six-dimensional span of the raw Extra6 coordinates: their sum has rank14. Thus every Extra6 perturbation preserves the terminal rank8. Indeed, a dependence on the modified P6 would express its nonzero Extra6 perturbation as a vector in the old terminal code, which is impossible; a dependence not using modified P6 would already contradict the old rank8. This binary minor statement remains valid over every characteristic-two extension field. It is also enough for each fixed whole-record tensor implementation.

Every new stationary owner is retired after the base word. All arbitrary Y nuisance columns and all original X restoration identities are unchanged. There is no new owned MOVE. This proof composes with the private affine proof because each injected perturbation is additive, reaches only its specified first retention or P6 terminal, and is corrected at the specified real source chart.
