# Actual paired relay bridges with restored dirty or clean owners

This package provides a fully costed application of the classical paired
commutator identity to the programme's actual complex source. It supports
rectangular, possibly singular acquisition without an invertible full-bank
completion. The native instance reuses two authentic reverse Gram owners and
preserves their old duties, removes16 paired coefficients, and retains all400
independent input directions and all endpoint charts.

A separate zero-output theorem cleans a forward scratch owner from its actual
zero-born output cache, reducing the clean bridge from four transfers to three.
Both scratch owners then retire zero at D; the forward owner does not return
to its birth chart C. The local forward caches and all inherited physical,
ordinary, precision, compiler, erasure and uniform supplier duties remain.

**No new complete kappa.** The residual reverse rank remains96 and5360 expanded
forward coefficients remain. These local mechanisms do not constitute a global
supplier. This is author evidence; independent review is recorded separately.

- `PROOF.md`: all-field theorem, precise terminal charts, scoped stage-count
  minimum, clean alternatives, exact native source and complete cost.
- `build.py`: literal400-input words for five explicitly different interfaces.
- `check_algebra.py`, `ALGEBRA.json`:80 exact matrix cases,57 zero-output cleanup
  cases,682 short-word controls, six hypothesis/sign counterexamples.
- `dirty-echo/`: actual reuse of existing dirty reverse Gram owners.
- `zero-output-cleanup/`: clean three-transfer source using genuine output caches.
- `zero-roundtrip/`: both scratch owners restored to their separate birth charts.
- `zero-erasure/`: cheaper two-transfer source retaining dirty-owned erasure.
- `zero-echo/`: dominated six-transfer clean control of the dirty-compatible macro.
- Each variant has `WORD.json.gz`, `RESULT.json`, `PRICE.json`, `PHASES.json`.
- `reproduce.py`: isolated replay and semantic comparison with committed evidence.

From repository root, after integration at the declared destination:

```bash
python3 -I -B research/moonshot-005-program/results/complex-paired-relay-echo/author/reproduce.py \
  --repo . --work /tmp/paired-relay-echo-replay
```

The script uses pinned predecessor source and engines from the same repository,
creates a new output directory, and verifies canonical decompressed scientific
payloads. Gzip wrapper bytes are not a reproduction invariant. The copied
native and caller inputs retain their exact original hashes and credit.

The optional `search_instance.py` is finite discovery support for this explicit
C4/D5 rectangle. The theorem and source do not rely on a search maximum.
