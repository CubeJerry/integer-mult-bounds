## 1. A noninterfering affine null observer

Let an existing reciprocal cohort have an invertible hosted matrix M and an
actual pivot insertion matrix E. At its real common chart C, the hosted dual
bank has current value z=M^(-T)b. Its receiver reads change this bank to
z'=z-E d; all entries subsequently arrive at the hub before the existing
M^T decoder. Let C0 be any matrix supported on these pivot positions,
representing coupled primal control coefficients.

Initialize an actual owned field vector g to zero at C, and compute

    g = -C0^T z.

Send g along a paid route to the hub. When the authentic z' entries are there,
before their old decoder, perform

    g += C0^T z'.

The resulting field is exactly

    g = -C0^T E d.

All original hosted and primal fields are unchanged by these new reads.
The identity holds for arbitrary original b and d, at every field volume.
It is the missing-coordinate part of the inverse transpose of the affine
block matrix [[M,C0],[0,I]], but it does not assume that two aliased public
records are independent. The added records are genuinely initialized zeros.

The only source prerequisites are the stated actual current cocharts and
the correct pre/post-injection rows. A newly available original b value is
never substituted for an encoded current row. In particular, the early
g=-C0^T z is not a pure-d observation. Its original-b dependence disappears
only after the actual hub cancellation.

For the source's rank-two direct exception at chart 1105, the four relevant
original Y2 sources are already cocharted. There is no claim that a two-row
hosted bank has four independent pivots. The required null rows are instead
formed directly from those four actual sources, then sent to the hub.

## 3. Why one whole null arrival can be omitted

Each null coordinate is read only to form and transport itself, then to
provide an observer at the hub. It never updates an original active field.
Consequently an observer that is a known linear combination of the other
final observers need not be materialized early at all. Its early INIT,
preload and transport can be omitted together. If a later consumer needs
that coordinate, a real zero field can be initialized at the hub and filled
from the already decoded final observers there.

Here g17=g19+g38-g40. The actual word omits g17 entirely and uses the seven
independent rows directly. This removes a whole paid rank-three arrival;
it does not merely assert a seven-dimensional rank while moving eight
fields. It also avoids granting any zero-padding field a fictitious
original raw route.

This global boundary relation does not contradict the earlier local rank
census: the coupled columns at each acquisition chart are independent.
The dependence combines fields from distinct groups after their original-b
terms have actually been cancelled. Applying the relation to their early,
genuinely cocharted hub values is wrong; an actual-word negative control
exhibits the remaining independent b nuisance.

In the interface consisting only of these pure-d observers and unchanged
hosted outputs b+R d with independent arbitrary b, seven observer field
dimensions are necessary to recover all eight g coordinates. Hosted
outputs cannot supply a pure-d row: cancelling their arbitrary b
coefficients forces their combination to be zero. The rank-seven
observation matrix gives the lower bound and the selected seven rows
attain it. This is an information statement about the specified interface,
not a universal transport lower bound.

## 6. Global continuation and its exact remaining premises

In a prospective complete rectangular paired code on the 96 hosted reverse
