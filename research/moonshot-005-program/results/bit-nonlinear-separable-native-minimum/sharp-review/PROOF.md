# Sharp image gap with up to 54 unspecified defective functions

The three-donor theorem in [the independent native proof](../sharp/PROOF.md) proves global additive rigidity when |im T|<2|A|⁹ and the specified tree is bijective. Its endpoint example has exactly twice as many outputs as the binary canonical code and can keep every proper function bijective. The original two-column proof establishes the smaller 3/2 neighborhood.

The stronger cutoff survives 54 missing bijections anywhere on the 6,470 proper cells. For each tree cell (i,p) the certificate exhibits at least 54 detours. A detour consists of another row r, another donor q and eight common anchors. The signed native geometry supplies a third donor s outside the anchors. It is distinct from p,q, and all six (i,r)×(p,q,s) cells meet the common anchor condition.

Only four other functions need to be bijective: (r,p),(r,q),(r,s) and (i,q). All three columns then project bijectively on row r. The graph-sum single-fibre proof gives one additive map from row r to row i across the three donors. It is an automorphism since both maps on donor q are bijections. Thus (i,p) is bijective without a hypothesis at (i,s). For each fixed tree cell all relied-on four-cell sets are pairwise disjoint. If a seed were defective, at most 53 other defective cells would remain and one of its at least 54 detours would be intact. This repairs the full tree at the sharp cutoff.

The independent verifier reconstructs all 2,965 three-column propagation steps, every one of the 110 additive transitions, and all 12,481 four-cell detours directly from the 111 genuine roots. A separate weighted two-column proof is retained for the linear stability estimates. This is an image theorem for an additive sum of arbitrary single-donor functions.
