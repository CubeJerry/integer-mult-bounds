# Exact raw-cache reactivation obligations at the raised-Y cuts

**Source-specific linear information necessity; independent review pending.
This is not a complete-source impossibility theorem.**

The low-retention and proper-export cuts leave four public Ys at ground and
move all103 noncoordinate Ys to rank-three query charts. Forty native snapshots
remain at rank one after their corresponding original X have departed. Treating
all those snapshots as already available to the raised Ys loses a real source
access condition. This certificate measures that condition under two stated
global-history spaces.

## 1. Actual spaces and the necessary affine condition

Authenticate the two words and cut inventories named in CERTIFICATE.json.
For the low-retention cut, let G be C plus the span of all current full4/6-term
query rows. For the proper-export cut, let G be C plus the twelve independent
four-sign query rows that are actually exported. In both cases dim(G)=21.
These are deliberately generous global grants; they are not claims that C or
all scattered query fields are physically available at every receiver.

For receiver i, let L_i be the span of the X parts of every current non-native-
snapshot field whose actual chart is contained in F_i. This includes original
X, original Y, and, in the export case, all actual baseline, axis-history and
export owners at eligible charts. Grant every initial Y input for free so all
Y nuisances can be removed for this necessary test. Let E be the40 source
indices whose original X is currently above rank one. Their native snapshots
are the only initially dormant native raw coordinates.

Assume public routes remain monotone upward, operations remain linear, and
the X part of every future downward payload lies in G tensor k^V. Then any
completed receiver must satisfy

    e_i in G + L_i + span{e_j : j in S_i},                 (1)

where S_i consists of expired native coordinates actually reactivated into
upward information reaching F_i. Every such j lies in the native neighbour
set N_i. All future upward relays of current fields were generously included
in L_i whenever their initial chart lies inside F_i. A field initially outside
F_i can contribute through a descent only via the globally granted G. Linearity
keeps arbitrary-Y equations separate; it does not create new X directions.

Native snapshots whose original X is still native add no new initial direction:
their unit rows are already present among the current public fields. A dormant
native snapshot can enter an upward public path at its rank-one chart only
through a public Y still at ground. No other current public chart is contained
in that distinct native line. The four such Y originals are exactly4,5,6,7,
and each can visit at most one distinct rank-one line under monotone ascent.

Every other new native-coordinate contribution requires an owned upward
departure from that native line, unless a new descending X history leaves G
(an explicit escape from the premise). A single such first upward departure
can introduce only the one native coordinate at its source line; other arriving
descending X information is already in G. Repeated visits or changing names
do not remove those paid occurrences.

## 2. Exact minimization

For each i compute the least cardinality of S subset E intersect N_i for which
(1) holds. Binary elimination computes the quotient by G+L_i. Every eligible
unit gives an exact quotient syndrome. Split the eligible coordinates in two,
enumerate every subset of each half, and retain a minimum-weight mask for each
syndrome. Matching complementary syndromes for the target gives the exact
minimum over *all* subsets, not only subsets of size four.

These are binary row-span statements. Their ranks are unchanged over every
characteristic-two field. Tensoring the observation spaces and taking a scalar

## 3. Verification and precise escapes

The checker authenticates source words, derives actual rational charts,
verifies the four ground Ys and all111 native snapshots, constructs every
visible initial space from the full inventory, and exhaustively solves all222

    python -B check_raw_cache_reactivation.py --repo REPO --out OUT

New descending coded modes outside G, public turns, earlier cache transport,
changed source cuts or nonlinear operations are outside this theorem. Paid
