## 1. The stronger observation relaxation

Previous dormant-cache bounds granted every active native X original as
freely available local data. This is a valid favourable relaxation but
does not price those originals' eventual departure and branching. Here
the first-exit test is applied to all source lines simultaneously.

At cut1142, every field at a native line L_j has X part either zero or
the unit e_j. This is checked against all341 actual fields. The111 native
snapshots are present. All other fields retain their full actual X/Y
rows and actual charts. Original Y inputs are revealed only for the
necessary lower-bound argument.

For receiver i, grant G and the X parts of every current field inside F_i
that is NOT on a native line. For a source j in N_i, additionally grant
every other eligible native unit e_k, k in N_i minus{j}. Native-line
fields of those other sources are therefore known, but the actual
native fields at L_j remain the only ungranted local source for x_j.

A binary dual d_ij satisfies

    d(G)=0,
    d(all granted current nonnative fields)=0,
    d(e_k)=0 for k in N_i minus{j},
    d(e_i)=d(e_j)=1.

This says that source j is still indispensable for receiver i after every
other eligible raw coordinate is supplied. It makes no claim that those
other coordinates are physically free; granting them favours the decoder.

## 2. A first-exit lemma

Apply d_ij to the complete X coefficient row of each live field. Every
future downward payload has dual value zero because its row lies in G.
An ascending carrier cannot enter F_i's downward-closed chart region
from outside. Every initial field inside that region, except those at
L_j, has dual value zero by the preceding grants. Thus the final nonzero
target must receive information from the actual native j line along
an effective upward path contained in F_i.

This is true whether X_j is still at its native line or has already
departed. Its earlier nonnative occurrences have all been included in
the actual current-field test. A stored value on a native line is not
a cost-free source at every later chart.

If only one effective upward departure occurs from L_j, let P>L_j be
its first destination. Every forced receiver must be reachable through
that departure, so P must lie in all its forced facets. Local recoding,
copying, arbitrary paid owned turns and changing packet contents do not
evade this conclusion: descending values have dual value zero, and
upward paths cannot enter a missing facet downset. Each receiver can
use its own dual; a common dual for the entire fanout is unnecessary.

For each of the103 noncoordinate source roles, the certificate selects
seven forced receivers whose real normals are independent and whose
facet intersection is exactly L_j. No strict superchart P lies in that
intersection. Hence each such source needs at least two native-line
upward departures. The eight coordinate sources need none in this test
because their unit values already belong to G.

The binary dual argument extends entrywise to arbitrary block coefficient
matrices over every characteristic-two field. The target identity block
survives while every granted block vanishes. Every selected receiver
still needs an actual nonzero path from L_j. Real geometric ranks remain
separate from the coefficient field. No scalar or commuting-block
assumption enters the count.

The103 forced lines need206 departure occurrences. Distinct native
lines are incomparable, so one movement cannot be a first departure
from two of them. Reusing an owner at a later time creates another
movement occurrence, not a free second departure.

Exactly71 of those lines currently hold a public X original. Each
monotone public X can depart that line at most once and cannot visit
another distinct native line. The other32 public X originals are
already at rank2/3 and cannot descend to their old lines. The eight

line; grant all eight that possible service even though their final

noncoordinate Y is already at rank three and cannot visit a native line.

    future owned ascents >=206-71-8=127.

The ground public allowance is subtracted once across all source roles,
not separately for active and dormant subsets. Native snapshot owners
and any fresh copies remain owned and pay for their actual departures.

## 5. Controls, scope and next direction

Granting all raw coordinate units in G eliminates every forcing claim.
Allowing111 ground public carriers instead of the actual eight would
reduce this particular departure count to24, below the present budget.
These are scope controls, not claims that either altered source is a
complete supplier. The actual word has all222 columns,32 modified sign
sources and eight completed coordinate values exactly as independently
reviewed; no source operation is rejected by this theorem.

The result concerns a linear continuation whose descending X rows stay
in the exact rank29 bank. Full data-dependent scheduling, non-linear
payloads without this row model, new descending directions, or public
downward turns need a different theorem. Earlier acquisition that keeps
more public receivers at ground changes the counted resource and is a
concrete way to test the boundary. Every subsequent source must be
audited anew rather than inheriting this cut's count.
