## 1. Why the exported fields are pure despite arbitrary Y inputs

For each selected query q, write P for its early rank-two pair chart, u and v
for its two sign-pair sums, and a for its actual axis-delivery history. In a
sign-only gadget a is absent. The representative receiver's value immediately
before its early pair read is an arbitrary baseline b. This can contain both
its own independent Y input and a courier's independent Y input. The prefix
actually snapshots b at P. At the later query chart it actually snapshots a
when the gadget uses an axis delivery. These are executed reads, not assumed
reconstructions from a final value.

After the two pair reads and axis read, the receiver contains b+u+v+a at its
rank-three query chart. A fresh zero owner reads that value and, when needed,
the stored actual a at that same chart. Its value is then b+u+v. The owner
descends one rank to P and reads the saved baseline b there. Its value becomes
exactly q=u+v, the four-sign sum. It contains no original-Y coefficient.

The retained raw donor at P has value x_d. Adding q makes it x_d+q. Since d is
one of q's four inputs, this is a three-input sum. The independent geometry
check gives native support span rank three, whereas its physical chart P has
rank two. Thus the operation really creates a nonlocal X payload at a proper
chart; its informational effect is not inferred merely from a formal code.

The actual word never introduces any original-Y coefficient into an X
original. The replay checks that invariant after every original-X update.
