## 1. An actual cyclic-interval decoder

Let a_0,...,a_(m-1) be pairwise orthogonal native root lines in an ambient
D-dimensional chart. Let C be a c-dimensional chart orthogonal to all of them,
with 2 <= m <= D-c. For indices read cyclically, define

    T(j,k) = C + span(L_(a_j),...,L_(a_(j+k-1))),   1 <= k <= m-1.

Suppose the original sources can follow these new paths without unprotected old
readers. Each original X_(a_j) ascends through T(j,1),...,T(j,m-1), then Hub.
At each T(j,k) it leaves an independently initialized stationary owner
R(j,k)=x_(a_j). These are actual captures, not a grant of raw local information.
After all these original sources have reached Hub, acquire the actual field

    p = sum_j x_(a_j)

and deliver it to C by the specified paid source route. Each Y_(a_i) waits at
ground until p is available. It first moves to C and reads p. For k=1,...,m-1,
it then moves to T(i-k,k) and reads R(i-k,k). The visited intervals are nested:
each step adds the next preceding line in the cyclic order. None contains the
receiver's own line, so every one lies in its final facet F_(a_i). The last
chart is followed by F_(a_i), omitting an equal-chart move when appropriate.

Exactly the other m-1 source values are added. Therefore the final value is
y_(a_i)+x_(a_i), independently for every original y. No Y is used as a donor.
No source X is changed. All ADD identities use only characteristic-two
cancellation, so the binary coefficient proof tensors with I_V over every such
field and width.

There are m(m-1) stationary cache births and retirements, m(m-1) capture ADDs,
and m^2 decoder ADDs. Code acquisition, mode transport, all old-reader changes,
and owned retirement are separate real operations. The source movement per X is

    [c] + (m-2)[1] + [D-c-m+1],

and receiver movement per Y is

    [c] + (m-1)[1] + [D-c-m],

with zero terms/moves omitted. These expressions include the genuine initial
and final public endpoints. For D=8,c=m=4, both are [4]+3[1]. The caches never
MOVE; their births at proper charts are zero births followed by actual reads.

## 5. Literal reset benchmarks and the global stop condition

The root's source-reset theorem applies particularly simply to these completed
interfaces: the displayed remaining closure suffix contains no ADDs. The
separate reset builder copies each coordinate in the actual owned support S
from its native line to a ground owner, zero-initializes every old owner at its
actual cut chart, preloads every Y_i for i in S, takes public originals directly
to their cut charts, and appends the actual closure suffix verbatim. It completes
**every copied coordinate**, including61 and67 in the S54 case.

with profile54[1]+222[7]. It completes54 receivers, with moment

placeholders matching the old cut; removing them would reduce only ordinary

receivers. The pruned cohort therefore has no advantage for continuations that
the reset theorem covers and that do not need the old nonzero source values.

For the paid46-source cohort the actual support is all111. Its corresponding
literal reset completes all111 but costs111[1]+222[7], namely
**1649.953594222204937888199767835050435636186436**, above the necessary ceiling.
This full111 raw-copy benchmark is not a new useful multiplication bound.

Neither reset preserves free acquisition of future unknown-valued quartet
fields. A reset owner at C starts zero. An unknown quartet must still be
acquired and delivered by a real later source.

There is also a direct stop condition for repeating this particular mechanism.
At the pruned cohort cut, 57 coordinates lie outside every current owned row.
If new nonlocal information is provided only by fixed quartet fields and each
such field pays at least one new rank-one MOVE, at least ceil(57/4)=15 fields
are needed merely to cover these coordinates. Even granting all their source
acquisition, public detours, ordinary work and other requirements free, the
moment is at least **1625.9883424778408685...**, exceeding the ceiling. A field
that changes value en route, an already-paid delivery, a different code, or a
different source interface escapes this stated repetition premise. This is not
a universal impossibility theorem for shared corrections.

Thus the next productive construction must share changing histories or other
already-funded transport. Scaling the fixed quartets by endpoint count alone
does not have a viable all111 budget.
