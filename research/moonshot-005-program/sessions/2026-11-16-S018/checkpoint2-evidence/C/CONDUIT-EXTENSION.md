## Protected suffix lemma

In the protected-projection theorem, a raw backup need not itself travel from
the native line to ground. Suppose an actual stationary native owner R_d
captures rawx_d before immutable X_d departs. Suppose an already-paid
descending packet P has actual value zero when it reads R_d at L_d. After
that read, suppose its only computational source use is one ground read into
Y_d, while subsequent changes to P are reads of unchanged, simultaneously
available ground mask fields. Those masks are explicitly charged and contain
no released original coordinate.

Protect X_d→R_d, the native R_d→P load, and the final P→Y_d read. Delete
every other old read of X_d and R_d, and detach the original's old movements.
Project the rest of the old computation as before. Before its protected load,
P follows its projected old row. It is zero at the load by hypothesis, so
afterwards its row is Π_D(oldP)+x_d. Every subsequent ground-mask update
preserves that identity. Since its only source use is Y_d, this insertsx_d
exactly once into the projected Y_d endpoint and nowhere else. The old
remaining ground mask reads in Y_d still cancel the same projected mask.
Every other record obeys the original projection induction. The native
original can close raw at Hub or enter a separately verified collector word.

This is an actual protected data path through an already-paid packet suffix.
It is not a grant of a terminal value whose earlier acquisition disappeared.
The raw native capture, zero packet state, exact load, subsequent masks and
single own-output reader are all necessary source hypotheses.
