## Why the universal transcript argument holds

Fix every input outside the chosen J, including all original Y values.
Let each unfixed input record have the same finite nontrivial alphabet A.
At the cut, each record at chart H depends only on the selected inputs whose
native lines lie in H. After future operations, allow it also to depend on
the complete transcript of owned downward payloads already observed.

The induction is sound. Cocharted deterministic operations see only that
same local input set and the transcript. Zero-initialized births add no
input information. An upward move only enlarges the permitted local input
set. For a downward move, recording its entire payload makes its new value
known from the transcript regardless of which native directions the smaller
chart loses. CLEAR cannot create information. Granting upward moves to owned
records makes this bound more permissive than the actual downward-only
owned grammar and does not weaken the induction.

If every native line in J is absent from each final F_j, the final required
Y_j is a function of the transcript alone once other inputs are fixed.
The vector of required increments therefore reconstructs all independent
x_J from that transcript. With m descended records, at most|A|^m transcripts
are possible, whereas|A|^r independent input assignments must be distinguished.
Thus m>=r. This uses finite record capacity and does not assume linearity
of the continuation. It is not a claim for unbounded-width records or for
input information encoded in adaptive route or schedule choices.

For a linear cut, the actual column test is sufficient for the initial
functional-locality hypothesis: fixing the other inputs turns each surviving
nonlocal-zero column into no dependence. The proof does not need a separate
original-restoration assumption for its lower bound. Arbitrary temporary
original-Y feedback, original borrowing, cocharted nonlinear calculations,
and later inverses remain inside the invariant. They do not create a new
geometric communication channel.

The initial rho-record grant variant follows by putting those records into
the transcript before induction. Then m+rho>=r. A linear space that explains
all fields modulo their local rows supplies a sufficient optimistic grant.
This is a relaxation for a lower bound, not permission to materialize an
unavailable source in a construction.
