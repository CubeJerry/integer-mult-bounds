# A complete physical narrow finite-Core join

Prepared for **@CubeJerry**, with substantial OpenAI assistance. **No new κ.**

This package joins three actual global dense interior calls, two actual
complete sparse-union calls and their exact signed-word seams into the whole
five-factor narrow finite Core. It also implements the actual global
original-coordinate gather and inverse gather around that word. The sparse
payloads are the real first inverse window from #6908 and the real supplied
banded action from #6909; there is no numerical payload callback.

The all-size theorem is conditional on the exact retained physical/native
supplier contracts and source admissions. The selected #6030 record and all
five assumptions (`native_all_columns`, `owned_erasure`, `compiler`,
`precision_tape`, `analytic_recovery`) remain unchanged. This completes a specific source-bound
composition boundary; it does not claim a complete Gaussian/FFT/CRT multiplier.

## What is new

For one common original Reference, write
`Q=[[A,B0],[C0,D]]`, `F=D-C0 A^-1 B0`. The physical execution order is

1. `diag(A^-1,I_J)` through the complete dense cohort;
2. `(u_I,F^-1(u_J-C0 u_I))` through the complete physical union and #6908;
3. `diag(A,I_J)` through the same dense source;
4. `(u_I-B0 u_J,u_J)` through the complete physical union and #6909;
5. `diag(A^-1,I_J)` through the complete dense source again.

Every dense call covers the entire `T=K L^g` field. The sparse stages traverse
its K complete contexts. The controller carries the actual returned rounded
field between every pair of stages, including any possible dense boundary
drift. Dense/router source-axis order is bound explicitly. Exact converters
use the original dense input and output widths without changing their seals
or losing low grid bits. Long context keys and local addresses are raw streams;
no arithmetic counter holds the exponentially large local volume.

The exact factorization, union combinatorics, block solve, lift and generic
error telescope are predecessor results. The contribution here is the actual
complete physical caller, its common-source allocation, two global outer
routes, whole current-state chronology, protected-return lifecycle and complete
cost/backing compatibility. [PROOF.md](PROOF.md) proves the controller and
invoice; [NUMERICS.md](NUMERICS.md) supplies the independent numerical and
complete-rate interface.

## Reproduction

Python 3.12 and its standard library suffice. From the repository root:

```sh
python3 -B scripts/research_package.py --package research/complete-core-physical-join --check-only
python3 -B scripts/research_package.py --package research/complete-core-physical-join
```

The two registered commands run the complete physical K1 word plus all bounded
source, semantic, allocation, numerical and independent transport checks in
normal and optimized Python. Each command has a 600-second limit. Each child
uses a fresh bytecode-cache namespace. The exact original K1 receipts remain
unchanged; replay writes temporary results and compares their scientific and
machine-operation fields.

Useful direct commands are:

```sh
python3 -B research/complete-core-physical-join/replay.py --reviews-only
python3 -B research/complete-core-physical-join/verify.py
python3 -O -B research/complete-core-physical-join/verify.py --output /tmp/core-optimized.json
python3 -B research/complete-core-physical-join/check_physical_result.py --receipt /tmp/core-optimized.json
python3 -B research/complete-core-physical-join/verify_original.py
```

The last command is the longer K8 original-coordinate physical run; budget it
separately. The receipts state exactly what was run, and [VERIFICATION.md](VERIFICATION.md)
records the cleanup-check correction and byte-preservation correction rather
than hiding earlier failed checks.
In a self-contained source export, run `replay.py` directly; the standard
metadata launcher needs a Git checkout. The local optional full-history
preflight was blocked by the existing shallow repository, while raw committed
bytes, modes, canonical parent and exact source-tree pins were checked.
