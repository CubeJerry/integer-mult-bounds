## Failed checks and corrections

1. The first restored run opened the numerical and physical module cohorts at
   the same time, causing an import-namespace collision before physical work.
   The verifier now closes source loading before opening the physical cohort,
   while retaining prepared input-independent source objects. Source bodies are
   unchanged.
2. The first complete normal run reached all five outputs, then failed an
   overstrong final check requiring every private cell to be blank. There were
   615 native roles with marker/configuration content before any traffic. The
   correct check freezes initial configuration and compares the entire
   historical body after return consumption, allowing only erased initial
   markers or the exact initial configuration. Normal and -O complete runs
   then passed. No service or payload code was changed for this correction.
3. The saved #6895 audit manifest had an extra trailing LF: 2,540 bytes with Git
   blob 78d74bcd9e7a72d2406dadbebb7e67449bb73baf. Removing exactly that final
   byte produced 2,539 bytes and the public pinned blob
   8482832ef13929712a7e404cb18038571f03cc61. The copy was repaired only after this
   exact hash equality was established; the check remains active.
4. The independent K8 review initially required all eight complete Q matrices
   to be nonidentity. All regenerated matrices already matched the receipt;
   the two origin-4 matrices are exactly identity because of the actual source
   hole. The reviewer corrected only that scope gate to require the actual
   six coupled/two identity classification. The full normal/-O review then
   passed. This was a reviewer classification correction, not a service failure.
