## Uniform adapter and exact count

The proof correctly assumes that the encoded positive height agrees with
the unary width and that p>=h+1. Height preparation copies all p digits,
trims only the high zero suffix and retains that visited capacity. The
modulus, offset and row each copy h+1 digits and inspect every discarded
digit for zero. The modulus2^h high bit is preserved. The address copies
its exact h digits and appends a high zero. The offset's extra separator
is checked and charged.

The actual B4 output is read from its owned tape and retained in one of
two fixed control branches. The temporary unary marker identifies the
physical target cell; the address and width are traversed together. The
address bit is updated, the marker restored, and all six owned copied
inputs/output and eight B4 private roles return blank at their origins.
An arbitrary valid k implements the stated toggle primitive; the separate
layer corollary needs `k-1=min(j,2h-2-j)`.

Only the copied height extends beyond B4's former height span; its extra

supplied live frames. The stated historical bound follows, with retained

inconsistent framing, aliasing and arbitrary malformed rollback are outside
the success theorem, as explicitly stated.

## Actual caller, numerical freshness and reversal

The retained `emit_headers` obtains h and s from physical source records
and a from the live numerical result. The independent fixture serializes
moduli(5,7,2,3) directly onto those source tapes; it does not replace the
retained host fixture descriptor. The observed headers are h=2,p=5,s=3,a=2,
so this also rules out accidentally routing from the predecessor's cached
modulus-two fixture. The current row is a paid encoded counter, and the
current wire is physically copied anew at every point call.

The target walks positions1,...,h,h-1,...,1. Forward row numbers increase
from0; inverse row numbers are physically constructed as2h-2 and decrease.
Thus the row/target condition holds in either direction, including h=1.
After every call the address contains the newly routed current wire. The
opaque payload is passed physically, its destination key is written into
the existing key cells, and the retained stable radix program consumes it.

The review instruments lease opening, staging, closure and commit without
feeding those observations back into runtime operands. Every point observes
the actual live source/result snapshots unchanged, their heads returned,
the exact precision-guide endpoint and returned axis/half heads. Its copied
offset must equal that live result. Staging occurs while the selected lease
is live; closure retires it and releases the bank; commit follows closure.
Skipped leases are also closed. Source and payload backing identities remain
unchanged.

Direct modular inversion gives `2^-1 mod3=2`, hence destinations
`[2,0,1,3]` and tags `[730,905,293,3681]`. The actual forward source becomes
`(3,2,1,0)`. Inverse routing restores the complete original source, all key

## Independent checks and failure boundary

Six focused point fixtures cover unit modulus, the high modulus bit2^h,
a257-bit padded height with earlier80-cell histories retained, a valid
non-layer target k, a height17 full-depth middle half-turn, and a clean
zero-modulus rejection. Every point compares its sparse state with the
actual owner actions, whole borrowed frames/exteriors and all returned
heads. No backing object is replaced, and every owned guard is installed
then erased exactly once. Static checking covers all2500 instructions;
the universal derivation is not inferred from finite fixtures.

Three actual returning controls expose distinct missing obligations:

- A stale offset0 produces unchanged tag order, while the live numerical
  offset is2. All twelve header/lease comparisons detect that mismatch;
  source commit itself is still correct.
- A separately mutated table copies the original index only during the
  address-copy phase, while consumption still changes the current wire.
  At final row j=2 it returns1 at current wire2 instead of the canonical0
  (and the converse at current wire0). The caller returns with all owned
  histories retired, but its keys/tags are wrong.
- Using forward row order during inverse restores the source bytes but
  leaves the physical payload incorrect. Source-only restoration would
  miss this failure.

The actual producer rejects unit modulus before any point call, with
`CRT modulus exceeds one`. This is outside source admission even though
the standalone point theorem accepts it. No arbitrary malformed rollback
or cleanup claim is attached to that failed source invocation.
