## Endpoint chart audit

The chart covers every pair of distinct commuting rank-two endpoint
projectors. Their common image is nonzero because P_n e0 has final-row value
one. Commutation and distinctness make that intersection one-dimensional:
two commuting projections with the same image must be equal. The vector
P0 u_n is nonzero because v0 P0 u_n=-1. Consequently r=-v0(P_n e0) is
nonzero. This does not discard any admissible endpoint pair.

The two remaining one-dimensional atoms cannot vanish: b=0 would force
r=0, whereas c=0 would give v_n a=0. Both contradict the established
identities. The common kernel lies in K={x:x0=0, sum(x)=0}; the constructed
z lies in K and P0 z=e0, so K is the direct sum of the line generated by z
and the common kernel. There is no unmentioned generic-position assumption.

Within either face, both-sided query support forces the stated H columns
and rows. Invertibility of their Gram matrix implies independent columns and
surjective rows. A rank m+2 bank has H image exactly the span of those m
columns, which forces E=D(CD)^{-1}C. Allowing extra H rank would remove this
uniqueness, so the minimum-rank hypothesis is material.

## All-size trace extension

For odd m, let A have entries sgn(i-j), B have entries
(-1)^(i+j)sgn(i-j), and q=(1,-1,...,1)^T. Alternating sums give
Aq=0, B1=0, AB=I-1q^T, BA=I-q1^T and 1^Tq=1. Hence, for s nonzero,

\[
(A+s11^T)^{-1}=B+s^{-1}qq^T,
\qquad K^{-1}1=q/s,\quad 1^TK^{-1}=q^T/s,
\quad 1^TK^{-1}1=1/s.
\]

For even m the last sandwich is zero. The odd formula always applies in an
actual face because its parameter is 1/r or -r, never zero.

For two ordered groups whose cross-pairings are α11^T and β11^T,
EF has rank one when α is nonzero and
tr(EF)=αβ(1^TK_I^{-1}1)(1^TK_J^{-1}1). The injectivity and surjectivity
above ensure that this rank-one product really is nonzero. A nonzero
rank-one idempotent must have trace one in every field.

For the same face this trace is zero if either size is even, and otherwise
1-1/s². It is never one. At s=1 or -1 one orientation is zero but the other
is nonzero, so the argument still applies. Therefore there cannot be two
ordered minimum-rank banks of the same face, for any positive sizes and
characteristic different from two.

For R before L, both cross coefficients are nonzero in characteristic
different from two. The trace is zero if either size is even and otherwise
four. This excludes commutation except possibly when both sizes are odd
in characteristic three. L before R still has zero cross-pairings in either
parity. Thus the extension is a theorem, not an inference from the finite
test coverage below.

## A genuine characteristic-three scope control

Over F3, take n=4, r=1, z=(0,2,0,1)^T, and the basis with columns

\[
a=(0,2,2,0)^T,\quad b=(1,1,1,0)^T,\quad
c=(1,1,0,2)^T,\quad h=(0,2,1,0)^T.
\]

In that basis, set P0=diag(1,1,0,0), Pn=diag(1,0,1,0),
Q_R=diag(1,0,1,1), and Q_L=diag(1,1,0,1). These four projectors commute.
The endpoints support R0 and R4; Q_R supports R1 and Q_L supports R2 on
both sides. Both internal banks have minimum rank three, but the right
group precedes the left group.

This witnesses failure of the all-odd ordering extension in characteristic
three under the theorem's support-only hypotheses. It is **not** a native
caller root: prefix commutation fails at sites 1 and 2 for the canonical
prefixes generated by I-2R_i. It is not an exception to the original even
theorem or the all-size one-per-face bound. The checker outputs all four
conjugated projectors, so this witness is reproducible without relying on
the accompanying explanation.

specified endpoint faces, noninterleaving ordered groups, and minimum H

with the actual root; this review does not replace its complete caller,
