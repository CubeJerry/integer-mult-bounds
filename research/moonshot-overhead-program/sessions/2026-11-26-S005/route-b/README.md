## Exact checks

Run from this directory with Python's standard library:

```sh
python -I -B verify_collision_and_invoice.py
python -I -B review_rowspace_rank.py
python -I -B verify_spectator_span_lift.py
python -I -B verify_bell_outer_boundary.py
python -I -B verify_finite_algebra_seams.py
python -I -B verify_carry_remainder_independent.py
```

Each script writes a local JSON receipt with the applicable proof or
review hashes. These are exact finite supporting computations, not
simulations of an unbounded tape multiplier or new Lean proofs.

SF covers 5,054 ordered spectator fibres, 1,157,324 exact character
entries, 74,954 transformed integer entries and 2,075 coset Gram blocks,
including 780 degenerate blocks. BO covers 16,368 product coordinates,
16,368 diagonal coordinates, 336 literal conjugated matrix columns,
the unitary third-root adverse control and exact endpoint invoices.

The fresh finite-algebra controls cover literal total-grade factors,
whole cyclic identities including zero cases, negative-offset predictors,
ordinary shift moments, extension-field independent module repair and
coarse-role padding. They are newly written targeted checks; they do
not claim a rerun of all historical suites. The CRT carry control
reconstructs the b=2 matrix by integer polynomial division and checks
all Boolean inputs/polarization pairs plus actual lifted addition
circuits. General higher-precision carry identities were reviewed
algebraically without an expanded experiment.
