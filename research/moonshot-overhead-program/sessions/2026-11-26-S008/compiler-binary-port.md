# Kernel-checked binary-addressed word access on the original tape model

Let an occupied memory bank consist of delimited $b$-bit binary words, and let a marked value register contain another arbitrary $b$-bit word. An independent $B$-bit, most-significant-first address tape represents $i$ and may have leading zeros. The cell before the origin of each register or bank is a marked home. An access may start with arbitrary absolute bank and value origins $p,q$; all cells outside the specified memory prefix, register or address are unrestricted. The two initially empty private tapes each have a home marker at offset $-1$. Write $h$ for the number of one bits in the address.

[The five-tape source](compiler-binary-access.lean) defines separate load and store opcodes, each with 23 states and a six-symbol tape alphabet. The theorem S008.Compiler.Binary.binary_access computes the literal deterministic transitions of the original OpenAI TM model. A load fills the marked register with the independent word at index $i$. A store changes that word to the marked register's original contents. Each selected bit and every absolute position outside the written word satisfy the source's named read, write and exterior-preservation laws. The other external data are preserved everywhere. Both private tapes return to their original contents, and all five heads return to their original absolute positions. The next transition halts. The exact time is
$$
      i(2b+15)+3b+8B+19-5h .
$$

The [index converter](compiler-unary.lean) begins with the actual binary word and performs the recurrence $k'=2k+d$ for each scanned digit $d$. It erases the previous unary output while writing two marks per old mark to its temporary bank, plus the new bit. After returning the first bank to its home, a backwards traversal moves the new word from temporary to output. The temporary bank is empty again at the next digit. The per-digit time is $7k+2d+7$. Finalizing a unary word of $i$ marks and real right delimiter while restoring the address requires $2i+B+6$ further transitions. The converter's exact total is $9i+8B+6-5h$.

The [occupied-word transfer](compiler-indexed-transfer.lean) now takes this generated unary index. Its proved clock $i(2b+4)+3b+9$ covers the selected word, the retained occupied data and all three local returns. The ambient rule then clears the $i$ private unary marks and the delimiter in $2i+2$ transitions. Two finite-state dispatch transitions join the three programs. When a subprogram runs, each extra tape rewrites its currently scanned symbol and stays at its own absolute position. The source proves this simulation for every actual transition, so no virtual bank lookup, unary conversion or private erasure remains in the instruction.

## Physical resource bounds

Let $M\ge1$ be the number of available slots and suppose $i<M$, $B\le b$. The [original visited-cell certificate](compiler-binary-space.lean) proves that this port uses at most $40M(b+1)$ transitions and visits at most $205M(b+1)$ tape/address pairs, including both endpoint positions. Its finite-set proof selects the single deterministic endpoint after each elapsed step; the five heads at those endpoints cover every original-model visit. Substituting $M=m^{32}$, $m\ge4096$, $b+1\le m$ gives kernel-proved bounds $m^{37}$ transitions and $m^{34}$ distinct cells, exactly as required by the [finite controller](compiler-controller.md). The source theorem concerns load/store as an instruction. The finite field, predictor compiler, other arithmetic instructions and complete native program keep their individual written proofs.

A sharper direct head-by-head count is $i(b+3)+2b+B+10-\mathbf{1}_{B=0}$. The memory head reaches its home marker through the selected delimiter, the value head its home through its own delimiter, and the binary tape its home through the final $B$th position. The two private unary heads reach offset $i$ and visit their home markers, except that a zero-digit input never displaces the temporary head. The exact sharp count has a written proof and executable checks. The looser $m^{34}$ bound above is formally checked using OpenAI's VisitsAtMost definition.

## Independent reproduction

The [rule exporter](compiler-binary-export.lean) evaluates both opcodes on all $2\cdot23\cdot6^5=357{,}696$ scanned-symbol tuples. [A separately written interpreter](compiler-binary-access.py) compared their complete normalized rule rows byte for byte. The SHA-256 digest was d46534c565d53c2b56e8aa712cff6e666123f7c6c3d735d87288e530a0b6bf59. The interpreter then performed 4,918 independently populated operations and 460,484 literal transitions. It checked every absolute external and private tape cell, all head positions, halting, the exact clock and the sharp distinct-cell formula. The largest sampled operation used 4,042 transitions and 1,792 distinct cells. The examples include displaced or negative bank/register origins, leading zeros, empty binary encodings of zero, and unrelated occupied data beyond all three external words.

[compiler-check-lean.sh](compiler-check-lean.sh) verifies pinned original source blobs from OpenAI commit 3344da59991ed94f9ba711217b29c1d760badfa6 and mathlib commit d13f23b723b8a846827a245b89c10fc7d3f11612. It builds all five proof sources using Lean 4.34.1 with warnings as errors and runs the independent three-tape and five-tape table comparisons. The main endpoint/time and controller-space theorems report only propext, Classical.choice and Quot.sound. The word-encoding assumption is explicit. A caller whose address arithmetic is little-endian can reverse its short address by a charged $O(b)$ marked copy as described in the controller; the five-tape source accepts the resulting most-significant-first address word.
