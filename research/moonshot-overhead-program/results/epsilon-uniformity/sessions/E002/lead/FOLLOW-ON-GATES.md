## What the geometric obstructions do not prove

The four-box argument concerns one-sided variation spaces, not every larger
endpoint space or a general sparse change of basis. The common-coset
argument concerns preserving the physical query coordinate, not arbitrary
query-touching permutations. The application-volume count concerns the
fixed separate map list, not the number of records actually moved or the
minimum number of physical passes. Sharing, cancellation, different kernels
and different endpoint architectures remain possible.

In particular the query application-volume theorem does not contradict
RV-W, which explicitly allows polynomial-m ordinary address work. It
invalidates the sharper proposed numerical address gate only for a compiler
that continues billing each listed map as a separate full-volume primitive.
No result here lower-bounds actual multiplication time or rules out the
exact square-root endpoint.
