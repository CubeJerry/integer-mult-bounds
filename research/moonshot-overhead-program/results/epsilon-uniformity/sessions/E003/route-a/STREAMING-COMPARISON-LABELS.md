# Simultaneous comparison labels without full-volume mask tracks

fixed template. This note supplies the growing-parameter space refinement
needed by the on-demand spectral table: keep all m current comparison

## 1. Exact interface

Let a stream have lexicographic shape

    [P] x [Q]^D x [S],

where Q>=2, D>=2m, and all m pairs of controlled field positions
`(H_j,N_j)` satisfy `H_j` before `N_j` in the field list. The other
fields are occupied spectators. External P and S can be arbitrary positive
integer ranges. Put V=P Q^D S, counting encoded bits. Range descriptors
are binary and there is one fixed finite alphabet.

At a controlled tuple the required label is

    lambda_j = sign(H_j-N_j) in {-1,0,1}.

A pointwise coefficient routine receives the m current labels and a
compact parameter description. It may use poly(m) actual bit operations
and temporary bits to choose a coefficient or a polynomial-size small
matrix. It may then apply the coefficient to the following S-bit suffix
with its separately proved polynomial-m per-bit arithmetic bill.
The routine does not request an output array containing all labels.

**Theorem CL.** A fixed multitape processor can supply this interface in
`V poly(m,D)` actual steps, plus fixed-degree descriptor setup, using

    O(V)+poly(m,D,log(2Q),log(2S),log(2V))

cells ever visited. The constant on V is absolute. Only one current label
tuple is stored. Under polynomial-m dimensions and the large-field guard
of G4, the additive region is absorbed into an absolute O(V) bound.

## 2. Nested run scan

Scan the D controlled/spectator fields by nested counters in their physical
lexicographic order. At the entrance to an N_j loop, its H_j value is
already fixed by an earlier counter. Replace the ordinary Q-value loop by
three consecutive runs:

    N_j=0,...,H_j-1       label +1,
    N_j=H_j               label 0,
    N_j=H_j+1,...,Q-1     label -1.

Zero-length runs are skipped. Store these three lengths in binary and use
amortized low-end countdowns; set the j-th label flag only when its run
changes. A single separate control tape holds the m current flags. Its
head may scan all m flags when one is updated or when the coefficient
routine reads the tuple; this costs polynomial m per such event.

Earlier H_j values are stored in the controlled-field counter region of
size O(D log Q), separate from the possibly very long outer prefix counter.
Reading one such value at the entrance to an N_j loop costs at most
poly(D) log(2Q). The list of controlled field positions is of polynomial
size in m,D. It is never confused with an expanded table over all tuples.

At the innermost controlled tuple, all m flags are valid simultaneously.
Run the small coefficient routine and process the suffix, then resume the
nested scan. No m-bit header is appended to the suffix and no mV-sized
mask track is retained. Masks needed on a later complete scan are
regenerated by the same processor.

## 3. Actual-step accounting

For any N_j loop, fix the prefix ending immediately before that field.
Let S_j be the size in bits of its full remaining suffix, including later
controlled fields and the external S. Computing its run lengths and
preparing its counters costs a fixed polynomial in
`m,D,log(2Q),log(2S_j)`. Since

    (log(2Q)+log(2S_j))^c <= C_c Q S_j

for every fixed c, this setup is paid by that entire Q S_j-bit fiber.
Summing over all such prefixes costs V poly(m,D) for this field, and
summing over the m controlled fields retains the same form. This is
exactly the source's per-fiber amortization, with the number of fields
made explicit.

Counter advancement and return are amortized over their complete scans.
Use an end-access stack for the nested counters. The deepest counter
remains at its low end between successive payload positions; it is not
reread in full for every datum. Entering or reinitializing a deeper loop
is charged to the complete fiber just described. The outer P counter is
advanced and tested without rescanning its whole contents per tuple.
The suffix loop has the same elementary-stream implementation.

Reading all m flags and running a polynomial-m coefficient selector once
per controlled tuple costs at most V poly(m), because S>=1. Its arithmetic
registers are reused. If a small row operation needs several complete
passes, each pass regenerates the flags; a polynomial number of such
passes increases only the polynomial coefficient in time.

## 4. Space and exact field masks

The current labels need O(m) bits. Field counters, loop return state and
run lengths need a fixed polynomial in m,D,log Q,log S and log V bits.
They occupy a single reused control region. The scanned data, optional
output accumulator and one arithmetic work stream occupy an absolute
number of complete V-bit regions. Marking and reusing these regions
bounds all visited cells.

Characteristic-two order-three spectral values distinguish equality,
ascending and descending addresses, so the three labels supply exactly
the E002 selector's input. All extension-basis coordinates and all opaque
payload bits use the same address label. FP1--FP3 permit them to be
processed successively without storing a separate mask for each coordinate.
Computing small check coefficients on demand therefore adds polynomial
time per encoded volume and additive control space, not m copies of the
parent payload.

The proof requires the stated ordered-pair layout. It does not prove
constant-space streaming for arbitrary predicates of an unstructured
address permutation. Callers must invoke it at the ordinary spectral
address layout specified by the source conversion, or pay for a justified
change into that layout. It does not move a mask through an unperformed
converter.

from the nested-run and source scan proof; finite replay can check every
label and transition at small Q and D, but cannot replace the amortized
fixed-tape argument. The result supplies one previously implicit component
of the absolute-array premise in G4.
