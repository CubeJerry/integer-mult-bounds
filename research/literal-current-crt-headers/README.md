# Construct current CRT leaf headers from the actual encoded source

One fixed **21513-instruction, 27-role** graph replaces the exact current
`emit_headers` controller and can continue directly into the unchanged
complete all-wire destination-key pass. It reads the actual source records,
current axis cursor, precision guide and numerical result; constructs the
exact H/S/A/zero-row/unary-width streams; preserves borrowed contents and
returns their heads. A separate literal entry retires all five outputs
after the retained radix/source continuation.

**No new kappa.** This is a uniform typed primitive and a bounded actual
caller join. Numerical offset production, current-lease acquisition,
physical grants, full source/radix orchestration and the selected five
foundational assumptions remain explicit. The multiplication bound remains
conditional.

## Exact source and scope

Canonical base: `e54523517d0f03e58352e647c403a5af3e525a57`.
The header source is CrocSwap/integer-mult-bounds#7388 at
`d6f4a69202ad0bba4a915f4d4f3eaba1fe431c86`. Its no-target `_record` helper
validates both padded fields; `copy_numeric_field` reads the actual current
result. The actual selected caller is the admitted last nonroot leaf.

The complete key child is published CubeJerry commit
`f789e7318ef89b26c2e358c4c1eb09ce93d21f73`, package
`research/literal-all-wire-crt-keys`. All 21135 child instructions are
embedded once without changing their operations. The inherited **fixed
13-bit codeword / arbitrary 12-bit opaque payload ABI** remains in force.
Full sorted roundtrip restoration requires original physical-position keys;
inverse-key emission does not undo arbitrary old key overwrites.

The local theorem admits positive source widths, a nonempty prefix, matching
actual guide p=u+h+1>=4, and a valid current p-bit result. It proves matching
binary height and unary width from the same source marks. It does not infer
a current lease or numerical offset from framing alone. Failure cleanup on
malformed input is not promised.

## Complete prefix and historical costs

Let m be the number of prefix records before the left record, U the sum of
all m+1 skipped widths, W their maximum, h the current right width, and p
the actual precision. The exact construction cost is

`B = 6ph + 53p + 41U + 57m + 42h + 199 - popcount(h)`.

Retirement costs `28p+7h+53`. Each joined direction has B+2 header
instructions before all unchanged B7 work. The complete source prefix is
paid: its terminal RIGHT lies `3U+4m+3h+9` cells from LEFT. This is
O(L_source+L_result+p(h+1)); no bound on prefix widths by current p is used.

The actual iterator's temporary width role is reused and fully cleared.
Its historical window is W+3 cells, even if W is much larger than p. Count
the union with every older per-role history, including borrowed access
windows and unchanged B7 histories. All source access, owner grants and
backing acquisition remain supplied and charged capabilities.

The exact native-action overlap inside the literal graph is
`30U+47m+12h+20p+113`; actual native, marker and payload overlaps are
subtracted once from retained source meters. The resulting finite caller
invoice remains a cost vector with the retained numerical/radix models.
No common whole-caller bit tariff or runtime gain follows just from
removing host control.

## Actual join and verification

The exact four-tag caller and its modulus-three/left-two variant both run
forward and inverse with the original source and literal radix providers.
For the sensitive variant the new complete literal bills are 25679/25835;
they include 1051 header and 207 retirement instructions per leg. Remaining
source symbol counts are 117453/359559, remaining marker14, remaining
payload156, and unchanged radix43162 per leg. Full source bytes, payload,
identity keys, heads and the 200-owner retained history union return.

Normal and optimized author receipts are byte-identical. They cover
61 header packets and 447764 construction/retirement instructions, including
W=4097 with p=5, a 126-record prefix, h=129, p=260, translated origins and
larger old histories. Every output matches both direct arithmetic and the
exact original helper. Twenty-one controls include malformed domains,
child relocation drift, returning wrong fields, omitted erasure/head return,
and actual caller faults with correct numerical source but wrong payload.

An explicit meter audit resolves an initially suspected omission: the actual
guide is bank[0] and result bank[62], both already counted. The original
helper's 592 native actions were all included; the omitted count is zero.
See METER-AUDIT-RESULT.json. This is not a correction to older results.

Run from the repository root:
