## 1. Exact observation and claimed implication

Fix the provider bindings used by the pinned inverse Endpoint.run. Its
input is the admitted padded axis source, source head one and initially
clean private roles. All numerical/entry/ownership correctness hypotheses
are those of the pinned inverse theorem. Clients obey its linear-use
interface: there is no external mutation or escaped stale lease during
run. The producer's fault parameter is None.

The scientific observation consists of the actual supplied source tape
and head, every physical private tape and head, successful termination,
and the charged source-operation and retained-history bounds. It excludes
Python addresses, garbage-collector behavior, diagnostic Meter values and
Python execution time. Diagnostic erasure preserves the full local-action
trace. Finite-slot normalization may permute independent final erasures;
that step preserves their endpoint and complete bill, not their ordering.

**Projection lemma.** On every admitted successful run of this exact hot
closure, removing diagnostic updates, abstracting each backing/head pair
as one actual tape/head, and replacing fixed-role metadata by finite control
yields a fixed finite-control program. Only the invariant host-position
atoms identified below are discharged; all action-producing argument
evaluations and their short-circuit order remain. The program has 80 data
tape roles, including the supplied source, independent of d, widths, moduli,
coordinates and prior source-tail capacity. There is a fixed constant c
such that its complete finite-symbol execution takes at most c(T_raw+1)
steps, where T_raw counts the actual hot Word/Port reads, writes and unit
moves. No input-dependent cycle consumes zero such actions.

The program preserves the inverse endpoint, borrowed source metadata and
history, prescribed heads and complete private erasure. It retains the
source theorem's arithmetic and entry postconditions; this lemma proves
neither CRT algebra anew nor their unconditional validity by testing.

Let A, M, P_G and D be exactly the quantities in the pinned inverse proof.
In particular M=2+3A+4d and K_source+D is its total retained-backing bound.
Its explicit raw-action envelope may be substituted without relying on an
unexpanded C_inv:

    R = 2^19(M+2)^2 + 4096
        + sum_G [2^21(P_G+2)^4 + 2^16(P_G+2)^2 + 4096].

There is consequently a fixed c with total refined source cost <=c(R+1).
The value of c is not computed here. This is the exact existential edge
under audit, not a claim that the Python interpreter runs in that time.

The proof constructs a finite program schema: finite sets can be enumerated,
role dispatch expanded and calls inlined. No transition table, exact
instruction multiplier or executable literal binary endpoint is claimed
to have been emitted.

## 2. Resolve the actual providers before examining host operations

The important dispatches are not their same-file defaults:

- Endpoint binds the inverse Iterator subclass to the frozen frontend. Its
  constructor calls base doubling explicitly; its level hook halves.
- Bank.open supplies adapter.Port=bank.take and a Reentry subclass whose
  new_port returns an existing bank role. The default Entry.new_port is
  not used on a numerical reentry.
- The frontend supplies its own NodeEntry through its _entry bridge.
  bridge.py contributes only canonical_end. Its original compiled-geometry
  RowEntry, including len(widths), bit_length and range(node size), is cold.
- Entry.invoke supplies records.Tape=output_factory, returning the one
  existing output port. The original Tape constructor/write implementation
  and its bulk extension are cold.
- Entry creates Arena and HostedWord metadata with object.__new__. It does
  not run Word.__init__ or Arena.__init__, which use eager width-sized lists.
  All 64 numerical slots already exist when produce begins.
- Arena.zero's constructor fallback is unreachable: eight slots are protected
  and the inherited producer peak is at most 24 other live slots, leaving a
  free private slot whenever another is requested. No hot allocation reaches
  Word.__init__.
- Arena.literal is called only with the compiled constant 1. Its bit_length,
  tuple and range expressions therefore have fixed size. Numerical input,
  inspect, times_small, Ring, rollback and the records stack/program/fixture
  machinery are not in this call closure.

An AST scan of entire files without these bindings would incorrectly import
cold geometry decoding and eager constructors into the scientific program.
Conversely, a check of only the new inverse adapter would miss its actual
primitive interfaces. INVENTORY.md lists the resolved closure explicitly.

## 3. Erase diagnostics without erasing scientific dependence

The hot references to Meter fields are read/write/move/allocation increments,
the peak_live maximum update, and initialization. A counter is read to update
itself; it is false that the source never reads counters. The necessary fact
is that its value cannot reach a scientific condition, symbol, direction,
role selection or returned numerical word.

This follows by inspection of all hot references, not from the counters being
small. Meter.record is cold. Update statements write only a diagnostic field,
and no other hot statement consumes those fields. Replacing them by no-ops
leaves all remaining statements and decisions unchanged. Arbitrarily different
initial diagnostic values therefore give the same scientific execution after
erasure. The peak-live field is bounded anyway; the others are not.

For example, take two axes, moduli(2,3), zero coordinates and common declared
width h>=2. The source length is 6h+10 and staging scans it. Head positions,
backing lengths and diagnostic counts are unbounded as h grows. A proposed
finite-value closure including all those Python integers would be false.
The projection places heads/backing in the tape configuration and erases
diagnostics; it does not call them finite-control integers.

The orchestrator's independent perturbation evidence uses ordinary,
permanently zero and huge signed counters on actual hot runs and compares
full local-action digests and final tapes. A counter-read mutant changes the
digest and is detected. Those finite executions support the source-use
argument; they do not prove its universal quantifier.

## 4. All remaining scientific host metadata is finite

The physical data roles are source, bank B0..B62, guards G0..G7, seven
topology roles and staging: 80 in total. The bank cursor ranges over 0..63.
Entry.control is reset per context and reaches at most 124, from 64 slot-loop
increments and 60 new-port handoffs. It is not a global node counter.

The role map is fixed. Canonical guide/left/right use B0/B1/B2; slots 8..63
use B3..B58; template uses B59; padded left/right/output use B60/B61/B62.
Slots 0..7 alias the guards. Every runtime reference to one of these objects
is a tag in a fixed finite set. Role identity, dictionary field selection
and slot access expand to finite dispatch among literal tape names. No
coordinate or precision selects a host array index.

The numerical available list has at most 56 distinct private slot tags.
The live/protected/keep collections are subsets of the 64 slots. Their sizes,
membership, comparisons and stack operations have finite domains. A scan
of all 64 slots is a uniform implementation. The producer's live-set iteration
disposes slots in its final cleanup. Those erasures act on distinct words
and commute. Their order affects only the unused end-of-context available
list: only result disposal and context closure follow, and the next context
resets its available list. Fixed-order cleanup therefore preserves the
endpoint, with an at-most64-slot scan. Every live word has the same current
P-bit extent and returns its head, so changing that final order does not
introduce a hidden variable-width or seek cost. No Python hash-table timing
assumption enters the refinement.

Other hot collections have fixed bounds: 64 wrapped slots, 60 Entry-owned
ports, 63 bank ports, eight guards, seven counters, two fields per descriptor,
and at most 11 free_many arguments. Context/result field schemas are fixed.
Per-node wrapper, Lease, class and Arena objects describe the one current
context. Under linear use, obsolete wrappers cannot be queried and have
no scientific observer. Their metadata can be recycled; their physical
tapes cannot be forgotten. This is not a bound on the host garbage
collector's retained heap.

The scalar locals also have fixed domains:

- Tape symbols belong to the 14-symbol alphabet; phase, seen/valid/last,
  parity and borrow/carry indicators are Boolean.
- Unsigned comparison state is -1,0,1. Addition totals are 0..3; subtraction
  digits are -2..1. The int conversion in subtract is a Boolean borrow.
- Quotient, remainder, inverse, reconstructed integer, products and offsets
  are word-role references. Their numerical values are not host integers.
- arena.bits is an Extent object backed by the unary guide. Its only hot
  observation is >=4, implemented by four local reads and a paid rewind.
- Providers, callbacks, error messages and phase states are fixed. The
  fault parameter is None. No source-level generation number is created.

Thus finite control may be large but is independent of every input size.
Unbounded values occur only in the tape configuration or erased diagnostics.

## 5. Head, origin, length and identity assertions

### Port primitives

Map backing to its tape contents, extended by BLANK beyond the retained end.
Port.read is exactly the symbol at the actual head, including default BLANK.
Port.write overwrites that cell or appends one cell at the current frontier;
it never performs a variable-distance gather. Port.step's index increment
is exactly one physical move.

A valid trace never writes with head greater than retained length. A forward
scan reads an existing nonblank token before stepping, or appends a symbol
before stepping. A delimiter-driven scan can reach the first blank cell at
the frontier but does not step through that blank into an unallocated gap.
Canonical trimming and returns move backward over existing cells. Width,
half, axis and depth loops are driven by their actual tokens; record parsers
stop at the final RIGHT. Constructor marker installation and its first move
also satisfy this invariant. These cases cover the hot Port movement sites.

Every rewind enters at head at least one with a unique logical LEFT at zero.
Its first left move and LEFT-terminated scan cannot cross zero. Numerical
scans that intentionally finish on LEFT explicitly move right once before
returning or freeing their word. Marker retirement clears LEFT after a
completed return, then moves right once. No subsequent rewind uses that
retired marker; reacquisition restores it first.

Hence Port.step's nonnegative-index assertion is an invariant. Its direction
already has the finite values +/-1. The local move replaces the host index
arithmetic on this domain.

### Word primitives and backing extent

Entry.word_storage or guard preparation reserves at least P+2 cells on
every current numerical role. Allocated words have LEFT, P bits and current
RIGHT. Unused private words are blank inside the reserved extent and are
only origin-retired, not numerically scanned. Arithmetic reads/writes and
returns stay in positions 0..P+1: forward loops stop at RIGHT, backward
loops stop at LEFT, and they explicitly step right before returning. Old
blank suffixes cannot substitute for a current delimiter.

Thus Word.step's `0<=head<len(cells)` guard follows from current extent and
retained capacity. The only hot HostedWord.head setter is reached through
Word.step, with value previous head plus/minus one. That assignment is a
unit move, not a free seek. Word.read/write access only the current cell;
their properties expose the actual Port backing/head without a copy or a
shortened view. Word primitives access the Port representation directly,
so their counted action is one local action; it is not an extra Port action
to be counted a second time.

### Retired heads, aliases and exceptions

Bank.take/release's head==1 atoms follow actual return/retirement invariants.
Initial acquisition and the fixed role map imply bank/source/guard separation.
The id-based tests inspect only equality among this inventory; absolute
addresses are unnecessary. Word-arena and word-alias checks concern current
fixed tags. In particular, a==b in unsigned arithmetic still distinguishes
the alias case and does not duplicate a physical move.

**Assertion discharge does not delete argument evaluation.** For example,
Bank's `head==1 and port.read()==BLANK` retains its actual Port.read;
`need(not denominator.zero())` retains the full Word.zero scan; the >=4
Extent observation retains its reads and rewind. Only the invariant pure
host-position atoms become constant true. Their established truth preserves
the successful source's original short-circuit decisions. All symbol-reading
and finite-metadata conditions can be retained as finite guarded branches.
No condition is discharged merely because a finite test passed it.

The finally blocks that consume results and erase scratch remain. Constructor
and inspect monkeypatch bookkeeping may be erased because the resolved
successful closure never invokes those forbidden operations; their restoration
carries no scientific data. The simulation does not claim the source's exact
behavior on arbitrary malformed streams, corrupted heads, foreign aliases,
interruption or unbounded escaped stale-handle histories.

## 6. Fixed call depth and absence of uncharged control cycles

The resolved method-call graph is acyclic. Shape/record helpers call local
canonicalization and Port methods. Numerical produce calls Arithmetic;
inverse calls multiply/remainder/subtract, which call Unsigned primitives;
those call Arena/Word primitives. Rewinds call only step/read and guards.
Entry/owner callbacks terminate in these same helpers. No callee recursively
invokes an ancestor. Class/subclass dispatch does not create recursion:
the base doubling and inverse halving methods have distinct fixed bindings.

The call stack consequently has a fixed maximum depth determined by these
finite files. Calls can be inlined or their continuations stored in bounded
finite state. A variable number of loop iterations does not create frames.

Every unbounded iteration consumes a counted local action. Frontend, writer,
canonicalization, parser and Port loops test read symbols. Word loops scan
read symbols. Euclid tests Word.zero, which itself reads the word; numerical
multiply/product loops scan actual bits. Endpoint.run can repeat only after
a successful step, which processes a nonempty node and stages/commits a
complete source. The unique terminal step returns false and cannot generate
an idle positive loop.

Loops without a local observation have fixed bounds: the slot/role scans,
two-field passes, finite free_many tuples and the constant-one literal.
Their sets/lists cannot increase those bounds. After these bounded loops
and the acyclic calls are expanded, a segment with no Word/Port action
cannot contain an input-dependent cycle. There is a fixed maximum length
for such a segment. Expanding finite role/symbol tests into decision chains
therefore proves the constant c in Section 1. Initialization, the terminal
test, bounded cleanup and finite metadata disposal are included. The bound
does not extrapolate an instruction multiplier from measured execution.

## 7. Visited span and four-bit realization

The primitive analysis gives an explicit space consequence. Let K_j be a
data role's maximum retained backing length during the run. Its Port head
never exceeds K_j; a live Word head is strictly less than its role's
retained length. Positions are nonnegative. That role therefore visits
at most K_j+1 source positions. Over the 80 data roles,

    total visited source positions <= K_source + D + 80.  (1)

This includes staging's one-past-end visit and the analogous possible visits
in guides and temporary streams. Erasure does not subtract K_j; shrinking
current precision does not shorten historical backing.

For a supplied tape representation over the 14-symbol alphabet, use four-bit
codewords with BLANK mapped to 0000. For example, map source symbols 0,1,2,3
to codes 1,2,3,4; map BLANK 4 to 0; and leave codes 5..13 unchanged. The 14 codes
are distinct. Logical cell j occupies bit positions 4j..4j+3, with heads at 4j
on source-action boundaries. This explicitly avoids treating source integer 4
as physical blank bits.

A read/write scans four bits and returns to the codeword start. A source
unit move takes four bit moves. All finite symbol and role choices become
fixed decision chains naming literal tapes. Inlining bounded calls/control
thus gives a fixed bit-step multiplier C and a constant initialization and
control-erasure charge C0. For a fully encoded supplied history,

    T_bit <= C(R+1),
    visited/retained bit capacity <= 4(K_source+D+80)+C0.  (2)

These are existential constants, not generated instruction counts. Private
logical erasure becomes all-zero codewords. Borrowed source codes and head
alignment are preserved. If an inaccessible incoming tail uses a different
physical representation, its actual supplied bit capacity remains a separate
invoice: four bits do not silently encode arbitrary out-of-alphabet host
bytes. No tail serialization or initialization is provided for free.

The actual caller still owes the source representation and its production,
alignment, role separation and owned-entry contracts. An embedding into a
different prescribed physical role/tape interface is also separate. These
equations refine this source helper on its admitted entry, not an entire
selected machine or multiplier.

## 8. Novelty and retained limits

Canonical #5486 already emits a literal lowering for its exact fixed-geometry
CRT repair program. It does not cover this variable-precision numerical/
endpoint closure. #5219/#5505 establish source entry/reuse and explicitly
leave literal lowering open. The current #7154 and inverse notes assert
an existential finite-control refinement without this transitive closure,
head/length/assertion projection and all-role visited-span account.

The result is a scoped verification advance: exact justification of that
existential edge, an allocated-to-visited span bound for the actual closure,
and a delimited binary representation corollary. It is not a newly executed
CRT algorithm or CRT identity. The complete bound and all five foundational
assumptions remain conditional.

The universal claim rests on the source case analysis and inherited domain
invariants. A diagnostic-use checker and finite counter-perturbation controls
can detect specific violations; they cannot prove arbitrary noninterference
or replace the manual dispatch/loop inventory. Independent human and
proof-kernel acceptance are not claimed.
