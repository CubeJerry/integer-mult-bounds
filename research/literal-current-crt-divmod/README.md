# Bind a literal divider to the actual current CRT leaf

This package lowers the sixth raw division of the actual one-left/one-right
current CRT producer into one fixed336150-location68-role program. Its64
numerical roles are the existing eight borrowed guards plus56 owned Word
ports. Six-bit descriptors and paid literal dispatch select current roles;
four existing pre-header marker owners receive explicit eight-cell grants.

The exact source call is left modulus divmod right modulus. The proof
derives its margin from the actual guide and shows how changed allocation
events can be related to the original continuation by a live/free-slot
bijection. Disjoint final clears commute, after which the free-stack
relation is rebuilt. Old physical histories are not permuted or discarded.

For width P>=4, the logical divider executes exactly
18P²+36P+458+(12P+9)popcount(floor(N/D)) instructions. Every numerical read
expands to30 literal instructions and every write/move to31, including all
descriptor head returns. Full literal acquisition, descriptor setup,
division, rebinding and output retirement cost <=2^14(P+2)². External
metadata binding and actual allocation have separate charged premises.
The result makes no kappa claim and retains all five full foundational
assumptions.

```bash
python -I -W error -B check_dispatch.py
python -I -W error -B test_core.py
python -I -W error -B test_join.py
```

## Complete scope and costs

Numerical operations in the new graph charge the real HostedWord arena
meter, while descriptor actions charge the real marker Tape meter. The
same-workload receipts subtract each overlap once and retain separate
literal, source-symbol, payload, radix, bounded-metadata and allocation
entries. The output Q/R retirement in the actual source continuation is
already paid there; the separate literal RETIRE entry is not double billed.

The metadata binder is retained finite64-slot source control. It selects
literal setter entries using current owner identities and reserves two
free roles; it neither decodes values/widths nor invokes external division.
Its representation and actual grant service remain explicit obligations.
The original source/key/radix path and fixed13-bit record code with arbitrary
12-bit opaque payloads are unchanged. This is one actual-call lowering,
not a full source-controller, supplier or multiplication result.
