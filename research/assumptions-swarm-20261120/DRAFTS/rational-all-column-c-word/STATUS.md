# Superseded checkpoint copy

This copy is retained only for recovery. The complete, independently reviewed
package is now published on CubeJerry/integer-mult-bounds at
`88dd72b4864665362230c56538d2bd2579c6beca`, under
`research/rational-all-column-c-word`. Use that immutable package and its

An earlier unverified draft incorrectly suggested the least common multiple
of unary denominators could attain L^L at total unary length L. The corrected
proof uses sum(q_i) <= L and D <= product(q_i) <= 3^(L/3). A D-state remainder
table alone would still fit a singly exponential description. The compact
binary-divisor implementation is a valid choice, not a necessary rescue.
This correction was completed before the reviewed contribution was published.
