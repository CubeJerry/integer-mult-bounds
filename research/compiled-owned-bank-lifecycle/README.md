# Current compiler private-bank lifecycle

This package gives a **source-bound physical lifecycle refinement** of the
selected complex construction. It preserves the actual current INIT/COPY/CLEAR
lifetimes through chronological products, completion/splitting and the complete
integer compiler, and executes the resulting fixed program with a literal
sequential-tape controller. The written theorem applies to every legal runtime
size for each fixed finite template, under explicit native, geometry and ordinary
row-service contracts. All five selected assumptions remain retained.

The new object is the executable current-source binding. The generic allocator,
coded-blank technique, output-before-pop discipline and geometric backing
argument are credited to #5814 and its predecessors. This does not repeat the
selected all-column algebra of #6890 or the newer owned-rise audit #6914.

## Concrete result

The authenticated current raw caller has 13,444 productive fields, 626
conservative private names and 2,118 private lifetimes. The source expansion
retains every operand and chart, all 1,974 COPY additions, and the complete
66,834-job paid profile. Added coordinate and whole-job boundaries are explicit
charged services. The annotated word has 642,410 events.

The source-driven lowerer uses #5443's actual Pascal matching, replication,
source deficits and deepest exits. It disables partial-copy and non-base
interface-only fallback. Every smaller program has its ordered matched fields,
placement and inverse-return boundary. Complete rank15 and rank20 fixtures
make 4 and 112 private-field borrow occurrences respectively, on 2 and 56
distinct private fields. Each returns before its actual owner can clear it.
Compiler nesting consumes no ordinary row divisor. The `borrowed_private`
receipt field counts occurrences, not distinct names.

The physical controller initializes the complete canonical zero format, adds
COPY into the actual destination, erases arbitrary dirty contents, and parks
all payloads and descriptors on one inherited physical continuation stack.
It collects every child output before retirement, restores the saved finite
PC and parent bank, and replaces the exact occupied issuing owner. Its tape
inventory is fixed independently of ordinary recursion depth.

For q payload ports, fixed return-PC width b, parent body sum S, child body sum
C, input/output owner lengths L_in/L_out and staged header length H, the exact
administrative descend/ascend bill is

`4S + 5C + 18L_in + 13L_out + 5H + 38q + 27b + 103`.

Row services, stopping tests, native/geometry tables, native work cleanup and
root conversion are charged separately. The proof includes exact INIT, COPY,
retirement and stack bills. Its coordinatewise retained-backing formula counts
old capacity, erased work, current delimiters, every visited frontier and
shared bridges. With the stated current-volume service bound and actual
whole-row contraction by fixed w>=2, it yields `K0 + C_template V_root`.

## Exact ABI and limitations

Every numerical/native payload uses three-bit codewords for logical symbols;
logical blank4 is code100. A signed component ends in logical2, code010, so a
canonical numerical zero row is not a run of physical zero bits. Numerical
providers return exactly the declared complete-record extent at the origin,
with no residual coded tail. All scratch extents remain charged even when
erased. Global common precision and actual addition headroom are premises.

For each fixed native table, ports are its event fields, fixed mutable
`primitive_work`, then read-only raw binary `primitive_context`. Context has
physical blank6 as its frontier, cannot be written, and cannot be crossed at
either boundary. It carries runtime e/f/K/rho without an uncounted host closure.
Auxiliaries and context are part of the same parked payload inventory. An old
native table with a different alphabet or representation requires an explicit
adapter and invoice.

Only ordinary rank-one PAID sites call `prepare/install/collect`. Their row
service must supply actual decreasing rank, placement, remainder kernels,
stock division, numerical cutoff and complete inverse row reconstruction.
Matched compiler occurrences already have their full ordered field list.
The local unary-depth row fixture proves none of those numerical producer
properties. The proof permits a separately verified physical row supplier;
it does not assume that a callback silently implements the selected recursion.

The final selected power1024 template at N=2^65807000000000 is constructively
defined but not materialized or executed. Native/compact primitive correctness,
the quantified source compiler dependency, actual numerical precision/error,
complete caller/row admission, BIT and analytic recovery remain explicit.
No selected-frontier file or kappa is changed.
