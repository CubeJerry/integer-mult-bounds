## 1. Complete the actual Word-service interface before a higher controller

**Weakest useful missing implication.** Bind one fixed literal Word-service
library to every remaining successful Word/Arena call of this exact
producer: zero/copy/literal-one/free, zero test, rewind, msb and charged
local reads/writes/moves, with the source's actual head postconditions.
Prove it composes with unchanged B12 and preserves the same owner relation.
The next higher-control boundary would then be one complete
Arithmetic.multiply invocation, including its scan copy, all P iterations,
conditional additions and erasures; it should not simply assume those
Word services under new names.

**Concrete seam.** `Arithmetic.__init__` first calls `arena.literal(1)`;
`Arena.zero` scans `arena.template`, whereas B12's64 numerical descriptors
name only eight guards plus56 owned Words. The template is a real additional
bank role: NodeEntry takes bank0..2, Entry maps private Words to bank3..58,
the template to bank59 and padded left/right/output to bank60..62. A new
service must bind and pay actual bank59 access or prove a different source
of the identical extent. It cannot treat the template as one of the64
already-dispatched Words. Higher loops deliberately move a scan spectator
to the MSB and then down to LEFT; an msb service must return headP, not
incorrectly promise head1 after every service.

**Already proved / still supplied.** #5053 proves these source algorithms,
numerical admission, source-operation bounds and live stock; #5219 proves
guide-driven framing and allocator correspondence. B12 preserves moving
spectators and proves raw-operand head1 typing. Their literal Word-service
binding and whole higher-controller graph remain supplied. #7565 assumes
such typed services; #6878's ideal compiler composition does not perform
this current template/head binding.

**Verification boundary and stop.** Start at the actual first literal-one
call, then verify every reachable Word-service kind and one full current
modular-multiply call, with template preservation, nontrivial scan heads,
aliased doubling, output erasure and larger retained histories. Derive an
all-P complete bill; do not infer it from packets. Stop if an existing exact
source-bound library already covers these ports/head states, or if template
access/grants or a caller loop is hidden in a host-selected helper. Keep the
full numerical producer and payload controller outside until separately
joined.

## 2. Replace the current finite owner service with an encoded state relation

**Weakest useful missing implication.** Realize the actual replacement
Entry's64-slot metadata lifecycle as one finite physical service: initialize
the protected bitmap and ordered free stack, bind live references, reserve
zero/one/two outputs, release an erased Word, and verify terminal protected
stock. Emit the six-bit descriptors consumed by unchanged B12 and prove a
bisimulation with the present replacement metadata, including all active
source guards and acquire-once state. Preserve the ordered free stack, not
just equal output values or equal live cardinality.

**Exact source.** Word/Arena.zero/free/free_many and producer.produce's
protected/keep/finally logic; Entry.__init__ initializes live0..7 and the
reversed8..63 free stack. B12 `binding.py:reserve_simple/install/simple`
(SHA256 `bdfbd5b05476b7f57035e5b87be215a279b30f3f6b215be12c5bac7bf9d363c4`)
and B10 `binding.py:reserve` contain the current external checks. B12 proof
§§3–4 gives their weak relation and conservative service invoice.

**Already proved / still supplied.** The universe and all stack lengths
are bounded by64; B12 proves the present object-level relation and literal
handle use. A finite-state realization exists in principle from that fixed
universe, so this is not a newly discovered unbounded-storage axiom. An
encoded bitmap/free-stack realization is a concrete, reviewable successor.
The old16384 reservation tariff is a supplied service bound; the successor
must derive its own physical tariff instead of assuming the same constant.
Neither generic permanent-home dispatch nor abstract occurrence matching
proves this exact metadata transition system and its source continuations.

**Verification boundary and stop.** Use complete per-Entry source traces
with different free-stack fingerprints, all reservation arities, aliases,
unit divisors and final cleanup. Challenge duplicate/free/live descriptors,
wrong stack order and returning live-data corruption. Include encoded
metadata initialization, all accesses, head returns, retirement and history.
Stop if a source callback still chooses a raw slot/continuation from decoded
state, or if the old stack relation is replaced by numerical equality alone.
No ancestor allocator or whole recursive ownership theorem follows.

## 3. Turn allocated-backend caps into actual physical grants and a tariff

**Weakest useful missing implication.** At one exact NodeEntry open/close
and subsequent fixed-payload handoff, map the supplied Port/Word/marker
services to a common physical representation, with explicitly granted
access windows and a complete invoice for every touched source prefix,
frame, return and retained history. Reuse the existing rolewise cap table;
prove the additional relation between its allocated-cell bounds and the
physical windows actually visited by the chosen literal machine.

**A concrete boundary to test.** The owner proof explicitly bounds retained
allocated cells, not all head visits. Its guide role0 bound is q0=P+1:
LEFT plus P unary ones. Entry.word_storage reads the blank terminator at
indexP+1, which Port.read supplies beyond allocated backing. A physical
owned-window grant for that read needs to include that cell (length at
leastP+2), even though the original allocation bound q0 remains correct.
Likewise some append/return paths move one cell beyond the final allocated
symbol. Do not reuse the allocation table verbatim as an access-capability
table; audit the actual typed paths before asserting a uniform conversion.
B10/B12 already handle the separate four eight-cell selector grants, but
that does not establish all63 numerical-owner grants.

**Already proved / still supplied.** #5219 and the persistent-owner proof
supply guide semantics, exact per-role allocated caps and sums of historical
maxima. B9–B12 provide literal portions and exact mixed-model overlaps.
The new obligation is the physical grant/access/tariff join, not another
capacity calculation. #7565 presupposes complete supplied windows, common
format and paid primitive tariffs; #6878's conditional geometry does not
supply this Port.read boundary or a current source-prefix grant.

**Verification boundary and stop.** Begin with the actual guide/output
bank0/bank62 binding, template bank59 and a complete NodeEntry lifecycle.
Use under-granted sentinel access as a rejection control, source-prefix
length L much larger than P, asymmetric retained histories, repeated
precision changes and all head/marker returns. Preserve the residual
Word/controller costs from items1–2 until they have their own realizations.
If fixed-width binary encodings are used to compare the14-symbol Port
model with the literal alphabet, charge every symbol read/write/move and
alignment change. Stop if a grant is inferred from growable arrays, if L or
old history is absorbed into P^4 without an applicability proof, or if the
fixed13-bit payload test is promoted to a general payload theorem.
