## Actual ABI mapping

| Existing physical object | Adapter action | B4 input |
|---|---|---|
| `headers['h']`: L, p LSB-first bits, R | copy, erase high zero suffix until last 1 | canonical h |
| `headers['modulus']`: same p-bit frame | copy first h+1 bits, check omitted suffix is zero | s |
| `headers['offsets']`: L, p bits, `|R` | same bounded copy, check exact suffix | a |
| `headers['selected_layer']`: p-bit current counter | same bounded copy | j |
| current `address`: L, h bits, R | copy all h bits and append zero | x |
| `width`: L, h unary marks, R; head on target mark | temporarily mark that cell, scan/return by marker | h+1 extent and target capability |

All copied fields occupy separate, fixed private owners. B4's numeric
alphabet is statically renamed into the already supported symbols:
0/1 stay `0`/`1`, blank becomes `_`, LEFT becomes `L`, END becomes `|`.
No public marker is converted or overwritten. The current target mark is
temporarily replaced with `|`, restored to `1`, and its head returned to
the same physical cell. The address is changed at exactly that target bit
iff B4's actual owned output is 1; no Python Boolean selects the switch.
Other borrowed headers and their origins return unchanged. The owned B4
input copies, Boolean output, private guards and all private bodies retire.

The uniform domain is h>=1, p>=h+1, canonical header values satisfying
1<=s<=2^h, 0<=a<s, 0<=j<2h-1 and 0<=x<2^h, with the width guide and frame
boundaries as declared. The actual #7388 fixture has h=2,p=5,s=2,a=1.
All p source digits, including high zero padding, are scanned and charged.
Source access/production is paid by the retained caller; this new lemma
does not manufacture an accessible source or numerical lease from an index.

## Source-order row controller

The predecessor already enumerates physical input positions by incrementing
an h-bit tape, scans the actual payload, writes keys in its allocated cells,
and follows the palindromic target sequence `0,...,h-1,h-2,...,0` by moving
the unary-width head. Retain that source structure. Replace the row-tape
traversal with a paid encoded layer counter. Forward starts at zero and
increments after each query. Reverse builds 2h-2 by scanning all width marks
after the first, incrementing twice per mark, then decrements per query.
Both directions terminate from the actual target-head boundary; there is
no host `range(2*h-1)`, decoded row number, or new variable tape inventory.

The same canonical rows are therefore visited in reverse order during the
inverse. Every switch layer is an involution. As in #7388, the left child
is unchanged during this isolated leaf operation, so the actual inverse
lease supplies the same offset. Full source/payload restoration must be
checked, not inferred from a final coordinate alone.

## Complete optimistic budget before coding

Put N=2^h, R=2h-1, Q=NR, and let L be the full actual source extent.
Let C_source(dir) be the retained complete source/lease/staging/retirement
bill for this direction, including skipped leases. Let A acquire the real
source, payload, caller roles and blank windows. Proposed per-query cost is

`T_query <= 1024(h+3)^2 + c(p+h+1)`

for one absolute constant c established by the emitted adapter loops. The
linear term includes full precision scans, copied-field zeroing, canonical
height trimming, target seeking, Boolean consumption, every head return
and retirement. A provisional envelope c=1024 is plausible but will not
be claimed until the graph's loops are counted. Storage increment beyond
borrowed entry histories is O(p+h), with constant fixed owners reused
between queries and without refunding earlier high-water capacity.

Header production costs O(L+hp+p) through the retained paid scans. The
new row-counter work costs O(Qp+Nhp). Payload scans, physical rekeying,
index increments and final adapter disposal cost O(N(h+1)+p+h). The
retained h-pass literal radix bill for N records with h-bit keys is

`T_radix <= h * (7740*(N*(12h+8)+10)+144)`.

Thus the entire admitted workload is bounded by A+C_source(dir), those
header/counter/scan/disposal terms, Q*T_query and T_radix, plus actual
external transport. The acquired numerical, adapter, output, payload,
bucket and finite-control histories all remain charged, including both
directions' separate acquisitions where the old caller uses them.

For the exact old workload, ROM production remains separately bounded by
`10^6 p^2 * 2*(N+1)^3*(h+1)^4`, followed by the complete row-query scans,
serialization, key writes, payload movement and output disposal. A retained
ROM can amortize production over later calls. These are upper bounds;
comparing them alone proves no runtime gain. The proposed source replay
will report measured same-workload component bills, preserve the existing
model distinction, and make no full supplier, E(p,ell), kappa or multiplier
claim. Its main progress is a paid actual caller for the direct predicate.

## Verification and stopping rule

First use the exact #7388 four-tag forward/inverse fixture and direct CRT
placement oracle. Then use an actual four-tag variant with right modulus3
and left modulus2 (same widths) to force dependence on the updated wire:
its offset is2, and a later row distinguishes current from original wire.
Add stale-offset and stale-current-wire mutations, wrong reverse layer
order, dirty-private/owner/marker controls, and full bytes/heads/history
checks. If admitted by the retained numerical source, check zero offset,
unit modulus, invalid left coordinate and padded right coordinate without
inventing a globally-invalid-is-identity rule. Uniform h=1 and larger h
adapter tests remain separate from the actual finite caller fixtures.

Stop if the new per-query bridge needs a host numeric decode, unbounded
role creation or runtime topology dispatcher; if exact current source
production cannot be connected without unpriced copies; or if the same
physical payload/source inverse fails. Scope may then narrow to the uniform
query-consumption adapter and an explicit remaining caller implication.
