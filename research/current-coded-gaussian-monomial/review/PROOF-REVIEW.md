## Independent construction

The observer imports the production adapter and the retained ordinary
constructor. It never imports the author's fixture, serializer or address
oracle. Its physical hardware is a sparse dictionary of seven-symbol cells
with counted reads, writes and unit head moves. Its current numeric serializer
separately constructs three-bit codes, little-endian two's-complement words
and literal `010` component delimiters. Its twenty-three-field descriptor order
is written independently and checked against the public interface.

The mathematical oracle uses integer address bits and repeated exact quarter
turns `(real,imaginary) -> (-imaginary,real)`. These host values are checker-only.
The production call receives only its actual coded ports, read-only context,
and preallocated physical work ports. No payload callback or oracle is
supplied to the engine.

The finite cases use rank-one monomials to isolate the current-format join.
They execute phase traversal and one inverse affine toggle. Their ordinary
supplier object is the retained elementary fixture, but its ordinary/Compact
call counters remain unchanged in every admitted case. These runs therefore
make no claim to recheck the complete Compact path; the author's separate
full-path cases and the inherited mathematical supplier remain distinct.

## Source/proof review

I read the adapter, bootstrap, selected source binder, retained phase control
and monomial engine, the adapter proof, and the inherited relevant contracts.
The within-row arithmetic, suffix grouping, component alignment, and inverse
ordering are consistent with the stated interface. The wrapper delays public
writes until the protected native result has returned, which is the necessary
reason its named headroom failure preserves the public field. Cleanup uses
the current coded frontier rather than a historical backing-array length.

I found no remaining blocker in the scoped endpoint and complete cost argument
after the following limits were made explicit in the proof:

* Physical segment disjointness is a caller premise. Distinct Python wrappers
  do not themselves prove that their underlying physical segments differ.
* The automatic `f<=d/2` suffix-growth implication requires rank at least two.
  At rank one, the favorable long-record domain is an additional hypothesis.
* The complete descriptor length `E` is charged even at `f=1`; this adapter
  reads metadata which the old engine could leave unused.
* The selected event token identifies a source chart, but does not by itself
  normalize a larger enclosing occurrence. Its nine-vector active span and
  matching current header remain a paid caller/placement contract.

These qualifications preserve a positive current-format refinement. They also
prevent the result from being silently promoted to a complete compiler/native
join or to a selected tariff. The historical ordinary exponent, flat-table
export, global precision/headroom supply and the other selected assumptions
remain as the package states.

## Portable reproduction

The script uses only the standard library. With an exact package directory:

```sh
python -I -B independent_current_phase.py --package PACKAGE --output normal.json
python -I -O -B independent_current_phase.py --package PACKAGE --output optimized.json
```

Both commands print `PASS_INDEPENDENT_CURRENT_PHASE_FORMAT` in their structured
receipt. The copied checker may be placed inside the package without editing
its source; both paths are explicit CLI arguments. Compare the complete receipts,
not only a status label. Any additional package wrapper should retain the
original script and receipt hashes above and state the same review scope.
