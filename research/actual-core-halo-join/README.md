## The missing interface this implements

The earlier complete Core supplies three global dense cohorts and two
complete sparse windows, with actual original-coordinate routes. The
earlier first-face transaction supplies saved-original transport, a
same-Reference halo consumer, and an exact kept/returned merge. It left an
actual Core at that boundary as an explicit open question.

`attachment.py` makes that call directly. It does not accept a dense or
sparse numerical service callback. The new `format_bridge.py` streams
between the two real formats: big-endian sign magnitude on grid `2^-q`,
and little-endian two's complement on the common Core grid `2^-P`.
It performs the exact input lift and one signed toward-zero return divided
by the product of all axis normalizers. No payload magnitude is decoded
into a host integer, and no quadratic scalar macro is applied to every
dense word.

`source_geometry.py` binds the source family using the actual Layout label
map. Family rows remain in halo/MSB order, while the retained Core performs
its documented reversal internally. Support completion can permute coarse
labels: a context label is not assumed to be the original Cartesian coarse
index. The generic factory uses the inherited conservative source band;
the smaller fixture band is separately admitted by a complete source scan.

The contribution is this full common-geometry implementation and its
source, radius, format, ownership and cost compatibility. The five-factor
identity, first-face enumeration, sparse recurrence and #6880 numerical
splice are inherited. Contemporaneous independent signed/grid bridge work
is acknowledged in NOTICE.md.

## Numerical and resource contracts

Let the actual active axes have normalizers `a_i=2^u_i`,
`A=product_i a_i`, gaps `delta_i`, halfwidths `W_i`, and halo term counts
`J_i`. The complete field contains `T=K L^g` complex records, including
all contexts and spectators. Input component-l1 radius `R_in` requires
the **global** Core radius `R0^2 >= T R_in^2`; a separate per-context radius
does not fund the three global dense calls.

If the actual whole-field Core has Euclidean defect epsilon, the literal
normalized return has pointwise complex-l1 defect at most

\[
2\epsilon/A+2\,2^{-q}.
\]

Set `tau_i=(1-delta_i)^J_i/delta_i` and
`eta_i=((2W_i+1)R_halo+2)2^-q/delta_i`. The inherited splice then gives

\[
E_{keep}\le 2\epsilon/A+2\,2^{-q}
             +2R_{in}\sum_i\tau_i/a_i,
\qquad
E_{halo}\le\sum_i\eta_i+R_{halo}\sum_i\tau_i/a_i.
\]

The full return error is at most `max(E_keep,E_halo)`. A shared halo
integer carrier `R_halo>=2R_in` is funded when `2epsilon/A<=R_in`; the normalized
principal-window inverses are contractions, and toward-zero conversion
does not increase radius. Incoming error and the later undoing of A belong
to the outer caller.

The complete invoice retains the prior Core bill, global dense scans,
every sparse source/page/catalogue operation, all original routes, the
halo source producer, repeated full-archive scans, descriptor/key work,
scalar macros, return and cleanup. The new dense bridges cost
`O(T(w+h) polylog(h+w+P+q+drop))`, with a fixed short-Count exponent and
end-marker field traversal. Their historical backing adds the complete
lifted input, one scalar scratch role, and fixed control roles. Cleared
historical tails and concurrently retained fields remain charged.

from the one-axis fixtures or identify those providers with the selected

## Reproduction and sources

Python 3.12 and the standard library suffice. Canonical base:
`7c49fe32c55de02c2c873655c804b16e4c3fef0a`.
`SOURCES.json`, `DEPENDENCIES.json` and `PUBLIC-HALO-PINS.json` record exact
Git blobs, SHA256 hashes and public commits. Retained bodies are unchanged.
`EXECUTION-SOURCES.json` seals the new execution and source-binding bodies.

The extended physical execution is deliberately separate from the bounded
registered review hook:

```sh
python3 -B research/actual-core-halo-join/verify.py --output /tmp/core-halo-physical.json
```

It performs real exact source-page preparation before all numerical
stages. Small source dimensions do not imply a short runtime: the
prepared Schur factors contain large exact rational coefficients, and
their actual tape reductions and inversions are charged. A scalar-product
timing alone is not a complete setup estimate.

The separately labelled semantic command is:

```sh
python3 -B research/actual-core-halo-join/semantic_halo.py --output /tmp/core-halo-semantic.json
python3 -O -B research/actual-core-halo-join/semantic_halo.py --output /tmp/core-halo-semantic-optimized.json
```

independent controls and failed-check history. It explicitly distinguishes
a full physical replay from review of an existing physical receipt.
