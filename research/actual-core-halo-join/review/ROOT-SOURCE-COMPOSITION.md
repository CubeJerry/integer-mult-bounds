## The joint Core error is normalized once

Let `T` be the full record count, including all contexts and spectators, and
let actual incoming complex component-l1 radius be `R_in`.
The Core's Euclidean input bound must satisfy `R0^2 >= T*R_in^2`.
This is distinct from the halo's componentwise carrier radius.

Write `a_i=2^u_i`, `A=product_i a_i`, and
`tau_i=delta_i^(-1)*(1-delta_i)^J_i` for the predecessor tail bounds.
With `a_i*delta_i>=1`, each normalized principal-window inverse is a
contraction in maximum component-l1 norm. Their tensor product and the direct
sum over complete boxes are contractions in that same norm.

If the executed unnormalized whole-field Core has Euclidean defect at most
`epsilon`, a sufficient bound for its normalized return on the q-grid is

`E_finite <= 2*epsilon/A + 2*2^(-q)`.

The first term converts the whole-field residual to a single complex
component and normalizes it; no additional sqrt(T) belongs there. The second
term pays the two actual toward-zero component truncations. Conversely, the
sqrt(T) factor above cannot be omitted from the input-radius admission.
The exact shift uses `P + sum_i u_i - q`, not the largest individual shift.
For a negative odd integer numerator, arithmetic floor is a different map.

The raw normalized approximate result has component-l1 radius at most
`R_in + 2*epsilon/A`. Thus the common larger carrier `R_halo=2*R_in` is
sufficient when `2*epsilon/A<=R_in`; truncation toward zero cannot increase
that radius. No claim about the ideal input alone substitutes for the actual
incoming field bound.

Applying the existing kept-row comparison to the actual joint Core gives

`E_keep <= E_finite + 2*R_in*sum_i tau_i/a_i`.

The retained shrinking consumer permits the conservative halo bound

`E_halo <= sum_i ((s_i*R_halo+2)*2^(-q)/delta_i) + R_halo*sum_i tau_i/a_i`.

The complete result is bounded by `max(E_keep,E_halo)`, since the output
